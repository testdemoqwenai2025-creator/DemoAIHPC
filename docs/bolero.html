BOLERO — Cell-State-Conditioned Sequence Model

A sequence-to-function Transformer whose weights are dynamically generated per cell type by a hypernetwork conditioned on a cell-state embedding. BOLERO predicts cell-state-specific transcript abundance and chromatin accessibility (ATAC-seq) directly from raw DNA — and generalises across species (human, mouse, macaque) without being trained on them. Trained on the Bolero-10M epigenetic + multiomics dataset (10M+ cells across human brain and body, development and aging, across species). Read the paper →

The six stages

Each stage narrates one component of the BOLERO pipeline. Click any stage to jump there.

  1. 1DNA input
    One-hot encoded sequence (A,C,G,T) — typically 4,096 bp context window.
  2. 2Cell-state embedding
    10M-cell reference compresses cell identity into a dense vector z ∈ ℝᵈ.
  3. 3Hypernetwork weight generator
    HyperNet(z) → ΔW per layer — dynamic weight modifications added to baseline Transformer.
  4. 4Sequence-conditioned Transformer
    Multi-head self-attention over DNA tokens with cell-state-specific ΔW injected at every layer.
  5. 5ATAC + transcript prediction
    Output head predicts chromatin accessibility + RNA abundance for that cell type at each locus.
  6. 6UMAP clustering + attribution
    ~32K predicted cells projected to 2D; saliency maps identify which DNA bases drive each prediction.
Paper key results
  • Predicts cell-state-specific transcript + ATAC from DNA
  • Cross-species generalisation (human → mouse → macaque)
  • Discovered FOX-AP-1 spacing rule (4bp optimal)
  • Designs new enhancers + scores disease variants
  • In silico virtual DNA-editing experiments

📐 Mathematical formulation

Stage 1 — DNA input: x ∈ {0,1}^{4 × L} (one-hot A/C/G/T over L base pairs)
Typical L = 4,096–16,384 bp context window. Each position is a 4-dim one-hot vector (A=[1,0,0,0], C=[0,1,0,0], G=[0,0,1,0], T=[0,0,0,1]).
Stage 2 — Cell-state embedding: z = f_embed(cell_id) ∈ ℝᵈ where d ≈ 128–512
Cell identity compressed to a dense vector by training a variational autoencoder on the Bolero-10M single-cell atlas (~10M cells, 200+ cell types, 4 species). The embedding captures cell-type + activation state + species + developmental stage.
Stage 3 — Hypernetwork weight generator: ΔWₗ = HyperNetₗ(z) ∈ ℝ^{dₗ × dₗ} for each Transformer layer l
A separate HyperNet per layer maps the cell-state embedding z to a weight-modification matrix ΔWₗ. This ΔWₗ is added to the baseline (DNA-only) weights Wₗ, so the same DNA sequence produces different ATAC predictions in different cell types.
Stage 4 — Cell-conditioned Transformer forward pass: hₗ = TransformerLayerₗ(hₗ₋₁ ; Wₗ + ΔWₗ(z))
Standard Transformer block: LayerNorm → Multi-Head Self-Attention → Add → LayerNorm → MLP → Add. The only modification is that every weight tensor is summed with the cell-state-specific ΔWₗ(z). This is a hypernetwork conditioning — different from FiLM/AdaLN which scale activations; here the weights themselves are cell-state-dependent.
Stage 5 — Prediction heads: ŷ_ATAC = softmax(MLP_ATAC(h_L)), ŷ_RNA = MLP_RNA(h_L)
Per-locus ATAC-seq accessibility (binary: open/closed) + per-gene RNA abundance (regression). Both heads are also cell-state-conditioned via ΔW on their final layer.
Stage 6 — Sequence attribution: attr(x, c) = ∂ŷ_c / ∂x = Σᵢ (∂ŷ_c/∂h_L) · (∂h_L/∂xᵢ) (gradient × input)
Saliency map identifying which DNA positions drive the model's prediction for cell type c. BOLERO's attribution discovered the FOX-AP-1 spacing rule: placing a FOX factor binding site exactly 4 bp from an AP-1 site dramatically boosts cellular response — a regulatory grammar learned directly from sequence.

💻 Math → Code — runnable Python implementation

BOLERO minimal reference implementation (numpy + 70 lines)

# Stage 1: DNA one-hot encoding
# A → [1,0,0,0]  C → [0,1,0,0]  G → [0,0,1,0]  T → [0,0,0,1]
import numpy as np

def encode_dna(sequence):
    # x → (4, L) one-hot — used as the sequence input
    code = {'A':0, 'C':1, 'G':2, 'T':3}
    x = np.zeros((4, len(sequence)), dtype=float)
    for i, b in enumerate(sequence):
        x[code[b], i] = 1.0
    return x  # shape (4, L)

# Stage 2: Cell-state embedding (pre-trained VAE on Bolero-10M atlas)
def cell_state_embedding(cell_id, atlas_weights):
    # z = f_embed(cell_id) ∈ R^d  (d ≈ 128)
    return atlas_weights['embeddings'][cell_id]  # shape (d,)

# Stage 3: Hypernetwork generates per-layer weight deltas
class HyperNet:
    def __init__(self, d_embed, d_layer):
        s = np.sqrt(2.0 / d_embed)
        self.W = np.random.randn(d_layer, d_embed) * s
        self.b = np.zeros(d_layer)

    def __call__(self, z):
        # ΔW_l = HyperNet_l(z) — added to baseline W_l
        return self.W @ z + self.b  # shape (d_layer,)

# Stage 4: Cell-conditioned Transformer forward pass
def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def transformer_layer(h, W_q, W_k, W_v, W_o, W_ff, b_ff, delta_W):
    # Inject cell-state delta: W → W + ΔW
    W_q_eff = W_q + delta_W
    W_k_eff = W_k + delta_W.T
    Q = h @ W_q_eff.T; K = h @ W_k_eff.T; V = h @ W_v.T
    d_k = Q.shape[-1]
    attn = softmax(Q @ K.T / np.sqrt(d_k), axis=-1)
    h_attn = attn @ V
    h_ff = np.maximum(0, h_attn @ W_ff + b_ff)
    return h_ff  # post-Add+LayerNorm skipped for clarity

# Stage 5: ATAC prediction head
def predict_atac(h_L, W_atac, b_atac):
    # ŷ_ATAC = softmax(MLP_ATAC(h_L)) — open/closed per locus
    logits = h_L @ W_atac.T + b_atac
    return softmax(logits, axis=-1)

# Stage 6: Sequence attribution via gradient × input
def attribute_sequence(x, cell_id, model_weights, eps=1e-3):
    # attr[i] = ∂ŷ_c/∂x[i] — which bases drive the prediction
    baseline = predict_atac(forward(x, cell_id, model_weights))
    attrs = np.zeros_like(x)
    for i in range(x.shape[1]):
        x_perturbed = x.copy()
        x_perturbed[:, i] = 0.0  # zero out position i
        pred_perturbed = predict_atac(forward(x_perturbed, cell_id, model_weights))
        attrs[:, i] = (baseline - pred_perturbed) / eps  # leave-one-out saliency
    return attrs  # shape (4, L) — per-base importance

def forward(x, cell_id, weights):
    z = cell_state_embedding(cell_id, weights['atlas'])
    h = x.T  # (L, 4) — sequence as tokens
    for layer in weights['layers']:
        delta_W = layer['hypernet'](z)
        h = transformer_layer(h, **layer['weights'], delta_W=delta_W)
    return h[-1]  # final-layer representation

# === Example: predict ATAC for a 32-bp DNA sequence in 2 cell types ===
np.random.seed(0)
seq = "ACGTACGTACGTACGTACGTACGTACGTACGT"  # toy 32-bp sequence
x = encode_dna(seq)
print(f"DNA shape: {x.shape} (one-hot 4×L)")
print(f"First 4 positions encoded:\n{x[:, :4]}")
# → shape (4, 32); each column is one-hot for A/C/G/T

🧠 Deep thoughts — when to reach for cell-state-conditioned sequence models

Strategic guidance — applying BOLERO-style architectures to your domain

USE WHENsingle-cell genomics where the same DNA sequence has different functions in different cell types (regulatory genomics, enhancer design, disease variant scoring, cell-fate prediction, virtual CRISPR experiments, cross-species transfer). Anywhere you need a universal sequence model that adapts to biological context.
AVOID WHENyou only have bulk-tissue data (no single-cell resolution → no cell-state embedding to learn); the cell types in your data are < 10 (a small classifier is faster); you need protein-level predictions (use AlphaFold + ESM-style models); or you need real-time inference at < 10 ms latency (BOLERO-style hypernetworks add ~3× compute vs vanilla Transformer).
WHYThe key insight is weight-level conditioning rather than the more common FiLM/AdaLN activation-level conditioning. By generating ΔWₗ per layer from the cell-state embedding, the model can express qualitatively different sequence grammars in different cell types — e.g. FOX-AP-1 spacing matters in neurons but not in glia. Activation-level conditioning can only scale/shift a shared grammar; weight-level conditioning can swap grammars entirely. This is why BOLERO discovers regulatory rules (FOX-AP-1 4bp spacing) that activation-conditioned models miss.

🔬 Comparison with related approaches

How BOLERO differs from prior sequence models

vs DeepSEA / BasenjiThose predict tissue-specific ATAC from sequence but use a fixed CNN — no cell-state input. BOLERO's hypernetwork conditioning means the same DNA can produce different ATAC in different cell types within one model (no need to retrain per tissue). ~100× parameter efficiency vs training one model per cell type.
vs EnformerEnformer extended Basenji to 200 kb context with Transformer attention. BOLERO keeps the Transformer but adds cell-state conditioning + attribution. Same architecture class, but BOLERO answers a different question: what would this sequence do in cell type X?
vs scGPT / GeneformerThose are cell-state foundation models — trained on single-cell RNA. They have no sequence input. BOLERO's complement: it needs a cell-state embedding (often from scGPT) as its conditioning input. The two are designed to be composed: scGPT → cell-state embedding → BOLERO → sequence-to-function prediction in that cell.
vs Hypernetworks (Ha et al. 2016)BOLERO's hypernetwork conditioning is the same idea (one network generates another's weights) but applied to the largest conditioning space to date — 200+ cell types × 4 species × developmental stages. The hypernetwork is also factored per Transformer layer (ΔWₗ not a single ΔW), giving finer control.
