Cryo-EM VAE — Protein Conformational Distributions

Recovering continuous distributions of protein conformations from cryo-EM particle images using Variational Autoencoders. Traditional cryo-EM produces discrete 3D structures — this method captures the full conformational landscape: how a protein flexes, bends, and moves. The VAE encoder maps 2D cryo-EM images to a latent space where each point is a different conformation; the decoder reconstructs the 3D atomic structure. Read the paper →

📐 Mathematical formulation

Stage 1 — Cryo-EM image formation: I = P(R · C(x)) + noise R = rotation matrix, C = 3D conformation, P = projection operator
Each cryo-EM image is a 2D projection of a 3D protein in a random orientation R and conformation C. The protein is flash-frozen in vitreous ice — each particle captures a different snapshot of the protein's dynamic motion.
Stage 2 — VAE encoder: q(z | I) = N(μ(I), σ(I)) Maps 2D cryo-EM image → latent conformational code z
The encoder network learns to extract a compact latent representation z from each 2D image — encoding both the protein's orientation AND its conformation. The latent space is continuous, so nearby points z are similar conformations.
Stage 3 — VAE loss: L = E_q[log p(I | z)] − KL(q(z|I) || p(z)) Reconstruction (cryo-EM image fidelity) + KL (smooth latent space)
The reconstruction term ensures the decoder can generate images that match the cryo-EM data. The KL term regularises the latent space to be smooth and continuous — so interpolation between conformations produces physically plausible transitions.
Stage 4 — Latent conformational space: p(C) = ∫ p(C | z) q(z | I) dz The distribution of protein conformations across all particles
By sampling z from the latent space across all particles, we recover the FULL conformational distribution p(C) — not just one structure, but the ensemble of structures the protein adopts. This reveals flexible regions, conformational substates, and transition pathways.
Stage 5 — Decoder: C(x) = g_θ(z, x) Reconstructs 3D atomic coordinates from latent code z
The decoder network maps a latent code z back to a 3D atomic structure C(x). By sampling z along a path in latent space, we can generate a smooth trajectory of the protein's conformational change — a "movie" of the protein in motion, reconstructed from static snapshots.

💻 Runnable code

# Cryo-EM VAE — simplified implementation
import numpy as np

class CryoEMVAE:
    def __init__(self, img_dim=128, latent_dim=8):
        # Encoder: cryo-EM image → (mu, log_var) in latent space
        self.enc_W = np.random.randn(img_dim, latent_dim) * 0.02
        self.enc_b = np.zeros(latent_dim)
        # Decoder: latent code → 3D atomic coordinates
        self.dec_W = np.random.randn(latent_dim, img_dim) * 0.02
        self.dec_b = np.zeros(img_dim)
        self.latent_dim = latent_dim

    def encode(self, image):
        # q(z|I) = N(mu, sigma) — encode image to latent
        h = self.enc_W.T @ image + self.enc_b
        mu = h[:self.latent_dim]
        log_var = h[self.latent_dim:] if len(h) > self.latent_dim else np.zeros(self.latent_dim)
        return mu, log_var

    def reparameterize(self, mu, log_var):
        # z = mu + sigma * eps (reparametrisation trick)
        eps = np.random.randn(*mu.shape)
        return mu + np.exp(0.5 * log_var) * eps

    def decode(self, z):
        # C(x) = decoder(z) — reconstruct 3D structure
        return self.dec_W.T @ z + self.dec_b

    def loss(self, image, mu, log_var, z):
        # L = reconstruction + KL(q(z|I) || N(0,I))
        recon = np.mean((image - self.decode(z)) ** 2)
        kl = 0.5 * np.sum(np.exp(log_var) + mu ** 2 - log_var - 1)
        return recon + kl

    def conformational_distribution(self, images, n_samples=100):
        # Sample from latent space across all images
        # → recover continuous p(C) = conformational distribution
        conformations = []
        for img in images:
            mu, lv = self.encode(img)
            for _ in range(n_samples):
                z = self.reparameterize(mu, lv)
                C = self.decode(z)  # 3D atomic structure
                conformations.append(C)
        return np.array(conformations)

# === Example: recover conformational distribution from 100 cryo-EM images ===
np.random.seed(0)
vae = CryoEMVAE(img_dim=64, latent_dim=4)
images = [np.random.randn(64) for _ in range(100)]  # simulated cryo-EM particles
conformations = vae.conformational_distribution(images, n_samples=10)
print(f"Recovered {len(conformations)} conformations from 100 cryo-EM images")
print(f"Each conformation: {conformations[0].shape} (atomic coordinates)")
print(f"Conformational variance: {np.var(conformations, axis=0)[:4].round(3)}")
print(f"→ This is the continuous protein motion, not just one structure!")

🧠 Deep thoughts

When to use VAE for cryo-EM vs traditional methods

USE WHENProteins are flexible (have multiple conformations — enzymes, transporters, ion channels). When you want the full conformational landscape (not just one structure). When you have large cryo-EM datasets (100K+ particles). When you want to visualise protein motion as a smooth trajectory.
AVOID WHENThe protein is rigid (single conformation — use standard cryo-EM reconstruction). When you need atomic-resolution structures (VAE reconstructions are lower resolution). When you have few particles (<1000 — VAE needs many samples). When the protein is symmetric (use symmetry-aware methods instead).
WHYTraditional cryo-EM produces discrete structures — you pick one conformation and solve it. But proteins are dynamic machines — they flex, bend, and change shape to function. The VAE captures the continuous distribution of all conformations in a single model. This reveals: (1) flexible regions (drug targets), (2) conformational substates (functional states), (3) transition pathways (how the protein moves). The latent space is the protein's "conformational genome" — every point is a valid structure.

🔬 Comparison

VAE cryo-EM vs other approaches

vs Traditional cryo-EM (RELION, cryoSPARC)Traditional methods produce ONE structure (or a few discrete classes). VAE produces a CONTINUOUS distribution. Traditional is better for high-resolution static structures; VAE is better for understanding dynamics.
vs AlphaFoldAlphaFold predicts the "default" structure. VAE-cryo-EM captures ALL structures the protein actually adopts. AlphaFold = prediction; VAE-cryo-EM = observation. Complementary: AlphaFold gives a starting point, VAE-cryo-EM shows the real landscape.
vs Molecular dynamics (MD)MD simulates protein motion computationally (expensive, μs timescale limit). VAE-cryo-EM observes real motion from experimental data (no simulation needed, captures ms-s timescale). MD is better for atomistic detail; VAE is better for experimental grounding.
