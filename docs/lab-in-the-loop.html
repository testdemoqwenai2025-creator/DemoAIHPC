Lab in the Loop — AI Drug Discovery

The closed-loop pipeline for AI-driven drug discovery. Six stages cycle endlessly: Complex Space (the universe of possible molecules) → Models (ML predictors) → Self-improving Search (active learning + Bayesian optimisation) → Agents (autonomous design + prioritisation) → Digital Twins (virtual wet-lab simulation) → Lab Hardware (automated synthesis + assay). The Agentic RSI gauge in the center measures workflow momentum — when RSI > 70, the loop is converging fast; when RSI < 30, the search is stuck. 📐 Mathematical formulation

Stage 1 — Complex Space: Ω = {ω₁, ω₂, ..., ωₙ} where |Ω| ~ 10⁶⁰ possible molecules
The chemical space of drug-like molecules is estimated at 10⁶⁰ — more than atoms in the universe. The loop's job is to find the ω* that maximises a multi-objective score (binding affinity + selectivity + ADMET) within a practical budget of wet-lab experiments.
Stage 2 — Models: f(ω) → ŷ = (binding, toxicity, solubility, ...) Trained on prior experimental data D = {(ωᵢ, yᵢ)}ᵢ₌₁ᴺ
ML models predict experimental outcomes from molecular structure. Each model has uncertainty — quantified via ensemble disagreement or Bayesian posterior. The loop queries the model for predictions + uncertainty on candidate molecules.
Stage 3 — Self-improving Search (Active Learning): ω* = argmax_ω [ EI(ω) ] where EI(ω) = (μ(ω) - f_best) · Φ(z) + σ(ω) · φ(z) z = (μ(ω) - f_best) / σ(ω)
Expected Improvement (EI) — the acquisition function for Bayesian optimisation. Balances exploitation (high predicted score μ) and exploration (high uncertainty σ). The loop selects molecules that maximise EI — neither greedy nor random, but information-optimal.
Stage 4 — Agents: Agent(ω*, context) → {design, prioritise, validate} LLM-orchestrated: Claude/GPT decides which experiments to run, interprets results, adjusts strategy
Autonomous agents (LLMs + tool-use) orchestrate the loop. The agent: (1) proposes candidate molecules, (2) prioritises which to synthesise, (3) interprets wet-lab results, (4) adjusts the search strategy. Like Claude's scorpion toxin binder design — the agent is the orchestrator, not a single tool.
Stage 5 — Digital Twins: T(ω) → ŷ_simulated Virtual wet-lab: molecular dynamics + docking + ADMET simulation
Before spending wet-lab resources, the digital twin simulates the experiment computationally. If T(ω) predicts failure, the molecule is filtered out. The twin is calibrated against real experiments — its predictions improve over time.
Stage 6 — Lab Hardware: ω → synthesis → assay → y_measured Feedback: D' = D ∪ {(ω*, y_measured)} → retrain models → repeat
Automated synthesis + assay platforms (e.g., Strateos, Emerald Cloud Bio) run the experiment. The measured result y_measured is added to the training data D, models are retrained, and the loop repeats. Each cycle improves the models' accuracy.
Agentic RSI: RSI(t) = 100 · (1 - Δbest/Δbest_max) · (1 + log(1 + N_validated(t))) RSI > 70 = converging fast | RSI 30-70 = steady progress | RSI < 30 = stuck (change strategy)
The Agentic Relative Strength Index measures the loop's momentum. Δbest = improvement in best score this cycle. N_validated = number of validated hits. High RSI = the loop is finding better molecules fast. Low RSI = diminishing returns — the agent should change strategy (explore a new region of chemical space, try a different model, or relax constraints).

💻 Runnable code — closed-loop active learning

# Lab in the Loop — simplified active learning pipeline
import numpy as np

class LabInTheLoop:
    def __init__(self, n_molecules=10000, budget=50):
        # Ω: complex space of candidate molecules
        self.space = np.random.randn(n_molecules, 8)  # 8-dim features
        self.budget = budget  # max wet-lab experiments
        self.measured = {}  # D = {(ω_i, y_i)}
        self.best_score = -np.inf
        self.rsi_history = []

    def model_predict(self, omega):
        # f(ω) → ŷ (simplified: linear + noise)
        return np.dot(omega, np.random.randn(8)) + np.random.randn() * 0.5

    def model_uncertainty(self, omega):
        # σ(ω) — ensemble disagreement (simplified)
        return np.abs(np.random.randn()) * 0.3 + 0.1

    def expected_improvement(self, omega):
        # EI(ω) = (μ - f_best) * Φ(z) + σ * φ(z)
        mu = self.model_predict(omega)
        sigma = self.model_uncertainty(omega)
        z = (mu - self.best_score) / (sigma + 1e-8)
        # Φ(z) = normal CDF, φ(z) = normal PDF (simplified)
        from scipy.stats import norm
        ei = (mu - self.best_score) * norm.cdf(z) + sigma * norm.pdf(z)
        return ei

    def agent_select(self):
        # Stage 3+4: select ω* = argmax EI(ω)
        scores = [self.expected_improvement(o) for o in self.space]
        return np.argmax(scores)

    def digital_twin(self, omega):
        # Stage 5: virtual wet-lab (simplified simulation)
        return self.model_predict(omega) + np.random.randn() * 0.2

    def lab_experiment(self, omega):
        # Stage 6: real wet-lab (ground truth)
        return self.model_predict(omega) + np.random.randn() * 0.1

    def agentic_rsi(self, delta_best):
        # RSI = momentum indicator (0-100)
        delta_max = 1.0  # normalisation
        n_validated = len(self.measured)
        rsi = 100 * (1 - delta_best / delta_max) * (1 + np.log(1 + n_validated))
        return min(100, max(0, rsi))

    def run_cycle(self):
        # One loop iteration: select → simulate → experiment → update
        idx = self.agent_select()  # Stage 3+4
        omega = self.space[idx]
        sim = self.digital_twin(omega)  # Stage 5
        if sim < -0.5:  # filter — digital twin says "skip"
            return {'status': 'filtered', 'rsi': 0}
        y = self.lab_experiment(omega)  # Stage 6
        delta_best = max(0, y - self.best_score)
        self.best_score = max(self.best_score, y)
        self.measured[idx] = y  # D' = D ∪ {(ω*, y)}
        rsi = self.agentic_rsi(delta_best)
        self.rsi_history.append(rsi)
        return {'status': 'measured', 'score': y, 'best': self.best_score, 'rsi': rsi}

# === Run 10 cycles ===
np.random.seed(0)
lab = LabInTheLoop(n_molecules=1000, budget=10)
print("Lab in the Loop — 10 cycles:")
for cycle in range(10):
    result = lab.run_cycle()
    print(f"  Cycle {cycle+1}: {result['status']}, best={lab.best_score:.3f}, RSI={result.get('rsi',0):.1f}")
print(f"\nFinal: best_score={lab.best_score:.3f}, molecules_measured={len(lab.measured)}")
print(f"RSI trend: {lab.rsi_history}")

🧠 Deep thoughts — when to use closed-loop AI drug discovery

Strategic guidance

USE WHENYou have access to automated synthesis + assay (Strateos, Emerald Cloud, in-house robotics). The search space is too large for brute-force (10⁶⁰ molecules). You need multi-objective optimisation (binding + toxicity + ADMET + synthesizability). The agent can interpret results + adjust strategy autonomously.
AVOID WHENWet-lab is manual (slow + expensive — each experiment costs $1000s + weeks). The target is well-characterised (brute-force screening of known libraries is cheaper). You need FDA approval (closed-loop discovers novel chemistries that need full safety studies). The models have high uncertainty (the loop wastes budget on bad predictions).
WHYThe key insight is information-optimal exploration. Instead of screening 100K molecules randomly, the loop screens 50-100 molecules selected by Expected Improvement — each experiment maximally reduces uncertainty about the best molecule. This is 1000× more efficient than brute-force. The Agentic RSI tells you when to change strategy (RSI < 30 = diminishing returns, try a different chemical scaffold or relax constraints).

🔬 Comparison with traditional drug discovery

Closed-loop vs traditional approaches

vs HTS (High-Throughput Screening)HTS screens 100K-1M compounds blindly — cost ~$10M, 2 years, ~0.01% hit rate. Closed-loop screens 50-100 compounds selected by EI — cost ~$50K, 2 weeks, ~20% hit rate. 200× cheaper, 50× faster, 2000× more efficient. But needs reliable models + automated wet-lab.
vs Virtual screeningVirtual screening uses models to rank compounds but doesn't close the loop — no wet-lab feedback, no model improvement. Closed-loop = virtual screening + real experiments + model retraining. Each cycle makes the next cycle smarter.
vs AlphaFold + manual designAlphaFold predicts structures but doesn't design binders. Claude's toxin binder design is a single iteration of the loop (design → screen → validate). The full loop repeats this 100s of times with model retraining between cycles.
vs Clinical trialsClinical trials are the final stage — they test whether a drug works in humans. Closed-loop is the pre-clinical stage — it discovers the drug. They're complementary: closed-loop finds candidates faster + cheaper, clinical trials validate them.
