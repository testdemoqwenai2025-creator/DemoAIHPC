Science Hub · Bioinformatics

Bioinformatics

Bioinformatics · sequence to structure

Sequence → MSA → Tree → Structure

BLAST, alignment, phylogenetics, structural bioinformatics.

Modern AI for bioinformatics — sequence alignment, phylogenetic tree construction, BLAST-style search, protein structure prediction. Inspired by the public research ecosystem (AlphaFold, BLAST, BioPython, Nextstrain).

Live demo

BLAST-style search

Local sequence alignment via Smith-Waterman. Paste a query, search against an embedded database. Pure client-side.

Tools: Smith-Waterman, BLOSUM62, KMP Demo card

Multiple Sequence Alignment

Progressive MSA (ClustalW-style). Align 5+ sequences, view coloured alignment, compute conservation scores.

Tools: Needleman-Wunsch, ClustalW, Pyodide Demo card

Phylogenetic Trees

Neighbor-Joining + Jukes-Cantor distances. Visualise the tree, bootstrap support, branch lengths.

Tools: NJ, JC distance, tree SVG Live demo

3D Structure Viewer

Three.js viewer for PDB structures. Drag to rotate, scroll to zoom. Download PDB as Blob.

Tools: Three.js, PDB parser, OrbitControls Coming soon

RNA-seq pipeline

Differential expression analysis. Count matrix → DESeq2-style → volcano plot. Pure client-side via Pyodide.

Tools: Pyodide, numpy, matplotlib Coming soon

Genome browser

Interactive genome track viewer. BED/GFF parsing, gene tracks, coverage plots.

Tools: Pyodide, pysam, IGV-style
