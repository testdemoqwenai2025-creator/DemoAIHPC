# LSTM cell at time t:
# f_t = σ(W_f · [h_{t-1}, x_t] + b_f)   (forget gate)
# i_t = σ(W_i · [h_{t-1}, x_t] + b_i)   (input gate)
# g_t = tanh(W_g · [h_{t-1}, x_t] + b_g) (candidate)
# c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t       (cell state — additive!)
# o_t = σ(W_o · [h_{t-1}, x_t] + b_o)   (output gate)
# h_t = o_t ⊙ tanh(c_t)                 (hidden state)
import numpy as np

class LSTMCell:
    def __init__(self, input_dim, hidden_dim):
        s = 1.0 / np.sqrt(hidden_dim)
        # Combined weights for all 4 gates (f, i, g, o)
        self.W = np.random.randn(4 * hidden_dim, input_dim + hidden_dim) * s
        self.b = np.zeros(4 * hidden_dim)
        self.hidden_dim = hidden_dim

    def step(self, x, h_prev, c_prev):
        xh = np.concatenate([x, h_prev])
        gates = np.split(self.W @ xh + self.b, 4)
        f = 1.0 / (1 + np.exp(-gates[0]))  # σ (forget)
        i = 1.0 / (1 + np.exp(-gates[1]))  # σ (input)
        g = np.tanh(gates[2])              # tanh (candidate)
        o = 1.0 / (1 + np.exp(-gates[3]))  # σ (output)
        c = f * c_prev + i * g             # cell state (additive)
        h = o * np.tanh(c)                 # hidden state
        return h, c

# Example
np.random.seed(0)
lstm = LSTMCell(input_dim=3, hidden_dim=4)
x = np.array([0.5, -0.3, 0.8])
h_prev = np.zeros(4); c_prev = np.zeros(4)
h, c = lstm.step(x, h_prev, c_prev)
print('h:', h)
print('c:', c)

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:long-sequence tasks where the model needs to remember information from 100+ steps back (machine translation, speech recognition, time-series with weekly/seasonal patterns), any task that benefits from explicit memory cell + gating, sequence-to-sequence models with attention (encoder-decoder LSTMs dominated NMT before 2017).
AVOID WHEN:you have massive datasets and parallel hardware (use Transformer — LSTMs can't parallelise across time, training is 5-10× slower), the sequence length is short and fixed (use 1D CNN — faster and similar quality), you need to inspect attention weights for debugging (LSTM gates are less interpretable than attention maps).
WHY:LSTMs solved the vanishing gradient problem by using an additive cell state update (c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t) instead of multiplicative. When the forget gate is near 1, gradients flow back through time unimpeded. This single architectural change unlocked sequence-to-sequence translation and speech recognition for a decade (1997-2017) until Transformers took over.
