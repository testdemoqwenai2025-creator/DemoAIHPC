Dropout

Randomly zero out p fraction of activations during training. Prevents co-adaptation — forces the network to be redundant. Probability p is the dropout rate.

# p → dropout rate (typically 0.1-0.5)
# Inverted scaling: divide by (1-p) to maintain expected value
import numpy as np

def dropout(x, p=0.3, training=True):
    if not training: return x
    mask = (np.random.rand(*x.shape) > p) / (1 - p)
    return x * mask
