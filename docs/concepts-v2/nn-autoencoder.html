z = f_enc(x) x̂ = g_dec(z) L = ‖x − x̂‖²
# Encoder: z = f_enc(x)   (x ∈ R^D, z ∈ R^d, d << D)
# Decoder: x_hat = g_dec(z)
# Reconstruction loss: L = ||x - x_hat||²  (MSE)
# Denoising AE: train on noisy x, target clean x
import numpy as np

class Autoencoder:
    def __init__(self, input_dim, latent_dim):
        # Encoder: input_dim → latent_dim
        self.W_enc = np.random.randn(latent_dim, input_dim) * 0.1
        self.b_enc = np.zeros(latent_dim)
        # Decoder: latent_dim → input_dim
        self.W_dec = np.random.randn(input_dim, latent_dim) * 0.1
        self.b_dec = np.zeros(input_dim)

    def encode(self, x):
        return np.tanh(self.W_enc @ x + self.b_enc)

    def decode(self, z):
        return self.W_dec @ z + self.b_dec

    def forward(self, x):
        z = self.encode(x)
        x_hat = self.decode(z)
        return x_hat, z

    def loss(self, x):
        x_hat, _ = self.forward(x)
        return np.mean((x - x_hat) ** 2)

# Example: compress 8-dim input to 3-dim latent
np.random.seed(0)
ae = Autoencoder(input_dim=8, latent_dim=3)
x = np.random.randn(8)
x_hat, z = ae.forward(x)
print(f'Input: {x.shape}, Latent: {z.shape}, Recon: {x_hat.shape}')
print(f'Recon MSE: {ae.loss(x):.4f}')

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:dimensionality reduction (PCA alternative when data has non-linear structure), denoising (train on noisy inputs to recover clean outputs), anomaly detection (anomalies have high reconstruction error), feature extraction for downstream supervised learning, pretraining for deeper models (learn useful features on unlabelled data, then fine-tune with labels).
AVOID WHEN:you need to generate new samples (use VAE/GAN/Diffusion — vanilla AE's latent space is non-structured, interpolation produces garbage), you need interpretable latent factors (use VAE with disentanglement loss), the data is small and you don't have enough to train both encoder and decoder.
WHY:the autoencoder's self-supervised objective (reconstruct input) requires no labels — every dataset is a training set. This makes AEs ideal for pretraining when labels are scarce. But the latent space is poorly structured: two nearby latent codes can produce very different reconstructions, so you can't sample new points by interpolating. VAEs and GANs fix this with explicit generative objectives.
