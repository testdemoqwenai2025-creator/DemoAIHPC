min_G max_D E[log D(x)] + E[log(1 − D(G(z)))]
# G: Generator  z (noise) → fake sample
# D: Discriminator  sample → P(real)
# Minimax objective:
#   min_G max_D  V(D, G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]
# D wants to maximise (correctly classify real vs fake)
# G wants to minimise (fool D into calling fakes real)
import numpy as np

class GAN:
    def __init__(self, noise_dim, data_dim, hidden_dim=32):
        s = 0.1
        # Generator: noise → data
        self.G_W1 = np.random.randn(hidden_dim, noise_dim) * s
        self.G_b1 = np.zeros(hidden_dim)
        self.G_W2 = np.random.randn(data_dim, hidden_dim) * s
        self.G_b2 = np.zeros(data_dim)
        # Discriminator: data → probability
        self.D_W1 = np.random.randn(hidden_dim, data_dim) * s
        self.D_b1 = np.zeros(hidden_dim)
        self.D_W2 = np.random.randn(1, hidden_dim) * s
        self.D_b2 = np.zeros(1)

    def generate(self, z):
        h = np.tanh(self.G_W1 @ z + self.G_b1)
        return np.tanh(self.G_W2 @ h + self.G_b2)

    def discriminate(self, x):
        h = np.tanh(self.D_W1 @ x + self.D_b1)
        return 1.0 / (1 + np.exp(-(self.D_W2 @ h + self.D_b2)))

    def d_loss(self, real_x, fake_x):
        return -(np.log(self.discriminate(real_x) + 1e-8) +
                 np.log(1 - self.discriminate(fake_x) + 1e-8))

    def g_loss(self, fake_x):
        return -np.log(self.discriminate(fake_x) + 1e-8)

# Example
np.random.seed(0)
gan = GAN(noise_dim=4, data_dim=2)
z = np.random.randn(4)
fake = gan.generate(z)
print(f'Generated: {fake}')
print(f'D(fake) = {gan.discriminate(fake)[0]:.4f}')

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:photorealistic image generation (StyleGAN for faces, BigGAN for ImageNet classes), image-to-image translation (CycleGAN — horses ↔ zebras, photos → paintings), super-resolution (ESRGAN), text-to-image before Diffusion (StackGAN, AttnGAN), domain adaptation (learn mapping between unpaired domains).
AVOID WHEN:you need stable, reproducible training (GANs are notoriously mode-collapse-prone — use Diffusion for production image generation), you need likelihood evaluation (GAN has no explicit density — use VAE/Normalising Flow), you need diversity (GANs collapse to a few modes), your data is 1D/tabular (VAE or Diffusion work better).
WHY:GAN's minimax training is a double-edged sword — it produces the sharpest samples of any generative model (the discriminator forces the generator to be photorealistic), but the same adversarial dynamic causes mode collapse and training instability. WGAN, StyleGAN-2, and Diffusion all emerged to fix these issues. By 2024, Diffusion Models dominate photorealistic generation; GANs remain useful for fast inference and for cycle-consistent domain transfer.
