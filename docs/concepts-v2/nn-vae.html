Variational Autoencoder (VAE)

L = E_q[log p(x|z)] − KL(q(z|x) ‖ p(z))
# Encoder outputs (μ, σ²) instead of point estimate:
# μ, log σ² = f_enc(x)
# Sample: z = μ + σ · ε  where ε ~ N(0, I)  (reparametrisation trick)
# Decoder: x_hat = g_dec(z)
# Loss = reconstruction (BCE/MSE) + KL(q(z|x) || N(0, I))
# KL for Gaussian: 0.5 * Σ(μ² + σ² - log σ² - 1)
import numpy as np

class VAE:
    def __init__(self, input_dim, latent_dim):
        # Encoder: input_dim → (mu, log_var), each latent_dim
        self.W_enc = np.random.randn(2 * latent_dim, input_dim) * 0.1
        self.b_enc = np.zeros(2 * latent_dim)
        # Decoder: latent_dim → input_dim
        self.W_dec = np.random.randn(input_dim, latent_dim) * 0.1
        self.b_dec = np.zeros(input_dim)
        self.latent_dim = latent_dim

    def encode(self, x):
        h = self.W_enc @ x + self.b_enc
        mu = h[:self.latent_dim]
        log_var = h[self.latent_dim:]
        return mu, log_var

    def reparameterise(self, mu, log_var):
        # z = μ + σ · ε  (backprop-friendly sampling)
        eps = np.random.randn(*mu.shape)
        return mu + np.exp(0.5 * log_var) * eps

    def decode(self, z):
        return 1.0 / (1 + np.exp(-(self.W_dec @ z + self.b_dec)))

    def loss(self, x):
        mu, log_var = self.encode(x)
        z = self.reparameterise(mu, log_var)
        x_hat = self.decode(z)
        bce = -np.sum(x * np.log(x_hat + 1e-8) + (1 - x) * np.log(1 - x_hat + 1e-8))
        kl = 0.5 * np.sum(mu ** 2 + np.exp(log_var) - log_var - 1)
        return bce + kl

# Example
np.random.seed(0)
vae = VAE(input_dim=8, latent_dim=3)
x = np.array([1, 0, 1, 0, 1, 0, 1, 0], dtype=float)
print(f'Loss: {vae.loss(x):.4f}')

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:controlled generation (interpolate smoothly in latent space — face morphing, music transitions), semi-supervised learning (use latent code as features), anomaly detection (low-likelihood regions = anomalies), data augmentation (generate plausible variants of rare classes), learning disentangled representations (with β-VAE variants).
AVOID WHEN:you need photorealistic high-resolution samples (GAN and Diffusion both outperform VAE on image quality — VAE samples are blurry because the Gaussian likelihood smooths high frequencies), you need fast sampling (VAE is fast but GAN/Diffusion give better quality), you have small data and want sharp outputs.
WHY:VAE adds two things over vanilla autoencoders: (1) a Gaussian prior on the latent space — sampling z ~ N(0, I) gives valid new samples, (2) a probabilistic decoder — outputs are distributions, not points. The KL term in the loss forces the learned posterior toward the prior, organising the latent space. This is what makes VAE a generative model and AE merely a feature extractor.
