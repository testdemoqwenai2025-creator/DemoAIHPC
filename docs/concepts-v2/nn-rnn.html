💻 Math → Code — how symbols become variables

h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b)
# At each time step t:
# h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b)
# y_t = W_hy · h_t + b_y
# W_hh → hidden-to-hidden weights (shared across all t)
# W_xh → input-to-hidden weights (shared across all t)
import numpy as np

class RNN:
    def __init__(self, input_dim, hidden_dim, output_dim):
        scale = 1.0 / np.sqrt(hidden_dim)
        self.W_xh = np.random.randn(hidden_dim, input_dim) * scale
        self.W_hh = np.random.randn(hidden_dim, hidden_dim) * scale
        self.W_hy = np.random.randn(output_dim, hidden_dim) * scale
        self.h = np.zeros(hidden_dim)  # initial hidden state

    def step(self, x):
        # h_t = tanh(W_hh · h_{t-1} + W_xh · x_t)
        self.h = np.tanh(self.W_hh @ self.h + self.W_xh @ x)
        y = self.W_hy @ self.h
        return y

    def forward(self, sequence):
        outputs = []
        for x in sequence:
            outputs.append(self.step(x))
        return outputs

# Example: process a 5-step sequence with 3-dim input
np.random.seed(0)
rnn = RNN(input_dim=3, hidden_dim=4, output_dim=2)
seq = [np.random.randn(3) for _ in range(5)]
print(rnn.forward(seq)[-1])  # final output (2-dim)

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:short sequences (<50 time steps), small datasets where LSTM/Transformer would overfit, real-time low-latency streaming, character-level language models (RNN can still produce charming toy demos), simple time-series prediction.
AVOID WHEN:long sequences (>50 steps — vanishing gradients make RNN forget early inputs; use LSTM/GRU/Transformer), machine translation quality matters (use Transformer), you need parallel training (RNN is sequential — can't parallelise across time), you need to inspect attention to debug (use attention-based model).
WHY:vanilla RNNs suffer from vanishing/exploding gradients because backpropagation through time multiplies the same recurrent matrix many times. Eigenvalues <1 → vanish, >1 → explode. LSTMs/GRUs solve this with gating; Transformers sidestep it entirely by removing recurrence. Vanilla RNN is now mostly of pedagogical interest — use it to understand the lineage of modern sequence models.
