AMKD — Adaptive Multimodal Knowledge Distillation

A multimodal teacher (genomic + pathology) trains a unimodal student (pathology-only at inference) for cancer survival prediction. Three loss components orchestrate the distillation: L_KD transfers knowledge from teacher to student, L_ARR (Adaptive Redundancy Reduction) prunes redundant features between modalities so the student learns complementary information, and L_SURV supervises both models on the survival task. Validated on TCGA cancer cohorts. Inspired by Heather's LinkedIn post →

📐 Mathematical formulation

Stage 1 — Teacher forward (multi-modal):
z_g = E_g(x_g) ∈ ℝᵈ ; z_p = E_p(x_p) ∈ ℝᵈ
Two encoders map genomic features (x_g: gene expression, mutations, CNVs) and pathology features (x_p: histology image embeddings from a pretrained encoder like UNI or CONCH) into a shared d-dimensional latent space. The key design choice is shared dimensionality — both modalities must live in the same ℝᵈ for cross-attention to be meaningful.
Stage 2 — Four cross-attention modules:
A_XY = softmax(Q_X · K_Yᵀ / √d_k) · V_Y where X,Y ∈ {g, p}
z*_{g} = z_g + A_{gg}(z_g) + A_{gp}(z_p) (Gene attends to Gene and Path)
z*_{p} = z_p + A_{pp}(z_p) + A_{pg}(z_g) (Path attends to Path and Gene)
Four attention matrices: Gene×Gene (which genes co-regulate), Gene×Path (which pathology features each gene depends on), Path×Path (which pathology regions are spatially related), Path×Gene (which genes each pathology region depends on). The dual cross-attention is what makes the teacher truly "multi-modal" rather than just early-fusion.
Stage 3 — Survival head + L_SURV:
ŝ_T = σ(w_T · z_T + b_T) (teacher's survival probability at time t)
L_SURV = −Σᵢ [δᵢ · log(1 − ŝ(tᵢ|xᵢ)) + (1 − δᵢ) · log(ŝ(tᵢ|xᵢ))]
Discrete-time survival loss (Negralle-Côte et al.). δᵢ = 1 if patient i died by time tᵢ (event observed), δᵢ = 0 if censored (still alive at last follow-up). The loss penalises both: predicting death when patient lived (1−δ), and predicting survival when patient died (δ).
Stage 4 — Knowledge distillation loss L_KD:
L_KD = ‖z_T − proj(z_S)‖² + λ · KL(p_T ‖ p_S)
Two-part distillation: (a) feature-level — student's latent z_S is projected to teacher's dimension and matched via MSE; (b) prediction-level — softmax distributions of survival predictions are matched via KL divergence. The feature-level term transfers "how to represent pathology", the prediction-level term transfers "what to predict from it".
Stage 5 — Adaptive Redundancy Reduction (L_ARR):
L_ARR = −0.5 · log det(I + (1/N) · Z_S · Z_Sᵀ) (information bottleneck)
Inspired by the Information Bottleneck (Tishby 1999), this term maximises the entropy of the student's representations while compressing redundancy. It works like a soft-decorrelator: features that are linearly dependent on others get suppressed. The key insight: in the multimodal teacher, genomic + pathology features are often redundant (a gene's expression often correlates with the histology's morphology). L_ARR forces the student to keep only the complementary (non-redundant) information — which is what makes it generalise.
Total loss:
L_total = L_SURV(T) + α · L_KD + β · L_ARR + γ · L_SURV(S)
α, β, γ are hyperparameters tuned via validation. Typical values: α=1.0 (KD weight), β=0.1 (ARR weight — too high collapses the representation), γ=0.5 (student supervised less aggressively than teacher to leave room for KD). The teacher's L_SURV is full-weight (1.0) so it learns good multimodal representations; the student is regularised.

💻 Runnable code

PyTorch-style implementation

# AMKD — Adaptive Multimodal Knowledge Distillation for cancer survival
# Math→Code mapping:
#   x_g → genomic_features  x_p → pathology_features
#   E_g, E_p → encoders (genomic / pathology)
#   A_XY → cross-attention modules
#   z_T → teacher latent  z_S → student latent
#   L_SURV → survival loss  L_KD → knowledge distillation
#   L_ARR → adaptive redundancy reduction
import torch
import torch.nn as nn
import torch.nn.functional as F

class CrossAttention(nn.Module):
    def __init__(self, d=256, n_heads=4):
        super().__init__()
        self.q = nn.Linear(d, d)
        self.k = nn.Linear(d, d)
        self.v = nn.Linear(d, d)
        self.n_heads = n_heads

    def forward(self, X, Y):
        # A_XY = softmax(Q_X · K_Yᵀ / √d_k) · V_Y
        Q, K, V = self.q(X), self.k(Y), self.v(Y)
        attn = F.softmax(Q @ K.transpose(-2, -1) / (Q.size(-1) ** 0.5), dim=-1)
        return attn @ V

class MultimodalTeacher(nn.Module):
    def __init__(self, d_gen=1024, d_path=1024, d=256):
        super().__init__()
        self.E_g = nn.Linear(d_gen, d)   # genomic encoder
        self.E_p = nn.Linear(d_path, d)  # pathology encoder
        # 4 cross-attention modules
        self.att_gg = CrossAttention(d)  # Gene × Gene self-attn
        self.att_gp = CrossAttention(d)  # Gene × Path cross-attn
        self.att_pp = CrossAttention(d)  # Path × Path self-attn
        self.att_pg = CrossAttention(d)  # Path × Gene cross-attn
        self.surv_head = nn.Linear(d, 1)

    def forward(self, x_g, x_p):
        z_g, z_p = self.E_g(x_g), self.E_p(x_p)
        # Dual cross-attention updates
        z_g_star = z_g + self.att_gg(z_g, z_g) + self.att_gp(z_g, z_p)
        z_p_star = z_p + self.att_pp(z_p, z_p) + self.att_pg(z_p, z_g)
        z_T = torch.cat([z_g_star, z_p_star], dim=-1).mean(dim=-1, keepdim=True)
        return z_T, torch.sigmoid(self.surv_head(z_T))

class UnimodalStudent(nn.Module):
    def __init__(self, d_path=1024, d=256):
        super().__init__()
        self.E_p = nn.Linear(d_path, d)
        self.att_pp = CrossAttention(d)  # only Path × Path self-attn
        self.proj = nn.Linear(d, d)      # projects student's z to teacher's d
        self.surv_head = nn.Linear(d, 1)

    def forward(self, x_p):
        z_p = self.E_p(x_p)
        z_S = z_p + self.att_pp(z_p, z_p)
        return z_S, torch.sigmoid(self.surv_head(z_S))

def amkd_loss(z_T, s_T, z_S, s_S, y_time, y_event, alpha=1.0, beta=0.1, gamma=0.5):
    # L_SURV (teacher): discrete-time survival loss
    L_surv_T = -(y_event * torch.log(1 - s_T + 1e-8) +
                 (1 - y_event) * torch.log(s_T + 1e-8)).mean()

    # L_KD: feature MSE + prediction KL
    proj_S = student.proj(z_S)
    L_kd = F.mse_loss(proj_S, z_T.detach()) + 0.5 * F.kl_div(
        (s_S + 1e-8).log(), (s_T + 1e-8).log(), reduction='batchmean')

    # L_ARR: information-bottleneck-style redundancy reduction
    Z_S = proj_S - proj_S.mean(dim=0, keepdim=True)
    N = Z_S.size(0)
    cov = (Z_S @ Z_S.t()) / N + torch.eye(N, device=Z_S.device)
    L_arr = -0.5 * torch.logdet(cov)

    # L_SURV (student)
    L_surv_S = -(y_event * torch.log(1 - s_S + 1e-8) +
                 (1 - y_event) * torch.log(s_S + 1e-8)).mean()

    # L_total = L_SURV(T) + α·L_KD + β·L_ARR + γ·L_SURV(S)
    return L_surv_T + alpha * L_kd + beta * L_arr + gamma * L_surv_S, {
        'L_surv_T': L_surv_T.item(), 'L_kd': L_kd.item(),
        'L_arr': L_arr.item(), 'L_surv_S': L_surv_S.item()
    }

# === Demo: simulate TCGA-like batch ===
torch.manual_seed(0)
N, d_gen, d_path = 32, 1024, 1024
x_g = torch.randn(N, d_gen)   # gene expression + mutation + CNV features
x_p = torch.randn(N, d_path)  # pathology slide embeddings
y_time = torch.randint(1, 100, (N,)).float()  # months
y_event = (torch.rand(N) > 0.5).float()                  # 1 = died, 0 = censored

teacher = MultimodalTeacher(d_gen, d_path)
student = UnimodalStudent(d_path)
z_T, s_T = teacher(x_g, x_p)
z_S, s_S = student(x_p)
total, components = amkd_loss(z_T, s_T, z_S, s_S, y_time, y_event)
print(f"Total loss: {total:.4f}")
for k, v in components.items():
    print(f"  {k}: {v:.4f}")

🧠 Deep thoughts — when does multimodal KD beat joint training?

Strategic guidance for clinical AI researchers

USE WHENYour deployment setting has asymmetric modality availability. Training time: rich multimodal data (TCGA has both WGS + WSI). Inference time: only the cheap modality is available (pathology slides are routine; genomic sequencing is $1k+ and slow). This is the canonical TCGA → clinical-deployment setting.
USE WHENYou want a regularised student that doesn't overfit to spurious pathology features. The teacher's genomic signal acts as a "ground truth probe" — features in pathology that correlate with genomics are kept, the rest are pruned by L_ARR. This is a stronger regulariser than dropout because it's semantically grounded.
AVOID WHENBoth modalities are equally available at inference (use joint multimodal training instead — the teacher model directly). KD is overhead with no payoff if you can always run both encoders.
AVOID WHENβ (L_ARR weight) is set too high (>0.5). The information-bottleneck objective collapses the student's representations — it learns to output the identity, which is degenerate. β=0.1 is a safe default; tune down if you see representation collapse.
WHYThe key insight is that genomic and pathology modalities are partially redundant (a tumour's grade is visible in both its morphology and its mutation profile). Naive KD would have the student copy the teacher's pathology branch — but that's already what the student has. L_ARR is the secret sauce: it forces the student to keep only the complementary information from the teacher (the genomic signal that doesn't already exist in pathology), which is exactly the information that makes the student better than pathology-only training.
WHYThe four cross-attention modules aren't symmetric — Gene×Path and Path×Gene are different operations. Gene×Path tells each gene which pathology regions it corresponds to (useful for biology interpretation: "TP53 mutations → aneuploidy visible in nuclei"). Path×Gene tells each pathology region which genes are likely mutated (useful for pathologist: "this morphology suggests EGFR mutation"). The dual cross-attention is what makes the teacher a multi-modal model rather than a multi-input model.

Where adaptive multimodal KD leads

2026-27Clinical-grade pathology-only survival prediction. AMKD-trained student deployed as a CE-marked medical device. Pathologist uploads a WSI → survival probability + uncertainty in 30 seconds. No genomic sequencing required. Closes the access gap for hospitals without next-gen sequencing.
2028-30Per-patient teacher adapt. When a patient's genomic data eventually arrives (e.g., from a later biopsy), the teacher model fine-tunes the student for that specific patient. The student becomes progressively more accurate as more modalities arrive — but works from day 1 with just pathology.

Each student inherits pan-cancer biological priors via KD but specialises via L_SURV. Cancers with limited data (rare cancers) benefit most from transfer.

Distillation transfers the late-stage genomic signal to make the early-stage student predictive years earlier than current pathology AI.

🔬 Comparison with related approaches

AMKD vs other multimodal learning strategies

vs Late fusion (PORPOISE, PONET)Late fusion concatenates modality-specific predictions. AMKD trains the student to internalise the teacher's fusion logic. At inference, the student is faster (single encoder vs two) and generalises better (the KD signal acts as a regulariser).
vs Standard KD (Hinton 2015)Standard KD uses soft predictions (softmax over classes). AMKD uses both feature-level KD (latent z matched via MSE) and prediction-level KD (KL on survival distributions). The feature-level term is essential — without it, the student never learns the teacher's representation, only its output.
vs Mutual learning (Zhang et al.)Mutual learning has two peer networks teach each other. AMKD is asymmetric (teacher → student), which fits the clinical setting where the multimodal teacher is the "gold standard" and the pathology student is the "clinical deployment" model.
vs MCAT (Chen et al. 2020)MCAT introduced co-attention between genomic + pathology for survival. AMKD builds on MCAT's attention but adds the distillation pipeline — making the multimodal capability available at pathology-only inference time. Without AMKD, MCAT requires both modalities at deployment.
