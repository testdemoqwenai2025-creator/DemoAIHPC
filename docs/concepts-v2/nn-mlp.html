Multi-Layer Perceptron (MLP)

Stacked linear layers with non-linearities. The foundational architecture — every other NN is a variation.

h_l = σ(W_l · h_{l-1} + b_l) for l = 1, …, L
# Forward pass for layer l:
# h_l = σ(W_l · h_{l-1} + b_l)
# W_l → weights (out_l, in_l)
# b_l → biases (out_l,)
# σ → activation (ReLU, GELU, tanh, ...)
# Output: y = h_L
import numpy as np

class MLP:
    def __init__(self, layer_sizes, activation=np.tanh):
        # layer_sizes: e.g. [4, 8, 8, 3] → 4-input, 2-hidden, 3-output
        self.weights = []
        self.biases = []
        self.act = activation
        for i in range(len(layer_sizes) - 1):
            # He/Xavier init
            scale = np.sqrt(2.0 / layer_sizes[i])
            self.weights.append(np.random.randn(layer_sizes[i+1], layer_sizes[i]) * scale)
            self.biases.append(np.zeros(layer_sizes[i+1]))

    def forward(self, x):
        h = np.array(x, dtype=float)
        for i, (W, b) in enumerate(zip(self.weights, self.biases)):
            h = self.act(W @ h + b) if i < len(self.weights) - 1 else W @ h + b
        return h

# Example
np.random.seed(0)
mlp = MLP([4, 8, 8, 3], activation=np.tanh)
x = np.array([0.5, -0.3, 0.8, 0.1])
print(mlp.forward(x))  # 3-dim output

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:tabular data with mixed numeric/categorical features (after encoding), simple classification/regression baselines, the final classification head on top of CNN/Transformer features, control problems with small state spaces.
AVOID WHEN:images (use CNN — MLP can't exploit spatial locality), sequences/time-series (use RNN/Transformer — MLP has no notion of order), very high-dimensional inputs (parameter count explodes), problems requiring interpretability (use decision tree / GAM).
WHY:MLPs are universal approximators in theory but in practice they waste parameters learning what convolutions or attention get for free. Use them as the 'final classification head' on top of stronger feature extractors, not as the feature extractor itself.
