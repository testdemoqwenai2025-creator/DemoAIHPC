💻 Math → Code — how symbols become variables

y[i,j] = σ( Σ_k Σ_l W[k,l] · x[i+k, j+l] + b )
# 2D convolution (no padding, stride 1):
# y[i,j] = σ( Σ_{k=0}^{K-1} Σ_{l=0}^{L-1} W[k,l] · x[i+k, j+l] + b )
# W → kernel (K, L) — shared across all spatial positions
# σ → activation (ReLU standard)
import numpy as np

def conv2d(x, kernel, bias=0.0, activation=np.maximum):
    # x: (H, W) input feature map
    # kernel: (K, L) convolutional kernel
    H, W = x.shape
    K, L = kernel.shape
    out_h, out_w = H - K + 1, W - L + 1
    out = np.zeros((out_h, out_w))
    for i in range(out_h):
        for j in range(out_w):
            # Element-wise multiply + sum + bias + activation
            out[i, j] = np.sum(x[i:i+K, j:j+L] * kernel) + bias
    return np.maximum(0, out)  # ReLU activation

# Edge-detection kernel (Sobel X)
sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=float)
image = np.random.randn(8, 8)  # 8x8 'image'
print(conv2d(image, sobel_x).shape)  # (6, 6) — output smaller due to no padding

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:images (RGB, satellite, medical, microscopy), 2D/3D grid data (audio spectrograms, seismic surveys, climate grids), video frames (treat time as channel dim or use 3D conv), point cloud data after voxelisation.
AVOID WHEN:unordered set data (use PointNet or Transformer), 1D sequences with long-range dependencies (use RNN/Transformer — CNN context window is limited by kernel × depth), graph data (use GNN).
WHY:CNNs exploit two key inductive biases — locality (nearby pixels are correlated) and translation invariance (a cat is a cat regardless of position). These biases let CNNs learn visual features with 100× fewer parameters than an equivalent MLP. For small datasets, CNNs still beat attention-based architectures because of these strong priors.
