P(Y ∈ [L(X), U(X)] | X) ≥ 1 − α (with conditional coverage)
# Split conformal prediction (Vovk 2005):
# 1. Score: s_i = |y_i - ŷ(x_i)|   (non-conformity)
# 2. Quantile: q_α = ⌈(n+1)(1-α)/n⌉-th order statistic
# 3. Interval: [ŷ(x) - q_α, ŷ(x) + q_α]
# Guarantees: P(Y ∈ [L(X), U(X)]) ≥ 1 - α (marginal coverage)
#
# CoCoNet extension (conditional coverage):
# Score network s_θ(x, y) learns input-dependent non-conformity
# Calibration network adjusts scores to maintain (1-α) coverage
# Two variants: CoCoNet-ICNN (input-convex NN) + CoCoNet-Spline
import numpy as np

def split_conformal_predict(model, X_cal, y_cal, X_test, alpha=0.1):
    """Split conformal prediction — distribution-free coverage guarantee.

    Returns intervals [L, U] such that P(Y_test ∈ [L, U]) >= 1 - alpha,
    assuming (X_cal, y_cal) and (X_test, y_test) are exchangeable.
    """
    # Step 1: compute non-conformity scores on calibration set
    y_cal_pred = model.predict(X_cal)
    scores = np.abs(y_cal - y_cal_pred)  # s_i = |y_i - ŷ(x_i)|

    # Step 2: find alpha-quantile with finite-sample correction
    n = len(scores)
    # ⌈(n+1)(1-α)/n⌉-th order statistic (Vovk's correction)
    q_alpha_idx = int(np.ceil((n + 1) * (1 - alpha)))
    q_alpha_idx = min(q_alpha_idx, n)  # clamp to last index
    q_alpha = np.sort(scores)[q_alpha_idx - 1]  # 1-indexed → 0-indexed

    # Step 3: output prediction intervals
    y_test_pred = model.predict(X_test)
    lower = y_test_pred - q_alpha
    upper = y_test_pred + q_alpha
    return lower, upper, q_alpha

# Simple linear model for the demo
class LinearModel:
    def __init__(self, slope, intercept):
        self.slope, self.intercept = slope, intercept
    def predict(self, X):
        return self.slope * np.asarray(X) + self.intercept

# Example: 6 calibration points, 2 test points, 90% coverage
np.random.seed(0)
model = LinearModel(slope=2.0, intercept=1.0)
X_cal = np.array([0.5, 1.0, 1.5, 2.0, 2.5, 3.0])
y_cal = model.predict(X_cal) + np.random.randn(6) * 0.5
X_test = np.array([4.0, 5.0])

lower, upper, q = split_conformal_predict(model, X_cal, y_cal, X_test, alpha=0.1)
print(f'q_alpha (90% quantile): {q:.3f}')
print(f'Test predictions: {model.predict(X_test)}')
for i, (l, u) in enumerate(zip(lower, upper)):
    print(f'  x={X_test[i]}: [{l:.2f}, {u:.2f}]  (width={u-l:.2f})')

🧠 Deep thoughts — when (and when not) to reach for this architecture

USE WHEN:you need uncertainty quantification on regression/classification predictions with distribution-free coverage guarantees (medical risk scoring, financial VaR, autonomous-system safety bounds, scientific reproducibility), you want to wrap any pre-trained model with valid prediction intervals, you need to compare different models' uncertainty (tighter intervals at the same coverage = better model), multivariate regression where input-dependent interval widths matter (high-variance regions need wider intervals).
AVOID WHEN:you only need point predictions (conformal adds calibration overhead), real-time streaming data without periodic recalibration (calibration set must be exchangeable with test data), very small calibration sets (<30 samples — the quantile estimate is too noisy), strict adversarial settings (conformal assumes exchangeability, which an adversary can break).
WHY:CoCoNet's contribution over standard split conformal is learning the score function s_θ(x, y) CONDITIONAL on the input x. Standard split conformal gives marginal coverage (P(Y ∈ C(X)) ≥ 1-α averaged over X) but conditional coverage can be much worse for subpopulations. CoCoNet-ICNN (Input-Convex Neural Network) learns a convex score function — useful when the score should be monotonic in y. The paper's result — CoCoNet-ICNN #1 in 22/30 multivariate regression tasks for region efficiency prediction — suggests that input-conditional scores give meaningfully tighter intervals in practice, especially when the data has heteroscedastic noise (different variances for different x).
