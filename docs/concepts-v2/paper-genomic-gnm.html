Genomic GNM — Gaussian Network Analysis of Hi-C

Apply the Gaussian Network Model (GNM) — originally from protein dynamics — to chromatin 3D structure from Hi-C data. The Hi-C contact map becomes a spring network where each genomic locus is a node and each contact is a spring. Normal mode analysis reveals collective chromatin motions: slow modes correspond to large-scale domain movements (TADs, compartments), fast modes to local fluctuations. Square fluctuations predict chromatin accessibility (ATAC-seq/DNase-seq) and cross-correlations identify long-range regulatory interactions. Inspired by Banerjee et al. LinkedIn post →

📐 Mathematical formulation

Stage 1 — Hi-C contact map:
C_ij = contact frequency between loci i and j
A_ij = 1 if C_ij > threshold, 0 otherwise (adjacency matrix)
Hi-C produces a symmetric N×N matrix where N is the number of genomic bins (typically 1000–5000 at 50kb resolution). C_ij counts how often loci i and j are spatially close in 3D. Higher contact frequency → stronger physical proximity. The threshold converts the continuous contact map into a binary adjacency matrix for the network model.
Stage 2 — Kirchhoff (Laplacian) matrix:
Γ = D − A
D_ii = Σ_j A_ij (degree = total contacts for locus i)
Γ_ij = { −A_ij if i ≠ j; D_ii if i = j }
The Kirchhoff matrix Γ is the Laplacian of the contact network. It encodes the connectivity structure: diagonal = how connected each locus is, off-diagonal = negative of contact strength. Γ is the central object of GNM — its eigenvalues and eigenvectors reveal the dynamical modes of the chromatin network.
Stage 3 — Normal mode analysis:
Γ v_k = λ_k v_k (k = 0, 1, ..., N−1)
λ_0 = 0 (zero mode — rigid-body translation, v_0 = uniform)
λ_1 < λ_2 < ... < λ_{N−1} (slowest to fastest modes)
Eigenvalue decomposition of Γ gives N modes. The zero eigenvalue (λ_0 = 0) corresponds to uniform translation (all loci move together — irrelevant). The slowest non-zero modes (small λ) correspond to large-scale collective motions — entire chromatin domains moving coherently. The fastest modes (large λ) are local fluctuations — individual loci vibrating independently.
Stage 4 — Square fluctuations + cross-correlations:
⟨ΔR_i²⟩ = (k_BT / γ) Σ_{k≠0} (1/λ_k) [v_k]_i² (per-locus mobility)
⟨ΔR_i · ΔR_j⟩ = (k_BT / γ) Σ_{k≠0} (1/λ_k) [v_k]_i [v_k]_j (cross-correlation)
The square fluctuation ⟨ΔR_i²⟩ tells you how much locus i moves on average — mobile loci are more accessible (correlated with ATAC-seq/DNase-seq signal). The cross-correlation ⟨ΔR_i · ΔR_j⟩ tells you whether two loci move together (positive = correlated, negative = anti-correlated). Loci with high cross-correlation belong to the same GNM domain — a dynamical unit that often coincides with TADs.
Stage 5 — Biological mapping:
GNM domains = clusters of loci with high cross-correlation ↔ TADs
Slow modes (small λ) ↔ compartment-level motions (A/B compartments)
High ⟨ΔR_i²⟩ ↔ open chromatin (ATAC-seq/DNase-seq peaks)
High ⟨ΔR_i · ΔR_j⟩ for distant i,j ↔ long-range regulatory interactions
The GNM analysis maps directly to known biological annotations: TADs emerge as clusters of co-fluctuating loci, A/B compartments emerge from the slowest modes, chromatin accessibility is predicted by square fluctuations, and long-range enhancer-promoter interactions show up as high cross-correlations between distant loci. The key insight: chromatin dynamics, not just structure, encodes function.

💻 Runnable code

Python — GNM analysis of Hi-C data

# Genomic GNM — Gaussian Network Model analysis of Hi-C data
# Math→Code mapping:
#   C_ij → contact_matrix  (Hi-C contact map)
#   A_ij → adjacency  (thresholded binary contacts)
#   Γ → kirchhoff  (Laplacian matrix)
#   λ_k, v_k → eigenvalues, eigenvectors of Γ
#   ⟨ΔR_i²⟩ → square_fluctuations
#   ⟨ΔR_i·ΔR_j⟩ → cross_correlations
import numpy as np
from scipy.linalg import eigh

def genomic_gnm(contact_matrix, threshold=1):
    # Stage 1: Hi-C contact map → adjacency matrix
    N = contact_matrix.shape[0]
    A = (contact_matrix > threshold).astype(float)
    np.fill_diagonal(A, 0)  # no self-loops

    # Stage 2: Kirchhoff (Laplacian) matrix Γ = D − A
    D = np.diag(A.sum(axis=1))  # degree matrix
    gamma = D - A  # Γ

    # Stage 3: Normal mode analysis — eigenvalue decomposition
    eigenvalues, eigenvectors = eigh(gamma)
    # eigh returns sorted ascending: λ_0=0, λ_1, ..., λ_{N-1}
    # Skip the zero mode (k=0, rigid-body translation)
    lam = eigenvalues[1:]  # non-zero eigenvalues
    V = eigenvectors[:, 1:]  # corresponding eigenvectors

    # Stage 4: Square fluctuations + cross-correlations
    # ⟨ΔR_i²⟩ = (kBT/γ) Σ_k (1/λ_k) [v_k]_i²
    inv_lam = 1.0 / (lam + 1e-10)  # 1/λ_k (avoid div-by-zero)
    sq_fluct = np.sum(inv_lam * V**2, axis=1)  # per-locus mobility

    # ⟨ΔR_i·ΔR_j⟩ = (kBT/γ) Σ_k (1/λ_k) [v_k]_i [v_k]_j
    cross_corr = V @ np.diag(inv_lam) @ V.T  # N×N cross-correlation matrix

    # Stage 5: GNM domains = clusters of high cross-correlation
    # (simplified: use the slowest 3 modes to partition into domains)
    slow_modes = V[:, :3]  # 3 slowest non-zero modes
    # K-means on slow-mode embeddings gives domain boundaries
    from sklearn.cluster import KMeans
    n_domains = 5  # expected number of TADs
    domains = KMeans(n_clusters=n_domains, n_init=10).fit_predict(slow_modes)

    return {
        'eigenvalues': eigenvalues,
        'square_fluctuations': sq_fluct,
        'cross_correlations': cross_corr,
        'domains': domains,
        'slow_modes': slow_modes
    }

# === Example: synthetic Hi-C contact matrix (100 loci) ===
np.random.seed(42)
N = 100  # 100 genomic bins (at 50kb resolution = 5Mb region)
# Build a synthetic contact map with 3 TAD-like domains
contact = np.zeros((N, N))
for i in range(N):
    for j in range(N):
        d = abs(i - j)
        # Distance-dependent decay + TAD structure
        tad_boost = 3.0 if (i // 33) == (j // 33) else 0
        contact[i, j] = 10 * np.exp(-d / 20) + tad_boost + np.random.poisson(2)

result = genomic_gnm(contact, threshold=3)
print(f"Loci: {N}")
print(f"Eigenvalues: λ_0={result['eigenvalues'][0]:.4f} (zero mode), λ_1={result['eigenvalues'][1]:.4f}, λ_2={result['eigenvalues'][2]:.4f}")
print(f"Square fluctuations (min={result['square_fluctuations'].min():.4f}, max={result['square_fluctuations'].max():.4f})")
print(f"GNM domains: {np.unique(result['domains'], return_counts=True)}")
print(f"Cross-correlation matrix shape: {result['cross_correlations'].shape}")

🧠 Deep thoughts — when GNM reveals what Hi-C alone cannot

Strategic guidance for genomic data scientists

USE WHENYou want to go beyond static 3D structure to understand chromatin dynamics. Hi-C gives you a snapshot; GNM gives you a movie. The slow modes reveal collective motions that are invisible in the static contact map — domain-level breathing, compartment switching, and long-range coordination.
USE WHENYou want to predict chromatin accessibility without ATAC-seq/DNase-seq. The square fluctuation ⟨ΔR_i²⟩ is a physics-based predictor of accessibility — mobile loci are more accessible. This works because accessibility ≈ how much a locus moves, and GNM directly computes mobility from contact topology.
AVOID WHENYour Hi-C data is sparse (<100M reads). GNM requires a well-populated contact matrix; sparse matrices produce noisy Kirchhoff matrices with unreliable eigenvalues. Use at least 500M reads or use ICE/KR normalisation first.
AVOID WHENThe resolution is too coarse (>1Mb bins). GNM modes at coarse resolution are biologically uninterpretable — they reflect binning artefacts rather than real chromatin dynamics. Stay at ≤100kb resolution.
WHYThe key insight is that GNM borrows from protein dynamics (Bahar et al. 1997), where it's been validated for 25+ years. The chromatin is treated as an elastic network — same physics as a protein's residue network, just at a larger scale. The cross-domain transfer works because the underlying physics (spring-connected nodes, harmonic approximation) is scale-invariant. The modes reveal functional units that the static structure obscures.
WHYGNM domains often don't perfectly match TADs from insulation score or directionality index. This is by design — TADs are structural boundaries; GNM domains are dynamical boundaries. A locus can be in one TAD but dynamically coordinated with a neighbouring TAD. The mismatch is biologically informative — it reveals functional coordination across structural boundaries, which is where enhancers often act.

🚀 Futuristic possibilities

Where genomic GNM leads

2026-27Single-cell GNM. Apply GNM to single-cell Hi-C (scHi-C) to get cell-type-specific chromatin dynamics. The slow modes reveal which compartments are stable vs cell-type-specific. Cancer cells' GNM modes will differ from normal — diagnostic potential.
2028-30Time-resolved GNM. Apply GNM to time-course Hi-C (e.g., after heat shock, hormone treatment, or differentiation). Track how modes shift over time — which domains destabilise first, which compartments reorganise. Gives a temporal dimension to the "chromatin movie".
2030-33GNM-guided CRISPR. Use GNM cross-correlations to predict which distal loci are functionally connected to a target gene. Guide CRISPRi/CRISPRa to the regulatory element most dynamically coordinated with the target — even if it's 10Mb away. Non-obvious regulatory connections revealed by physics.
2033+Multi-omics GNM. Integrate Hi-C + RNA-seq + ATAC-seq + ChIP-seq into a unified network. The GNM modes explain not just chromatin dynamics but also gene expression variability — the slow modes predict which genes co-vary across cell types. A physics-based foundation for the 4D nucleome.

🔬 Comparison with related approaches

GNM vs other chromatin structure analysis methods

vs Insulation score (Crane et al. 2015)Insulation score finds TAD boundaries by sliding a window and measuring contact depletion. GNM finds dynamical domain boundaries via cross-correlation. Insulation score = structural; GNM = dynamical. They often agree but disagree at functionally interesting loci.
vs 3D structure modelling (TADbit, 3D-GNOME)3D modelling produces explicit 3D coordinates. GNM produces a mode spectrum (eigenvalues + eigenvectors). 3D models are more intuitive to visualise; GNM modes are more compact + directly give dynamics. GNM is faster (eigenvalue decomposition vs MCMC sampling).
vs ANM (Anisotropic Network Model)ANM is the 3D-vector version of GNM — each node has 3 DOF (x, y, z) instead of 1 (scalar fluctuation). ANM gives directional information (which direction does each locus move?) but is 3× more expensive. GNM is the scalar approximation — sufficient for domain identification + accessibility prediction.
vs Hi-C eigenvector decomposition (Lieberman-Aiden 2009)Lieberman-Aiden's eigenvector decomposition of the Hi-C matrix itself (not the Kirchhoff) reveals A/B compartments. GNM's Kirchhoff eigenvectors reveal dynamical modes. The compartment eigenvector from Hi-C ≈ the slowest GNM mode — they're related but not identical because the Kirchhoff normalisation (D − A) changes the mode structure.
