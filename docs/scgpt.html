scGPT — Single-Cell Foundation Model

The first single-cell foundation model. Generative Transformer pre-trained on 33M+ human cells from the CellxGene atlas. Tokenises each cell as a sequence of (gene, expression) pairs, then learns cell + gene representations via masked-language-model + generative objectives. Fine-tunes to: cell-type annotation, perturbation prediction, multi-batch integration, gene-network inference, GRN inference — often state-of-the-art on each. Available on 🤗 Hugging Face.

📐 Mathematical formulation

Stage 1 — Cell tokenisation: each cell = sequence of (gene_id, expression) pairs
Cell C = [(g₁, e₁), (g₂, e₂), ..., (gₙ, eₙ)] where gᵢ ∈ {0, ..., ~60K genes} is a token ID, eᵢ ∈ ℝ is the expression value (binned). Genes are sorted by expression (highest first) — this order carries signal.
Stage 2 — Embeddings: each token has 3 embedding components xᵢ = E_gene(gᵢ) + E_expr(eᵢ) + E_pos(i)
Gene embedding (semantic identity) + expression-value embedding (the cell-state signal) + position embedding (the rank-order signal). Three additive components per token, like BERT's segment + position embeddings.
Stage 3 — Transformer encoder forward: hₗ = TransformerLayerₗ(hₗ₋₁) = LN(hₗ₋₁ + MHSA(hₗ₋₁)) then LN(+MLP)
Standard post-LN Transformer with multi-head self-attention. Attention is bidirectional — every gene attends to every other gene in the cell, learning regulatory co-expression patterns.
Stage 4 — Pre-training objective: masked expression prediction L = −Σ_{masked tokens} log p(eᵢ | hᵢ)
~15% of (gene, expression) tokens are masked; the model predicts the missing expression values from the visible ones. This forces it to learn cell-type identity + gene-gene regulatory structure — analogous to BERT's MLM.
Stage 5 — Fine-tuning head: p(cell_type | C) = softmax(MLP_cls(h_L[CLS]))
A [CLS] token is prepended to each cell's sequence; its final-layer representation is fed to a classification head. Other tasks (perturbation prediction, batch correction) use the same backbone with different heads.

💻 Math → Code — runnable Python implementation

scGPT minimal reference (~70 lines, numpy)

# Stage 1: Cell tokenisation — (gene_id, expression) pairs
import numpy as np

def tokenise_cell(gene_ids, expressions, top_k=128):
    # Sort by expression (descending) — rank-order is the signal
    # Then keep top_k most-expressed genes as the cell's "sentence"
    order = np.argsort(expressions)[::-1][:top_k]
    return gene_ids[order], expressions[order]

# Stage 2: Embeddings — gene + expression + position
class scGPTEmbeddings:
    def __init__(self, n_genes, n_expr_bins=51, d_model=512):
        self.gene_emb = np.random.randn(n_genes, d_model) * 0.02
        self.expr_emb = np.random.randn(n_expr_bins, d_model) * 0.02
        self.pos_emb = np.random.randn(512, d_model) * 0.02  # max 512 tokens

    def __call__(self, gene_ids, expr_bins, positions):
        return (self.gene_emb[gene_ids]
              + self.expr_emb[expr_bins]
              + self.pos_emb[positions])

# Stage 3: Transformer encoder
def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x); return e / e.sum(axis=axis, keepdims=True)

def transformer_layer(h, W_q, W_k, W_v, W_o, W_ff, b_ff):
    Q, K, V = h @ W_q, h @ W_k, h @ W_v
    d_k = Q.shape[-1]
    attn = softmax(Q @ K.T / np.sqrt(d_k))
    h_attn = attn @ V @ W_o
    h_ff = np.maximum(0, (h + h_attn) @ W_ff + b_ff)
    return h + h_ff

# Stage 4: Masked expression prediction
def mlm_loss(h_masked, expr_target, W_head):
    # Predict binned expression value for each masked position
    logits = h_masked @ W_head.T  # (n_masked, n_bins)
    return -np.mean(np.log(softmax(logits)[np.arange(len(expr_target)), expr_target] + 1e-10))

# Stage 5: Cell-type classification head
def classify_cell(h_cls, W_cls, b_cls):
    # h_cls = final-layer [CLS] token representation
    return softmax(h_cls @ W_cls.T + b_cls)

# === Example: tokenise a single cell, run forward pass, classify ===
np.random.seed(0)
n_genes, d_model = 10000, 128  # smaller model for demo
embed = scGPTEmbeddings(n_genes=n_genes, d_model=d_model)
gene_ids = np.random.randint(0, n_genes, size=64)
expr_bins = np.random.randint(0, 51, size=64)
positions = np.arange(64)
x = embed(gene_ids, expr_bins, positions)
print(f"Cell tokenised: shape={x.shape} (top-64 genes of cell)")

🧠 Deep thoughts — when to reach for scGPT

Strategic guidance

USE WHENsingle-cell RNA-seq analysis where you want one model that handles many tasks (cell-type annotation, batch correction, perturbation prediction, GRN inference) without training separate specialised models. Datasets with >10K cells (smaller → pretraining signal weak). Cross-species or cross-tissue transfer (scGPT embeddings carry cell-type signal that transfers). In-silico perturbation experiments ("what happens if I knock out gene X in cell type Y?").
AVOID WHENyour data is bulk RNA-seq (no single-cell resolution → no cell-state tokenisation). Spatial transcriptomics with rich spatial context (use spatial-specific models like Spateo / GraphST). Very small datasets (<1K cells) — pretraining foundation models only help when fine-tuning data is also reasonable. Real-time inference for live-cell microscopy (scGPT is ~1s per cell on GPU).
WHYscGPT's key insight is treating each cell as a "sentence" of (gene, expression) tokens, sorted by rank. This means the model learns cell identity from the order of expressed genes, not just their absolute values — which makes embeddings transferable across labs with different sequencing depths + chemistries. The masked-expression pretraining objective forces the model to learn gene-gene regulatory relationships (similar to how BERT learns word-word semantics from masked tokens).

🔬 Comparison with related approaches

scGPT vs other single-cell models

vs GeneformerBoth are Transformer foundation models for single-cell data. scGPT uses (gene_id, expression) token pairs + masked expression prediction; Geneformer uses ranked-gene tokens + masked gene prediction. scGPT preserves absolute expression magnitudes (more accurate for fine-grained cell-state distinction); Geneformer's rank-based tokens are more robust to sequencing-depth variation. Empirically: scGPT wins on perturbation prediction, Geneformer wins on cell-state transfer across species.
vs Seurat / ScanpyThose are analysis toolkits, not models — they implement PCA, UMAP, clustering, marker-gene tests. scGPT is a learned model that can be embedded inside Seurat/Scanpy pipelines. The two are complementary: scGPT produces cell + gene embeddings; Scanpy visualises them via UMAP, clusters them via Leiden, etc.
vs BOLEROBOLERO predicts ATAC from DNA sequence per cell type; scGPT predicts gene expression per cell. They operate at different layers of the central dogma (BOLERO = regulatory DNA → chromatin, scGPT = chromatin → RNA). Compose: BOLERO predicts which regions are accessible in cell type X → scGPT predicts which accessible genes are expressed → both together give a complete regulatory model.
vs scVI / totalVIVariational autoencoders for single-cell — small (1M params), fast, but specialised: scVI does batch integration, totalVI does multi-omics. scGPT is a general foundation model that subsumes both tasks once fine-tuned. Tradeoff: scGPT is 100× slower to fine-tune than scVI, but transfers across tasks where scVI is task-specific.
