Geneformer — Transcriptome Foundation Model

A Transformer pretrained on Genecorpus-30M — 30 million human single-cell transcriptomes from the CELLxGENE corpus. Each cell becomes a "sentence" of ranked gene tokens (genes sorted by expression, no magnitudes) — tokenisation that makes the model robust to sequencing-depth variation. Transfer-learns to: in-silico perturbation (predict what happens when you knock out any gene), cell-state classification, gene-network inference, disease classification. Available on 🤗 Hugging Face.

📐 Mathematical formulation

Stage 1 — Rank-based tokenisation: sort genes by expression (descending) → take top-K
Cell C = [g_(1), g_(2), ..., g_(K)] where g_(i) is the gene with i-th highest expression. No magnitudes — just the rank order. Typical K = 2048 (captures >95% of total UMIs in most cells).
Stage 2 — Token embeddings: xᵢ = E_gene(g_(i)) + E_pos(i)
Two additive components per token: gene identity embedding + position embedding (the rank-order signal). Note: no expression-value embedding — magnitudes are discarded.
Stage 3 — Transformer encoder forward: hₗ = PostLN(MHSA(PostLN(hₗ₋₁)) + MLP)
Standard post-LN Transformer. The model learns gene-gene regulatory patterns from co-occurrence in ranked order (similar to how BERT learns word semantics from co-occurrence).
Stage 4 — Masked gene prediction (MLM): L = −Σ_{masked tokens} log p(g_(i) | hᵢ)
~15% of gene tokens are masked; model predicts which gene belongs at that position. Forces the model to learn cell-type-specific gene-gene co-occurrence patterns. The ranking structure means the model is invariant to absolute counts (robust to depth).
Stage 5 — In-silico perturbation: Δ COS(h_gene_removed) = COS(h_full) − COS(h_gene_removed)
For any gene in any cell, Geneformer can compute the "shift in cell-state embedding" caused by removing that gene — i.e. the gene's importance to that cell's identity. This is the paper's headline capability: in-silico CRISPR at scale.

💻 Math → Code — runnable Python implementation

Geneformer minimal reference (~60 lines, numpy)

# Stage 1: Rank-based tokenisation
import numpy as np

def tokenise_cell(gene_ids, expressions, top_k=2048):
    # Sort genes by expression (descending) → take top-K
    # Magnitudes are DISCARDED — only rank order is kept
    order = np.argsort(expressions)[::-1][:top_k]
    return gene_ids[order]  # just gene IDs in ranked order

# Stage 2: Token embeddings (gene + position, NO expression)
class GeneformerEmbeddings:
    def __init__(self, n_genes, d_model=512, max_len=2048):
        self.gene_emb = np.random.randn(n_genes, d_model) * 0.02
        self.pos_emb = np.random.randn(max_len, d_model) * 0.02

    def __call__(self, gene_tokens, positions):
        return self.gene_emb[gene_tokens] + self.pos_emb[positions]

# Stage 3: Transformer encoder
def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x); return e / e.sum(axis=axis, keepdims=True)

def transformer_layer(h, W_q, W_k, W_v, W_o, W_ff, b_ff):
    Q, K, V = h @ W_q, h @ W_k, h @ W_v
    d_k = Q.shape[-1]
    attn = softmax(Q @ K.T / np.sqrt(d_k))
    h_attn = attn @ V @ W_o
    h_ff = np.maximum(0, (h + h_attn) @ W_ff + b_ff)
    return h + h_ff

# Stage 4: MLM loss (predict masked gene)
def mlm_loss(h_masked, gene_target, W_head):
    logits = h_masked @ W_head.T
    return -np.mean(np.log(softmax(logits)[np.arange(len(gene_target)), gene_target] + 1e-10))

# Stage 5: In-silico perturbation — compute "COS shift" when gene is removed
def in_silico_perturb(model, cell_tokens, gene_to_remove):
    h_full = model.encode(cell_tokens)
    # Remove all occurrences of the target gene from the token sequence
    filtered = cell_tokens[cell_tokens != gene_to_remove]
    h_filtered = model.encode(filtered)
    # Cosine shift = how much the cell-state embedding moves
    cos = np.dot(h_full.mean(0), h_filtered.mean(0)) / (
        np.linalg.norm(h_full.mean(0)) * np.linalg.norm(h_filtered.mean(0)) + 1e-8)
    return 1.0 - cos  # ΔCOS — higher = more important gene

# === Example: tokenise a single cell ===
np.random.seed(0)
n_genes, d_model = 10000, 128
embed = GeneformerEmbeddings(n_genes=n_genes, d_model=d_model)
gene_ids = np.random.randint(0, n_genes, size=500)
expr = np.random.exponential(size=500)  # raw UMI counts
tokens = tokenise_cell(gene_ids, expr, top_k=64)  # top-64 most-expressed genes
x = embed(tokens, np.arange(64))
print(f"Cell tokenised: {len(tokens)} genes (ranked), shape={x.shape}")

🧠 Deep thoughts — when to reach for Geneformer

Strategic guidance

USE WHENIn-silico perturbation (the killer feature) — predict the effect of knocking out any gene in any cell type without wet-lab work. Datasets with cross-species / cross-chemistry transfer (rank-based tokens are depth-invariant). Gene-network inference (co-attention patterns reveal regulatory relationships). Disease classification from small fine-tuning sets.
AVOID WHENyou need absolute expression magnitudes (Geneformer discards them — use scGPT instead). Multi-omics (RNA + ATAC + protein) — Geneformer is RNA-only. Real-time analysis (model is ~2 GB, slow on CPU). Small fine-tuning datasets with rich feature metadata — specialised models can win.
WHYGeneformer's key innovation is the rank-based tokenisation. By discarding magnitudes and keeping only the order of expressed genes, the model becomes invariant to sequencing depth, chemistry, and platform. This is huge for cross-study transfer (a cell sequenced with 10x 3' v3 looks the same as one sequenced with Smart-seq2). The downside is that fine-grained quantitative predictions (exact fold-changes) are impossible — only rank-based signals.

🚀 Futuristic possibilities

Speculative but grounded

2025-26Universal in-silico CRISPR. Geneformer-100M cells covering all human cell types + developmental stages — perturbation predictions for any (gene, cell-type) pair become accurate enough to skip wet-lab validation for screening.
2027-29Gene-therapy target discovery. Mine Geneformer's perturbation predictions for disease-specific cell types — find genes that, when knocked out, push a disease cell back to a healthy state. Drug discovery pipelines converge on these targets.
2030+Patient-specific transcriptome modelling. Sequence a patient's cells → load into Geneformer → predict personalised perturbation outcomes → design therapy. First widely deployed personalised cell-state model in oncology.

🔬 Comparison with related approaches

Geneformer vs other models

vs scGPTBoth are single-cell foundation models. scGPT preserves expression magnitudes (better for fine-grained cell-state distinction); Geneformer uses rank-based tokens (better for cross-platform / cross-chemistry transfer). scGPT wins on perturbation prediction accuracy; Geneformer wins on transfer across labs with different sequencing platforms.
vs BOLEROBOLERO is DNA → ATAC (one level of the central dogma); Geneformer is RNA → cell-state (another level). Compose them: BOLERO predicts which regions are accessible → Geneformer predicts which genes are expressed → both together give a complete model from DNA to phenotype.
vs scVI / totalVIVAEs specialised for batch integration (scVI) or multi-omics (totalVI). Geneformer is a general foundation model — fine-tune once, transfer across tasks. scVI is faster but task-specific.
