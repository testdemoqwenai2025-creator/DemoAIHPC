AlphaFold 3 — Biomolecular Structure Prediction

Extends AlphaFold 2 from proteins-only to full biomolecular complexes: proteins + DNA + RNA + ligands + chemical modifications + ions. The structure module is replaced with a diffusion model (vs AlphaFold 2's equivariant transformer). ~50% improvement on protein-ligand interactions vs AutoDock Vina; major gains on protein-nucleic-acid complexes. Trained on PDB. Web server at alphafoldserver.com (10 free predictions/day); commercial via Isomorphic Labs.

📐 Mathematical formulation

Stage 1 — Inputs: sequence (residues + ligands + nucleotides) + MSA + templates
Sequence S = [s₁, ..., s_L] where each sᵢ ∈ {20 amino acids, 4 nucleotides, ligand SMILES, ion, modification}. MSA provides evolutionary coupling; templates provide known structural priors.
Stage 2 — Single + pair representations: s ∈ ℝ^{L×d}, p ∈ ℝ^{L×L×d}
Single representation s captures per-residue features; pair representation p captures pairwise relationships (rough distance, orientation). Both initialised from MSA + sequence embeddings.
Stage 3 — Pairformer (replaces Evoformer): (s, p) → Pairformerₖ(s, p) — updates both s + p via triangle attention
48 blocks of triangle attention. Each block updates the pair representation p using row-wise + column-wise attention (treating p as a 2D grid of pairwise relations). Single representation s updated via cross-attention to p.
Stage 4 — Diffusion module (replaces AF2 structure module): x_t = √(ᾱ_t) · x_0 + √(1−ᾱ_t) · ε, ε ~ N(0, I) learn ε_θ(x_t, t, s, p) ≈ ε
Atomic positions are noised + denoised through 50 steps. The diffusion model is conditioned on s + p (the Pairformer outputs) — so the chemical context guides the denoising. This is the architectural change that enables multi-molecule complexes: the diffusion model naturally handles variable numbers of atoms, unlike AF2's fixed-point SE(3) structure module.
Stage 5 — Confidence head: pTM, pLDDT = MLP(s_final, p_final)
Predicted Template Modelling (pTM) score = expected TM-score, gives global confidence. Predicted Local Distance Difference Test (pLDDT) gives per-residue confidence. Both used to flag uncertain regions.
Stage 6 — Multi-molecule complex assembly: output = {x_protein, x_DNA, x_RNA, x_ligand, x_ions, x_modifications}
The diffusion model jointly predicts the structure of all input molecules, with implicit interface prediction (no separate docking step). This is the key capability: AF2 needed separate docking tools; AF3 handles it in one pass.

💻 Math → Code — runnable Python implementation

AlphaFold 3 minimal reference (~80 lines, numpy)

# Stage 1: Multi-molecule input encoding
import numpy as np

def encode_inputs(residues, ligand_smiles, nucleotides):
    # Concatenate residues + nucleotides + ligand tokens
    # Each token = (type, embedding_id) — type ∈ {protein, DNA, RNA, ligand}
    seq = []
    for r in residues: seq.append((0, r))  # protein residues
    for n in nucleotides: seq.append((1, n))  # nucleotides
    for l in ligand_smiles: seq.append((2, l))  # ligand tokens
    return seq

# Stage 2: Single + pair representations
def init_representations(seq, d_model=384):
    L = len(seq)
    s = np.random.randn(L, d_model) * 0.02  # single repr
    p = np.random.randn(L, L, d_model) * 0.02  # pair repr
    return s, p

# Stage 3: Pairformer block (triangle attention)
def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x); return e / e.sum(axis=axis, keepdims=True)

def triangle_attention(p, W_q, W_k, W_v, True):
    # p shape: (L, L, d). For row attn, attention over dim 1.
    Q = p @ W_q; K = p @ W_k; V = p @ W_v
    d_k = Q.shape[-1]
    attn = softmax(Q @ K.transpose(0, 2, 1) / np.sqrt(d_k), axis=-1)
    return attn @ V

def pairformer_block(s, p, W_s, W_p, W_cross):
    # Update pair via row + column triangle attention
    p_row = triangle_attention(p, *W_p)
    p_col = triangle_attention(p.transpose(1, 0, 2), *W_p).transpose(1, 0, 2)
    p_new = p + p_row + p_col
    # Update single via cross-attention to pair
    s_new = s + s @ W_cross + p_new.mean(axis=1) @ W_s
    return s_new, p_new

# Stage 4: Diffusion module
class DiffusionModule:
    def __init__(self, num_steps=50, beta_start=1e-4, beta_end=0.02):
        self.betas = np.linspace(beta_start, beta_end, num_steps)
        self.alphas = 1 - self.betas
        self.alpha_bars = np.cumprod(self.alphas)
        self.num_steps = num_steps

    def forward_noise(self, x_0, t):
        # x_t = √(ᾱ_t) · x_0 + √(1-ᾱ_t) · ε
        eps = np.random.randn(*x_0.shape)
        ab = self.alpha_bars[t]
        return np.sqrt(ab) * x_0 + np.sqrt(1 - ab) * eps, eps

    def reverse_denoise(self, x_t, t, eps_pred):
        # Reverse step — conditioned on s (single repr) + p (pair repr)
        b = self.betas[t]; a = self.alphas[t]; ab = self.alpha_bars[t]
        mean = (1 / np.sqrt(a)) * (x_t - (1 - a) / np.sqrt(1 - ab) * eps_pred)
        if t > 0:
            return mean + np.sqrt(b) * np.random.randn(*x_t.shape)
        return mean

# === Example: predict structure of a 50-residue protein + 1 ligand ===
np.random.seed(0)
residues = list(range(20)) * 2 + [5]  # 50 residues (toy)
ligands = [0]  # 1 ligand (e.g., ATP)
seq = encode_inputs(residues, ligands, [])
s, p = init_representations(seq)
print(f"Encoded: {len(seq)} tokens (residues+ligand)")
print(f"Single repr: {s.shape}, Pair repr: {p.shape}")
diff = DiffusionModule(num_steps=10)
x_0 = np.random.randn(len(seq), 3)  # 3D coords per token
x_t, eps = diff.forward_noise(x_0, t=5)
print(f"Noised coords shape: {x_t.shape} (3D per token)")

🧠 Deep thoughts — when to reach for AlphaFold 3

Strategic guidance

USE WHENPredicting multi-molecule complexes (protein-protein, protein-DNA, protein-RNA, protein-ligand). Drug discovery pipelines where you need protein-ligand binding poses (replaces AutoDock Vina + RoseTTAFold). Structural biology of large complexes (ribosomes, spliceosomes, chromatin). Designing novel proteins with specific binding interfaces. Where AlphaFold 2 failed (multi-chain complexes, disordered regions, ligand docking).
AVOID WHENyou need exact atomic coordinates (AF3 confidence is good but not perfect — pTM < 0.7 means reliable but not crystallography-grade). Real-time predictions (server is 10/day free; commercial API needed for high throughput). Protein dynamics / conformational ensembles (AF3 predicts a single static structure — use MD simulations for dynamics). Membrane proteins in lipid bilayers (AF3 doesn't model lipids).
WHYThe architectural change from AF2's SE(3)-equivariant structure module to a diffusion model is the key innovation. Diffusion naturally handles variable numbers of atoms (multi-molecule complexes) because it operates in continuous coordinate space — AF2's structure module was a fixed-iteration point-cloud network that struggled with mixed molecule types. The diffusion model also produces multiple plausible structures (via different noise seeds) — useful for disordered proteins + conformational ensembles.

🔬 Comparison with related approaches

AlphaFold 3 vs other structure predictors

vs AlphaFold 2AF2 (2021) was proteins-only with an SE(3)-equivariant structure module. AF3 (2024) handles proteins + DNA + RNA + ligands + modifications via a diffusion module. AF3 is ~50% better on protein-ligand; AF2 still slightly better on isolated monomer proteins (no diffusion overhead). Use AF2 for pure-protein tasks; AF3 for complexes.
vs RoseTTAFold All-Atom (Baker Lab)Open-source alternative. Three-track network + diffusion. Comparable accuracy on most tasks; AF3 wins on ligands. Use RFAA if you need to inspect / modify the model (open weights); use AF3 if you want best-in-class accuracy + can tolerate the closed model.
vs AutoDock VinaAutoDock Vina is a physics-based docking tool (~15 years old, 30M citations). AF3 outperforms it by ~50% on protein-ligand pose prediction. But AutoDock Vina is open-source, fast (~1 min per ligand), and free; AF3 server is 10/day free, commercial API for scale. Use AutoDock Vina for virtual screening of 100K+ ligands; AF3 for the top-10 hits.
vs DiffDockDiffDock (2022) was the first diffusion-based protein-ligand docking model. AF3's diffusion module is conceptually similar but conditioned on the Pairformer's pair representation (so it uses evolutionary + structural priors DiffDock lacks). AF3 wins by ~20% on docking accuracy.
