Dashboard · Temporal RDF Knowledge Graph

Watch the graph change over time

A temporal RDF semantic knowledge-graph UI complete with knowledge tracing and play / replay of how a given state changes over time. Context graphs (popularised alongside replayable decision traces) are a framework introduced by FoundationCapital and solved by Aktiver; this dashboard is AIHPC Advanced's open, client-side implementation of the same idea — applied to the AETHEL scientific knowledge graph. Every timestep records the decisions that added, removed, or updated RDF triples, so a viewer can scrub through time and watch the graph evolve. All client-side; no external services; no data leaves the browser.
