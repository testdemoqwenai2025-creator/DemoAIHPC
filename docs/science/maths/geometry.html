Tesseract (4D Hypercube)

A tesseract is the 4D analogue of a cube — 16 vertices, 32 edges, 24 square faces, 8 cubic cells. Watch it rotate in 4D and project to 2D. Drag to change the projection distance.

Math → Code derivation

Step 1: Define 4D vertices
V = { (±1, ±1, ±1, ±1) } → 2⁴ = 16 vertices
Each vertex is a 4-tuple where each coordinate is either +1 or −1. That's 2 choices for each of 4 dimensions = 16 vertices.
Step 2: Define edges
E = { (v₁, v₂) : v₁ and v₂ differ in exactly one coordinate }
Two vertices are connected by an edge if they differ in exactly one coordinate. 16 vertices × 4 neighbours each / 2 = 32 edges.
Step 3: 4D rotation
RXW(θ) = [[cos θ, 0, 0, −sin θ], [0, 1, 0, 0], [0, 0, 1, 0], [sin θ, 0, 0, cos θ]]
4D rotation rotates in a plane defined by two axes. We rotate in the XW, YW, and ZW planes simultaneously. This is what makes the tesseract "unfold" — it's rotating through the 4th dimension.
Step 4: 4D → 3D perspective projection
(x, y, z, w) → (x / (d − w), y / (d − w), z / (d − w))
Divide each spatial coordinate by (d − w) where d is the 4D viewing distance. Points farther in the W dimension appear closer — this is what creates the "nested cube" illusion.
Step 5: 3D → 2D perspective projection
(x', y', z') → (x' / (d' − z'), y' / (d' − z'))
A second perspective projection from 3D to 2D. The result is the 2D image you see on screen — a shadow of a shadow of a 4D object.

What you're seeing

  • The outer cube is the "near" 3D face of the tesseract; the inner cube is the "far" face.
  • The connecting edges between inner and outer cubes are the edges along the W (4th) dimension.
  • The rotation happens in 4D planes (XW, YW, ZW). As the W coordinate rotates, vertices move between the inner and outer cube — this is the 4D "unfolding" effect.
  • The projection chain is 4D → 3D → 2D. Each projection is a perspective division that distorts the shape, creating the characteristic nested-cube appearance.
