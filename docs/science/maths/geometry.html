N-D hypercube combinatorics

An N-dimensional hypercube (N-cube) has 2^N vertices and N·2^(N−1) edges. The number of k-dimensional sub-faces is given by the binomial C(N,k)·2^(N−k). The table below shows the combinatorics for dimensions 4 through 10 — observe how quickly the structure explodes.

Math → Code derivation

Step 1: Define 4D vertices
V = { (±1, ±1, ±1, ±1) } → 2⁴ = 16 vertices
Each vertex is a 4-tuple where each coordinate is either +1 or −1. That's 2 choices for each of 4 dimensions = 16 vertices.
Step 2: Define edges
E = { (v₁, v₂) : v₁ and v₂ differ in exactly one coordinate }
Two vertices are connected by an edge if they differ in exactly one coordinate. 16 vertices × 4 neighbours each / 2 = 32 edges.
Step 3: 4D rotation
RXW(θ) = [[cos θ, 0, 0, −sin θ], [0, 1, 0, 0], [0, 0, 1, 0], [sin θ, 0, 0, cos θ]]
4D rotation rotates in a plane defined by two axes. We rotate in the XW, YW, and ZW planes simultaneously. This is what makes the tesseract "unfold" — it's rotating through the 4th dimension.
Step 4: 4D → 3D perspective projection
(x, y, z, w) → (x / (d − w), y / (d − w), z / (d − w))
Divide each spatial coordinate by (d − w) where d is the 4D viewing distance. Points farther in the W dimension appear closer — this is what creates the "nested cube" illusion.
Step 5: 3D → 2D perspective projection
(x', y', z') → (x' / (d' − z'), y' / (d' − z'))
A second perspective projection from 3D to 2D. The result is the 2D image you see on screen — a shadow of a shadow of a 4D object.

N-D generalisation — the 5-step recipe for any dimension

Use the dimension slider above to explore 5D, 6D, 8D, or 10D hypercubes. The generalisation below is the recipe that works for any N.

Step 1 (N-D): Vertices — all ±1 tuples in R^N
V = { (±1, ±1, …, ±1) ∈ R^N } → |V| = 2^N
An N-cube has 2^N vertices, each a corner of the cube. For N=10: 1024 vertices. Each vertex is identified by a binary pattern: bit d selects the sign of coordinate d.
Step 2 (N-D): Edges — pairs differing in exactly one coordinate
E = { (v_i, v_j) : Hamming_distance(v_i, v_j) = 1 } → |E| = N · 2^(N-1)
Two vertices share an edge iff they differ in exactly one coordinate. Each of the N coordinates can flip (2 choices per flip), and there are 2^(N-1) pairs per flip — giving N · 2^(N-1) edges total. For N=10: 5120 edges.
Step 3 (N-D): Rotation in 2-axis planes
R_{ij}(θ) · v : v_i ← v_i cos θ − v_j sin θ, v_j ← v_i sin θ + v_j cos θ
N-D rotation happens in a plane (not around an axis). Pick two axes i, j; the rotation matrix R_ij preserves all coordinates except i and j, which transform as a 2D rotation. We rotate in N-1 planes (0, N-1), (1, N-1), …, (N-2, N-1) so the highest axis animates prominently.
Step 4 (N-D): Chain of perspective projections N → 2
(x_0, …, x_{N-1}) → project from N to N-1 → … → 3 → 2
Chain (N-2) perspective projections, each dividing by (d_k − x_k). Each step loses one dimension; the final 2D image is a "shadow of a shadow of a shadow …" (N-2 layers deep). For N=10, the image is 8 shadows deep.
Step 5 (N-D): k-faces — the combinatorial explosion
|k-faces| = C(N, k) · 2^(N-k) → N=10: 1024 verts, 5120 edges, 11520 sq faces, 15360 cubes, …
The number of k-dimensional sub-faces of an N-cube is the binomial C(N, k) × 2^(N-k) — choose k coordinates to vary, fix the others, and there are 2^(N-k) ways to fix them. Watch the combinatorics table above explode: N=10 has 1024 vertices but 5120 edges and 11520 square faces.

What you're seeing

  • The outer cube is the "near" 3D face of the tesseract; the inner cube is the "far" face.
  • The connecting edges between inner and outer cubes are the edges along the W (4th) dimension.
  • The rotation happens in 4D planes (XW, YW, ZW). As the W coordinate rotates, vertices move between the inner and outer cube — this is the 4D "unfolding" effect.
  • The projection chain is 4D → 3D → 2D. Each projection is a perspective division that distorts the shape, creating the characteristic nested-cube appearance.
