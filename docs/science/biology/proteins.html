3D Protein Viewer

Render a sample protein backbone in 3D using Three.js. Drag to rotate, scroll to zoom. The structure is a synthetic alpha-helix backbone (40 residues) generated procedurally — a placeholder for the real AlphaFold 3-style prediction model that will land in a later phase. Pure client-side; no external services.

What you're seeing

The 3D scene renders a synthetic alpha-helix backbone by default. Each green sphere is a C-alpha atom; cyan tubes are peptide bonds; amber sticks are stub side chains. Upload a real PDB file using the 📁 Upload PDB button to view any protein structure — the parser reads ATOM records, extracts C-alpha atoms for the backbone, and renders side chain atoms as amber spheres.

How it was built

  • Three.js loaded from CDN (jsDelivr mirror). No bundler — just a script tag. Pure client-side WebGL.
  • Procedural geometry — the helix is generated in JS using the standard parametric form. No external PDB file is loaded.
  • OrbitControls — drag to rotate, scroll to zoom. Standard Three.js addon.
  • Color coding — green spheres (C-α), cyan bonds (peptide), amber sticks (side chains). Matches the legend top-right.
  • Download PDB — the same procedural helix is exported as a minimal PDB file (ATOM records with x/y/z coordinates). Generated in-browser as a Blob.

What's coming next

  • Real PDB parsing — load any PDB file from user upload (no server). Parse ATOM records, render backbone + side chains + cartoon ribbon representation.
  • AlphaFold 3-style prediction — when the ML model lands (Phase 5+), this viewer will render its predicted structure with per-residue pLDDT colouring.
  • Multiple representations — cartoon (ribbon), stick, sphere, surface. Standard molecular-graphics viewer modes.
  • Pyodide + BioPython — parse PDB in Python via BioPython (loaded via Pyodide), pass geometry to Three.js.

Math → Code derivation

Step 1: Parse PDB ATOM records
for line in pdb: if line[0:4]=='ATOM': (x,y,z) = line[30:54]
PDB files list one ATOM record per atom with fixed-width columns. Columns 31-38, 39-46, 47-54 hold x, y, z in Ångström. Parse them once and store as 3D vectors.
Step 2: Identify the backbone
backbone = [a for a in atoms if a.name in ('N','CA','C','O')]
Every residue contributes four backbone atoms: N, Cα, C, O. Selecting these gives a one-atom-per-residue simplification for the cartoon ribbon.
Step 3: Torsion angles φ and ψ
φ = dihedral(Cᵢ₋₁, Nᵢ, Cαᵢ, Cᵢ), ψ = dihedral(Nᵢ, Cαᵢ, Cᵢ, Nᵢ₊₁)
Each residue's conformation is captured by two dihedral angles. Dihedral(a,b,c,d) uses the triple cross-product of (b-a),(c-b),(d-c) — six subtractions and two cross products.
Step 4: Ramachandran plot — favoured regions
P(φ, ψ) = high in α-helix / β-sheet basins, low elsewhere
Empirically, 98% of residues fall in 3 regions of (φ,ψ) space. The plot is the diagnostic for protein structure quality — outliers are geometry errors or rare conformations.
Step 5: Cartoon ribbon — spline through Cα positions
ribbon(t) = CatmullRom([Cα₀, …, Cₙ], t)
A Catmull-Rom spline interpolates the Cα positions smoothly, giving the ribbon backbone seen in molecular graphics. Cross-section orientation follows the peptide plane; the result is the iconic cartoon-rendered protein.
