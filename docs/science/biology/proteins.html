3D Protein Viewer

Render a sample protein backbone in 3D using Three.js. Drag to rotate, scroll to zoom. The structure is a synthetic alpha-helix backbone (40 residues) generated procedurally — a placeholder for the real AlphaFold 3-style prediction model that will land in a later phase. Pure client-side; no external services.

What you're seeing

The 3D scene renders a synthetic alpha-helix backbone. Each green sphere is a C-alpha atom; cyan tubes are peptide bonds connecting them; amber sticks are stub side chains pointing outward. The helix is generated procedurally using the parametric equations for an ideal α-helix: r = 2.3 Å, rise = 1.5 Å/residue, 3.6 residues/turn.

How it was built

  • Three.js loaded from CDN (jsDelivr mirror). No bundler — just a script tag. Pure client-side WebGL.
  • Procedural geometry — the helix is generated in JS using the standard parametric form. No external PDB file is loaded.
  • OrbitControls — drag to rotate, scroll to zoom. Standard Three.js addon.
  • Color coding — green spheres (C-α), cyan bonds (peptide), amber sticks (side chains). Matches the legend top-right.
  • Download PDB — the same procedural helix is exported as a minimal PDB file (ATOM records with x/y/z coordinates). Generated in-browser as a Blob.

What's coming next

  • Real PDB parsing — load any PDB file from user upload (no server). Parse ATOM records, render backbone + side chains + cartoon ribbon representation.
  • AlphaFold 3-style prediction — when the ML model lands (Phase 5+), this viewer will render its predicted structure with per-residue pLDDT colouring.
  • Multiple representations — cartoon (ribbon), stick, sphere, surface. Standard molecular-graphics viewer modes.
  • Pyodide + BioPython — parse PDB in Python via BioPython (loaded via Pyodide), pass geometry to Three.js.
