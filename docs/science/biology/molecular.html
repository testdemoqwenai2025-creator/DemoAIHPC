Molecular Biology

DNA → RNA → protein — the central dogma as a computational pipeline. Transcribe, splice, translate, fold. Below: an animated DNA double helix, the standard codon table, and the same translation routine implemented in all six platform languages.

Translate RNA → protein (polyglot)

The same translation routine in six platform languages. Toggle to compare idioms.

translate(rna) → protein 

      


      
Inputs

      
    
        
  • Sequence. DNA or RNA string over {A, C, G, T} or {A, C, G, U}.
    • 
        
  • Reading frame. 0, +1, +2 (forward); reverse-complement frames also supported.
    • 
        
  • Codon table. Standard by default; alternative nuclear / mitochondrial tables available.
    • 
      


      
Outputs

      
    
        
  • Translated protein sequence (one-letter code).
    • 
        
  • ORF coordinates (start, stop, frame).
    • 
        
  • Protein properties: MW, pI, extinction coefficient.
    • 
        
  • FASTA / GenBank download — generated in-browser.
    • 
      


      
Method

      
Translation is O(n). ORF finding is O(n) per frame. Reverse-complement is O(n). All in-browser.


      
Observability

      
    
        
  • Parse input → normalised sequence + alphabet check.
    • 
        
  • Reverse-complement (if requested).
    • 
        
  • Six-frame scan for ORFs.
    • 
        
  • Translate each ORF.
    • 
        
  • Compute protein properties.
    • 
        
  • Render plots + tables + offer FASTA / GenBank download.
