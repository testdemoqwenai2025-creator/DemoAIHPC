Recent QML research + tooling

          
    
            
  • QGNN — Quantum Graph Neural Networks (Verdon et al. 2019, arXiv:1905.10860; recent 2024 follow-ups): embed graph nodes as quantum states, apply VQC layers, measure node classification.
    • 
            
  • PennyLane (Xanadu): diff-rule-aware quantum ML library. Native support for parameter-shift, finite-diff, adjoint, and backprop on simulators.
    • 
            
  • Qiskit + Qiskit Machine Learning (IBM): VQC + QuantumKernel + QSVC. Recently merged Qiskit 1.0 primitives (Sampler + Estimator V2).
    • 
            
  • Cirq + TFQ (Google + TensorFlow Quantum): hybrid differentiable quantum circuits integrated with TensorFlow.
    • 
            
  • Barren plateaus (McClean et al. 2018, Nature Communications): for global cost functions on random parameterised circuits, gradient variance decays as ~2-n — the central NISQ challenge.
    • 
            
  • Layered ansatz strategies (Havlíček et al. 2019; Schuld et al. 2020): local cost functions + hardware-efficient ansatz mitigate (but don't eliminate) the barren-plateau problem.
    • 
            
  • Hamiltonian evolution / quantum walk GNNs (Verdon et al. 2019): the e-iHt step (where H is the graph Laplacian) implements a continuous-time quantum walk on the graph — exponentially faster mixing on certain topologies.
    •

Phase 42 · Many-Body Quantum Mechanics

        
Second quantisation · Fock states · ladder operators

        
The single-qubit Bloch sphere (Phase 37) + VQC (Phase 39) gave us single-particle quantum mechanics. Second quantisation extends this into many-body QM: particles are counted as quanta of a field, and the operators that change the count are the creation (a†) and annihilation (a) operators. The quantum harmonic oscillator is the simplest second-quantised system — the building block of quantum field theory, condensed-matter physics, and many-body quantum chemistry. Press a† to add a quantum, a to remove one.

2. Math → Code → Output (the human-eye preview)

          
This is the AIHPC pedagogy pattern: state the mathematical expression, show how it's expressed as code (with the symbol→variable annotation comments), then describe what the human eye will see when the visualisation runs.


          
          

            
📐 Mathematical expression

            

              
Wavefunction: ψn(x) = (1/√(2n n!)) · (mω/πℏ)1/4 · Hn(ξ) · e(-ξ²/2)

              
where ξ = x · √(mω/ℏ) is the dimensionless position and Hn is the n-th Hermite polynomial (H0=1, H1=2ξ, Hn+1=2ξ·Hn-2n·Hn-1).

              
Energy levels: En = (n + ½) · ℏω

              
Ladder operators:

              
a |n⟩ = √n · |n-1⟩  (annihilation — removes 1 quantum)

              
a† |n⟩ = √(n+1) · |n+1⟩  (creation — adds 1 quantum)

              
Number operator: N̂ = a†a;  N̂|n⟩ = n|n⟩  (counts quanta)

              
Commutation: [a, a†] = 1  (canonical quantisation)

            

          


          
          

            
💻 How it's expressed as code (Python)

            
# ψ_n(x) = (1/√(2^n · n!)) · H_n(ξ) · e^(-ξ²/2)
# n -> Fock state index  x -> position  H -> Hermite polynomial
# a, a† -> ladder operators (matrix-action: shift n ± 1 with √n / √(n+1)
import numpy as np
from scipy.special import hermite

def psi(n, x, hw=1.0):
    # Compute the n-th harmonic-oscillator wavefunction at position x.
    # Dimensionless: ξ = x · √(mω/ℏ) → use ξ = x with hw=1.
    # Normalisation: 1/√(2^n · n! · √π) (Gaussian integral).
    norm = 1.0 / np.sqrt(2**n * np.math.factorial(n) * np.sqrt(np.pi))
    H_n = hermite(n)              # H_n(ξ) — Hermite polynomial
    gaussian = np.exp(-x*x / 2)
    return norm * H_n(x) * gaussian

def annihilate(n):
    # a|n⟩ = √n · |n-1⟩ — returns (coefficient, new_n)
    return (np.sqrt(n), n - 1) if n > 0 else (0.0, n)

def create(n, max_n=8):
    # a†|n⟩ = √(n+1) · |n+1⟩ — returns (coefficient, new_n)
    return (np.sqrt(n + 1), n + 1) if n < max_n else (0.0, n)

Recent research + tooling

          
    
            
  • Second quantisation (Dirac 1927, Fock 1932): particles as field excitations; the foundation of QFT and condensed-matter physics.
    • 
            
  • QuTiP (Johansson et al. 2012, Comp. Phys. Comm.): Python library for open quantum systems; supports Fock basis + ladder operators natively.
    • 
            
  • PennyLane-SF (Xanadu): Strawberry Fields continuous-variable photonic backend; uses Fock basis for optical quantum computing.
    • 
            
  • IBM Qiskit (Fock basis): bosonic encodings via qutrits + qudits; emerging CV-quantum primitives in Qiskit 1.0.
    • 
            
  • Bosonic quantum codes (Albert et al. 2020, PRX Quantum): Gottesman-Kitaev-Preskill (GKP) codes for CV error correction; encode a logical qubit in a single oscillator's Fock basis.
    • 
            
  • Quantum-many-body scars (Turner et al. 2018, Nat. Phys.): special non-thermal Fock states that don't thermalise — basis of constrained quantum dynamics.
    • 
            
  • Tensor-network Fock basis (DMRG, MPS, MPO): the workhorse of condensed-matter numerics; all of MPS is just sparse Fock-basis amplitudes.
    •

Phase 45 · Continuous-Variable Quantum Optics

        
Coupled quantum oscillators — 2-mode squeezing · HOM · NOON states

        
Beyond single-oscillator Fock states (Phase 42), the next frontier is coupled oscillators — the foundation of continuous-variable (CV) quantum optics. Two modes (A + B) can be entangled via 2-mode squeezing, exhibit Hong-Ou-Mandel bunching at a beamsplitter, or form NOON states for Heisenberg-limited metrology. The viewer below renders 4 panels: mode A energy levels, mode B energy levels, joint state matrix |n_A, n_B⟩, and the time-dependent correlation ⟨N̂_A·N̂_B⟩.

        

          

          
Press Next ▶ to cycle through: (1) product state |1,0⟩ (independent), (2) 2-mode squeezed S₂(r)|0,0⟩ (entangled — both modes always have same photon count), (3) Hong-Ou-Mandel effect (2 photons bunch at beamsplitter — |1,1⟩ vanishes), (4) NOON state (|N,0⟩+|0,N⟩)/√2 (maximally entangled — Heisenberg-limited metrology). The correlation chart shows ⟨N̂_A·N̂_B⟩ oscillating as the entanglement evolves.

        

        

          Math: S₂(r) = exp[r(a†_A a†_B - a_A a_B)];   HOM: |1,1⟩ → (|2,0⟩-|0,2⟩)/√2;   NOON: (|N,0⟩+|0,N⟩)/√2 achieves N-fold phase supersensitivity Δφ = 1/N (Heisenberg limit).

          References: Hong-Ou-Mandel (1987, Phys. Rev. Lett.); Braunstein-van Loock CV quantum info (2005, Rev. Mod. Phys.); Eknstein-Reminger squeezing (1992); NOON-state metrology (Mitchell 2004).

          Math: Each gate is a 2×2 unitary matrix applied to one qubit: H = (1/√2)·[[1,1],[1,-1]], X = [[0,1],[1,0]], etc. CNOT is a 2-qubit gate: |c,t⟩ → |c, c⊕t⟩. The state |ψ⟩ evolves as each gate is applied left-to-right: |ψ_final⟩ = U_n · ... · U_2 · U_1 · |0...0⟩.

          References: Nielsen & Chuang (Quantum Computation and Quantum Information, 2010); Qiskit Textbook (IBM, 2024); Cirq (Google, 2024); PennyLane (Xanadu, 2024).
        

      


      
Math → Code derivation

      

        Step 1: The qubit
        
|ψ⟩ = α|0⟩ + β|1⟩,   |α|² + |β|² = 1

        
A qubit is a unit vector in ℂ². Measurement in the computational basis yields |0⟩ with probability |α|² and |1⟩ with probability |β|² — Born's rule.

      

      

        Step 2: The Hadamard matrix
        
H = (1/√2) · [[1, 1], [1, −1]]

        
H is unitary and Hermitian (H = H†, H² = I). It is the gate that creates superposition — the foundation of all quantum algorithms that exploit parallelism.

      

      

        Step 3: H |0⟩ = (|0⟩ + |1⟩) / √2
        
α = 1/√2,  β = 1/√2

        
Starting from the ground state, Hadamard produces an equal superposition of |0⟩ and |1⟩. Each outcome has probability ½ on measurement.

      

      

        Step 4: H |1⟩ = (|0⟩ − |1⟩) / √2
        
α = 1/√2,  β = −1/√2  (a relative phase)

        
The relative minus sign is the quantum phase — there is no classical analogue. Combined with H|0⟩, this lets H map computational basis states to a different orthonormal basis (the Hadamard basis).

      

      

        Step 5: H² = I — reversibility
        
H · H = I   →   H|ψ⟩ twice gives back |ψ⟩

        
All quantum gates are unitary (and thus reversible). H applied twice returns the original state. This is the foundation of the Deutsch-Jozsa and Grover algorithms — H is the quantum workhorse.
