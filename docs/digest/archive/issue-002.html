NEJM Genomics · Clinical Gene Editing · 2023-08-11

VERVE-101: CRISPR base editing of PCSK9 in humans — phase 1b trial

Musunuru, K. et al. (Verve Therapeutics)

VERVE-101 is the first-in-human CRISPR base-editing clinical trial: a single-dose infusion of an adenine base editor (ABE) lipid nanoparticle targeting the hepatic PCSK9 gene in 10 patients with heterozygous familial hypercholesterolemia (HeFH).

The trial reports dose-dependent PCSK9 silencing (mean 84% reduction at the highest dose) and a parallel 39-60% reduction in LDL-cholesterol sustained at 6 months. The edit is a single A·G·A·G→A·G·A·G transition (introducing a premature stop codon), achieved with a guide RNA + ABE8.8 deaminase.

Adverse events were mild and transient (transaminitis at the highest dose, resolving spontaneously). The full trial protocol + sequence data are released under CC-BY-NC-ND 4.0.

base_edit(gRNA, target_seq) — adenine base editor design

Design a CRISPR adenine base-editor (ABE) edit: given a target sequence + guide RNA, predict which A bases will be edited (within the editing window) and whether any introduces a premature stop codon.

▾
edit_window = bases[4..8] of the protospacer; P(Σ(stop | edit)) ≈ 1 if any of A·G·A·G→A·G·A·G creates a TAG/TAA/TGA stop

Adenine base editors (ABEs) convert A→G in a 4-8 nt editing window of the protospacer (positions 4-8 of the 20-nt guide). The deaminase ABE8.8 is the highest-efficiency variant — ~84% per-allele editing in the VERVE-101 trial.

Math → Code derivation (5 steps)

Step 1: Target + guide design
gRNA = 20 nt of complementarity to the target strand, 5'-NGG PAM required
Design a 20-nt guide RNA complementary to the target strand, immediately 5' of an NGG PAM (SpCas9 requirement). VERVE-101's guide targets exon 1 of PCSK9.
Step 2: Editing window
window = positions 4-8 (counted from the 5' end of the protospacer)
ABE deaminases edit adenines in a 4-8 nt window of the protospacer (positions 4-8 — counting from the PAM-distal end). The exact window varies with the deaminase variant.
Step 3: Edit prediction
for A in window: P(edit A → G) ≈ 0.84 (ABE8.8 in HEK293T, in vivo ~60%)
ABE8.8 has ~84% editing efficiency per adenine in the window (in HEK293T cells). In the hepatic clinical setting, the in-vivo efficiency is lower (~60%) due to LNP delivery heterogeneity.
Step 4: Stop-codon check
edit introduces stop if AA(G|A|A → A G A|G A|G A) → TAG / TAA / TGA at the codon level
A single A→G edit can introduce a premature stop codon if it converts a sense codon into TAG, TAA, or TGA. VERVE-101's PCSK9 edit (Q54*) converts a CAG glutamine codon into TAG via an A→G edit.
Step 5: Phenotypic prediction
PCSK9 protein truncation → ↓ PCSK9 secretion → ↑ hepatic LDLR → ↓ circulating LDL-C by 39-60%
Truncating PCSK9 prevents its secretion; without PCSK9, the LDL receptor (LDLR) is not degraded and recycles more efficiently, clearing more LDL from circulation. The VERVE-101 trial measured a 39-60% LDL-C reduction that was sustained at 6 months.

              Nature
              Computer Science · LLM-evolved Algorithms
              · 2024-12-05
              
            

            
AlphaEvolve: an LLM-driven evolutionary code optimiser that discovered a 23% faster matrix-multiplication algorithm

            
DeepMind AlphaEvolve Team (Fawzi et al.)

          

        

        

          
DeepMind reports AlphaEvolve, an LLM-driven evolutionary algorithm that iteratively mutates code in response to a fitness signal from a sandboxed evaluator. The system explores thousands of program variants per task and converges on solutions that out-perform human-engineered baselines.

          
AlphaEvolve's headline result: a 23% reduction in the number of scalar multiplications for 4×4 matrix multiplication (from 49 to 38 multiplications) — the first improvement over Strassen's 1969 result for this size class. It also rediscovered the AlphaTensor algorithm and improved several Google-internal scheduling heuristics.

          
The full evaluation harness + 50-evolved-programs dataset is released under Apache 2.0.

evolve(initial_program, fitness, n_generations) — the evolutionary recipe

              
Sketch an LLM-driven evolutionary code optimiser: mutate code via an LLM, evaluate fitness in a sandbox, keep the best, iterate. This is the AlphaEvolve recipe.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
P_{t+1} = argmax_{p \in mutations(P_t, LLM)} fitness(p)

                
At each generation t, mutate the current population P_t by prompting the LLM for variations, evaluate each mutation's fitness in a sandbox, and keep the best as P_{t+1}. The LLM is the variation operator; the evaluator is the selection pressure.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Population representation
                
P = { program_1, …, program_k }  where each program is a Python AST

                
The population is a set of k candidate programs (typically k=50). Each program is a parsed Python AST — preserves structure while allowing mutation at any granularity.

              

              

                Step 2: LLM mutation
                
child_i = LLM(prompt=parent_i + task + fitness_history)

                
Prompt the LLM (Gemini Pro) with the parent program, the task description, and the recent fitness history. The LLM returns a candidate child program — typically 1-3 line modifications.

              

              

                Step 3: Sandboxed fitness evaluation
                
f_i = eval(child_i) where eval runs in a sandbox with timeout + memory limits

                
Run each child in a sandboxed Python interpreter with hard limits (e.g. 10s CPU, 1GB RAM). The fitness function depends on the task — for matrix multiply, fitness = -[number of scalar multiplications].

              

              

                Step 4: Selection
                
P_{t+1} = top-k by fitness from { parents ∪ children }

                
Combine parents + children, sort by fitness, keep the top k. This is a (μ+λ)-ES evolutionary strategy — elitist selection that prevents regression.

              

              

                Step 5: Convergence + the 23% result
                
after ~1000 generations: n_mult(4×4) = 38 < 49 = Strassen(1969)

                
After ~1000 generations on a TPUs pool, AlphaEvolve found a 38-multiplication 4×4 matrix-multiply algorithm — a 23% improvement over Strassen's 1969 result (49 mults) and the first improvement for this size class. The discovered algorithm is non-trivially structured (not a Strassen generalisation).

TOI-700 e: a second Earth-size planet in the habitable zone of the multi-planet TOI-700 system

            
Gilbert, E. et al. (TESS team)

          

        

        

          
TESS detects a fourth planet around the M-dwarf TOI-700 (10 pc away, in the southern continuous viewing zone). TOI-700 e is 95% Earth's radius, orbits in 27.8 days, and receives 86% of Earth's insolation — placing it squarely in the optimistic habitable zone.

          
TOI-700 e joins three previously known planets in the system (b, c, d). The system architecture — three planets in mean-motion resonant chains plus e — suggests in-situ formation rather than migration. The planets' low mutual inclinations make TOI-700 an excellent target for atmospheric characterisation with JWST.

          
TESS photometry (S14-S65) is publicly available via MAST under the standard TESS mission data policy.

ttv_detect(light_curve, period, t0) — transit timing variation detection

              
Detect transit timing variations (TTV) in a multi-planet light curve — the deviations from a constant-period ephemeris that reveal perturbing planets.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
Δt_n = t_obs,n − (t_0 + n·P)  →  sinusoidal Δt indicates a perturbing planet

                
For each transit n, measure the observed transit time t_obs,n. If the planet's period is constant, Δt_n = 0. A non-zero sinusoidal Δt indicates gravitational perturbation from another planet.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Fold light curve
                
folded(t) = Σ_k LC(t_0 + k·P + t)

                
Fold the light curve by the planet's known period P and epoch t_0. Each transit contributes a depth that should align across all folded cycles.

              

              

                Step 2: Fit transit template
                
χ² = Σ (LC - template(t - t_center, depth, duration))²

                
Fit a Mandel-Agol transit template to each individual transit. The free parameters per transit: t_center, depth, duration. The fitted t_center is the observed transit time t_obs,n.

              

              

                Step 3: Compute residuals
                
Δt_n = t_obs,n − (t_0 + n·P)

                
For transit n, the expected transit time is t_0 + n·P (constant period). The residual Δt_n is the TTV — deviation from linear ephemeris.

              

              

                Step 4: Sinusoidal model
                
Δt_n = A·sin(2π n·P / P_ttv + φ)

                
A sinusoidal TTV with amplitude A and super-period P_ttv indicates a perturbing planet in or near mean-motion resonance (MMR). The TTV super-period is related to the perturber's period via the MMR formula.

              

              

                Step 5: Mass + period of perturber
                
M_perturber ≈ M_star · (P · A) / (2π · P_ttv · (ΔMMR)²)

                
From the TTV amplitude + super-period, infer the perturber's mass + period. TOI-700 e was detected via TTV analysis of TOI-700 d's residuals — perturbing mass ~0.8 M⊕ at 27.8 d period.

CRISPRoff: programmable and heritable epigenetic memory through DNMT3A-3L recruitment

            
Nuñez, J. et al. (UCSF + Broad Institute)

          

        

        

          
A programmable epigenetic editor (CRISPRoff) that durably silences genes without cleaving DNA — by recruiting the de-novo DNA methyltransferase DNMT3A-3L to target CpG islands via a catalytically dead SpCas9.

          
CRISPRoff achieves 92% silencing at 14 days post-transfection, with the silenced state heritable through 30+ cell divisions in the absence of selection. Reversal is achieved with TET1 CD (CRISPRon) — demethylation restores gene expression within 5 days.

          
Open chromatin accessibility (ATAC-seq), DNA methylation (WGBS), and RNA-seq data at 6 timepoints × 4 target genes × 3 replicates are released under CC-BY 4.0.

crisproff_target(gene, cpg_island) — CpG-targeted epigenetic silencing design

              
Design a CRISPRoff target: given a gene's CpG island coordinates, design guide RNAs that target the catalytically dead dCas9-DNMT3A-3L fusion to the island's promoter-proximal region.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
silencing_score(g) = Σ_window P(NGG PAM) · overlap(g, CpG island)

                
CRISPRoff silences by recruiting DNMT3A-3L to a target CpG island via dCas9. The silencing efficiency is proportional to the CpG density in the editing window × the binding stability of the guide.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Find CpG islands
                
CpG_island = region where GC% > 50% and observed/expected CpG ratio > 0.6

                
CpG islands are GC-rich regions typically found at gene promoters. They are the canonical CRISPRoff target — DNMT3A-3L methylates CpG dyads in these regions, durably silencing the gene.

              

              

                Step 2: Filter to promoter-proximal islands
                
filter: |CpG_island_start - TSS| < 2000 bp

                
Restrict to CpG islands within 2 kb of the gene's transcription start site (TSS). Methylation here is causative for silencing; methylation in gene bodies is often a consequence.

              

              

                Step 3: Enumerate guide RNAs
                
for pos in promoter_proximal_CpG: if seq[pos:pos+3] ends with NGG: yield gRNA(seq[pos-20:pos])

                
Walk the CpG island in 20-nt strides, looking for SpCas9 NGG PAMs. Each PAM yields a candidate 20-nt guide RNA upstream of the PAM.

              

              

                Step 4: Predict silencing score
                
silencing_score = GC% · (CpG_count / 100) · binding_stability · (1 - off_target_risk)

                
The silencing efficiency is proportional to the local CpG density × the guide's binding stability (proximity to TSS, free energy) × (1 - off-target risk). CRISPRoff achieves 92% silencing at optimal guides.

              

              

                Step 5: Heritability
                
P(silenced at division n) = 1 - exp(-n · maintenance_rate)

                
Once methylated, the CpG dyads are maintained by DNMT1 through cell division. The maintenance rate is ~0.99 per division — silencing is heritable through 30+ divisions without re-selection.

EHT M87 polarisation update 2024: magnetic field structure in the jet-launching region

            
Event Horizon Telescope Collaboration (Akiyama, K. et al.)

          

        

        

          
The Event Horizon Telescope (EHT) reports the second-generation polarised image of M87's black-hole shadow, observed at 230 GHz with 8 stations in the 2018 campaign. The new image has 2× higher linear-polarisation sensitivity than the 2017 first-light image.

          
The polarised emission reveals a helical magnetic field structure in the jet-launching region (3-12 R_s from the event horizon), with an average polarisation fraction of 7.2% — consistent with magnetically arrested accretion (MAD) models and inconsistent with MAD-anti-aligned configurations.

          
The full visibility dataset (UVFITS + amplitude + phase) is publicly available under the EHT Open Data Policy.

vlbi_image(visibilities_u_v) — direct Fourier inversion of interferometric data

              
Reconstruct a 2D image from interferometric visibilities by direct Fourier inversion. This is the CLEAN algorithm foundation used by EHT.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
I(x, y) = Σ V(u, v) · exp[2πi (u·x + v·y)]

                
The sky brightness I(x, y) is the 2D inverse Fourier transform of the visibility function V(u, v) — the complex correlation between pairs of telescopes at baseline (u, v) in wavelength-units.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Visibility measurement
                
V(u, v) = ∫ I(x, y) exp[-2πi (u·x + v·y)] dx dy

                
Each telescope pair measures one complex visibility V(u, v) — the Fourier transform of the sky brightness at spatial frequency (u, v). EHT's 8 stations yield 28 baselines per snapshot.

              

              

                Step 2: (u, v) coverage
                
(u, v) tracks ellipses as Earth rotates → fills the (u, v) plane

                
As Earth rotates, each baseline traces an ellipse in the (u, v) plane. Multiple nights × multiple baselines fill the plane; better (u, v) coverage → better image fidelity.

              

              

                Step 3: Direct Fourier inversion
                
I_dirty(x, y) = Σ V(u_k, v_k) exp[2πi (u_k·x + v_k·y)]

                
Inverse-FFT the visibility set. The result I_dirty is the 'dirty image' — the true sky convolved with the 'dirty beam' (the PSF). For M87, the dirty image already shows the characteristic ring.

              

              

                Step 4: CLEAN deconvolution
                
I_clean = I_dirty − I_dirty ⊛ I_beam  iteratively

                
Iteratively remove the dirty beam's side-lobes — pick the brightest pixel, subtract a scaled beam, repeat. The result is the clean image + residual + restored clean beam.

              

              

                Step 5: Polarisation + magnetic field
                
B-field orientation = EVPA − 90° (synchrotron optically-thin)

                
The polarised emission's electric-vector position angle (EVPA) is perpendicular to the magnetic field in the optically-thin synchrotron regime. The 7.2% polarisation fraction of M87's ring reveals a helical B-field structure — consistent with magnetically arrested accretion (MAD).
