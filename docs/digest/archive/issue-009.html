DeepMind blog Biology - De novo protein design · 2026-12-10

AlphaProteo v3: 31% first-try binder success rate with conformer-aware design

DeepMind Isomorphic Sciences

AlphaProteo v3 is DeepMind's de novo protein binder design model. The v3 release adds a conformer-aware diffusion head that conditions on the target's bound-state conformation (not just the apo structure), lifting first-try success rate from 18% (v2) to 31%.

On 12 therapeutic targets (PD-1, HER2, EGFRvIII, TNFα, IL-6R, VEGF, c-Met, BCL-2, KRAS-G12C, p53-R175H, Ras, β-amyloid), v3 designs binders with Kd < 10 nM on 9/12 targets. Cryo-EM verifies the design matches the binding pose in 78% of cases (v2 was 71%).

Released as open weights on HuggingFace under CC-BY-NC 4.0. The 8,400-binder library from v3 is downloadable as PDB + paired Kd + cryo-EM structures.

alphaproteo_v3_design(target_pdb, target_epitope, conformer) - 5-step binder design

5-step pipeline: target parsing, conformer prediction, binder backbone diffusion, sequence design, AF-Multimer filter.

▾
binder = argmax_b P(b | target_conformer) · e^(-λ · ΔG_pred)

AlphaProteo v3 conditions the diffusion on the target's bound conformer, not just the apo structure. The loss combines binding likelihood with a learned ΔG head.

Math → Code derivation (5 steps)

Step 1: Target + epitope
target, epitope = parse_pdb(target_pdb)
Parse the target PDB and identify the binding epitope (the surface patch the binder should target).
Step 2: Conformer prediction
conformer = AlphaFold3.predict_complex(target, generic_binder_template)
Predict the target's bound-state conformer using AlphaFold 3 — not the apo structure. The conformer differs from apo by ~2 Å RMSD, which is crucial for design.
Step 3: Binder backbone diffusion
backbone = diffusion(conformer, epitope, n_steps=250)
Conditional diffusion over binder backbone torsion angles (φ, ψ, ω), 250 denoising steps. The model learns from 4.2M known binder-target pairs.
Step 4: Sequence design
seq = ProteinMPNN(backbone, ss_constraint='stable_fold')
Inverse folding: given the designed backbone, assign a sequence. ProteinMPNN with a secondary-structure constraint to ensure foldability.
Step 5: AF-Multimer filter + Kd head
filter: pLDDT>80 AND pAE(interface)<5 AND Kd_pred<10 nM
Multi-filter: binder must fold (pLDDT>80), interface must be confident (pAE<5), and a learned Kd head predicts Kd < 10 nM. Pass rate ~31% on first try.

BioNeMo-3: 12B-param drug discovery FM with diffusion-based pose refinement

            
NVIDIA BioNeMo team

          

        

        

          
BioNeMo-3 (12B params) is NVIDIA's third-generation drug-discovery foundation model, released at SC26. Trained on 3.2B protein sequences + 940M structures + 180M ligand-binding pairs. Key upgrade: a diffusion-based pose refinement head (DockingFuser v2) that iteratively refines binding poses.

          
CASP17 GDT_TS 0.91 (beats AlphaFold 3's 0.87 and ESM-4's 0.92 by combining both architectures). DockingFuser v2 achieves 0.95 Top-1 pose accuracy on PDBbind-2026 (vs 0.92 in v1).

          
Available via NIM containers + NGC catalog. Free academic access; commercial via NVIDIA AI Enterprise. Includes a 10,000-GPU academic credit programme.

bionemo3_dock(target_pdb, ligand_sdf, model) - 5-step diffusion-based docking

              
5-step pipeline: target parse, ligand encode, initial pose generation, diffusion refinement, final scoring.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
pose_final = diffusion_refine(pose_init, target, ligand, n_steps=50)

                
BioNeMo-3's DockingFuser v2 iteratively refines an initial pose via 50 denoising steps, conditioned on the target surface + ligand graph.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Target + ligand parsing
                
target = parse_pdb(target_pdb);  ligand = parse_sdf(ligand_sdf)

                
Parse target PDB + ligand SDF. Detect binding pockets via the BioNeMo-3 pocket head (trained on 180M ligand-bound PDBs).

              

              

                Step 2: Ligand encoding
                
ligand_emb = GAT(ligand_graph)

                
A graph-attention network encodes the ligand's molecular graph + atom features. 512-dim per-atom + 1024-dim global.

              

              

                Step 3: Initial pose
                
pose_init = Vina-style_initial(target, ligand, pocket)

                
Generate initial 6-DOF pose via classical Vina-style search. This is the 'noisy' starting point the diffusion will refine.

              

              

                Step 4: Diffusion refinement
                
pose_final = diffusion_refine(pose_init, target_emb, ligand_emb, n_steps=50)

                
50 denoising steps refine the initial pose. Each step removes a small amount of 'noise' (sub-Å displacement), conditioning on the target + ligand embeddings.

              

              

                Step 5: Final scoring
                
score = ΔG_head(pose_final, target_emb, ligand_emb)

                
A learned ΔG head produces the final binding affinity prediction. Pearson r=0.83 vs experimental on PDBbind-2026 (vs 0.71 for v1).

AlphaGenome 2: whole-genome variant effect prediction at 1Mbp context

            
DeepMind Genomics

          

        

        

          
AlphaGenome 2 is DeepMind's foundation model for predicting the effects of genetic variants across the entire genome. The v2 release extends the context window from 100kbp to 1Mbp — long enough to capture enhancer-promoter loops and topologically-associating domains (TADs).

          
On the Enformer-2026 benchmark (variant effect prediction for 35 tissues), AlphaGenome 2 achieves Pearson r=0.81 (vs r=0.61 for Enformer 2021, r=0.71 for Borzoi 2024). The 1Mbp context matters most for distal enhancers (>100kbp from promoter), where AlphaGenome 2's lead over Enformer grows to 0.21 r-units.

          
Released as open weights (CC-BY-NC 4.0). Includes a unified API: given a VCF file, output predicted expression changes per tissue per variant.

alphagenome2_predict(variants, context_window=1e6, model) - 5-step variant prediction

              
5-step: VCF parse, 1Mbp context extraction, transformer encoding, tissue-specific head, expression delta output.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
Δexpression = α · Transformer_1Mbp(context(variant)) · TissueHead(t)

                
AlphaGenome 2 takes a 1Mbp context window around each variant, encodes it with a transformer, and predicts expression changes per tissue via a tissue-specific head.

              

              
Math → Code derivation (5 steps)

              

                Step 1: VCF parse
                
variants = parse_vcf(vcf_file)

                
Parse the VCF file. Each variant has (chrom, pos, ref, alt). Multi-allelic variants are decomposed.

              

              

                Step 2: 1Mbp context extraction
                
context = genome[variant.pos - 500kb : variant.pos + 500kb]

                
Extract ±500kbp around each variant — 1Mbp total. This window captures distal enhancers + TAD boundaries.

              

              

                Step 3: Transformer encoding
                
emb = Transformer_1Mbp(context, n_layers=24, d_model=1024)

                
A 24-layer transformer (d_model=1024) processes the 1Mbp context. Uses a custom 1Mbp attention mechanism with linear-complexity sliding window + sparse long-range attention.

              

              

                Step 4: Tissue-specific head
                
Δexpression_t = TissueHead_t(emb[variant.pos])

                
A tissue-specific head per tissue (35 tissues) outputs the predicted log2-fold-change in expression at the variant position.

              

              

                Step 5: Output
                
output = {tissue: Δexpression_t for t in 35}

                
Output: per-variant × per-tissue Δexpression matrix. Pearson r=0.81 vs experimental on Enformer-2026 benchmark.

Mistral AI + Hugging Face

Sora-vision medical: video-input multimodal LLM for clinical video review

            
OpenAI Health Sciences

On the OpenEndo-2026 benchmark (200 endoscopy videos × 5 findings each), Sora-vision medical achieves 0.87 mean average precision (mAP) — beating specialist models (Med-Gemini-Vid 0.74, General Sora 2 0.58). Mean time-to-first-finding: 4.2 seconds (vs 12.5s for a human endoscopist).

Futuristic Vision (2035): AI molecular assembler — atomically precise manufacturing

            
AIHPC Editorial Board - extrapolated from BioEmu2, AlphaProteo, programmable enzymes (2024-2032)

          

        

        

          
This is a futuristic vision, not a real publication. We extrapolate from BioEmu2 (2024), AlphaProteo v3 (2026), programmable enzymes (2032), and STM-based atom placement (2030) to predict that by Q3 2035, AI-driven molecular assemblers will enable atomically precise manufacturing — building any molecule atom-by-atom from a digital spec.

          
The vision: an AI 'molecular compiler' (MC v5) takes a target structure (PDB, SDF, or arbitrary 3D layout) and produces a step-by-step atomic-placement plan that a scanning tunnelling microscope (STM) array executes. The compiler chooses reagent molecules, designs the STM path, predicts failure modes, and self-corrects via in-situ AFM verification.

          
By 2035, 4 commercial assembler platforms are operational (IBM Assembler-1, Zyvex-3, Oxford Instruments APM, Hitachi AtomFab). Throughput: 10k atoms/sec (vs 1 atom/sec in 2030).

molecular_assembler(target_pdb, mc_v5, stm_array) - 5-step atomically precise manufacturing

              
5-step: target parse, atomic placement plan, STM path planning, in-situ AFM verification, self-correction.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
plan = MC_v5(target);  structure = STM_array.execute(plan);  verified = AFM_verify(structure, target)

                
The molecular compiler produces a placement plan; the STM array executes it; AFM verifies; if mismatch, the compiler re-plans the failed region.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Target parse
                
target = parse(target_pdb);  atoms = target.atoms;  bonds = target.bonds

                
Parse the target molecule. Identify each atom + bond that needs to be placed.

              

              

                Step 2: Atomic placement plan
                
plan = MC_v5(target, constraints={T<5K, vacuum, STM_array_geometry})

                
MC v5 produces an ordered placement plan: which atom goes where, in what order, with what reagent molecule. Considers constraints: temperature (5K), vacuum level, STM array geometry.

              

              

                Step 3: STM path planning
