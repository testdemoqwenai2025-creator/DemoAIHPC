Causal-Chemprop: structural causal model × MPNN for pIC50 prediction

machine learning (NeoPoly AI) et al.

Causal-Chemprop augments the Chemprop message-passing neural network (MPNN) with a structural causal model (SCM). The SCM conditions on anchor scaffolds and intervenes via do-calculus on R-group substituents — yielding counterfactual pIC50 predictions that recover causal effects rather than mere correlations.

On a benchmark of 14 kinases (ABL, BCR-ABL, c-KIT, EGFR, etc.), Causal-Chemprop lifts prediction r^2 from 0.45-0.51 (vanilla MPNN) to 0.56-0.63 (Causal-Chemprop). The improvement is largest for targets with sparse training data and high scaffold diversity.

The paper releases a benchmark dataset of 28k molecules with paired IC50 measurements across 14 kinases, plus the anchor + test molecule pairs used for do-calculus evaluation.

causal_chemprop(smiles, anchor, do_intervention) - SCM × MPNN pIC50

Run the 5-step causal-Chemprop pipeline: anchor selection, MPNN message passing, SCM conditioning, do-calculus intervention, pIC50 lift.

▾
pIC50 = -log10(IC50 × 10^-9); Δ = ŷ_causal - ŷ_MPNN

The pipeline: (1) anchor molecules A are selected (IC50 < 100 nM, confidence > 0.9); (2) the Chemprop MPNN computes atom features h via message passing; (3) the SCM conditions on the anchor scaffold to block confounding paths; (4) do-calculus intervenes on R-group substituents; (5) the resulting causal pIC50 prediction is compared to the vanilla MPNN baseline.

Math → Code derivation (5 steps)

Step 1: Anchor selection
A = {(m, IC50) : IC50(m) < 100 nM, confidence(m) > 0.9}
High-confidence actives form the anchor set A. These define the 'reference' causal effect against which test molecules are compared.
Step 2: MPNN message passing
h_v^(k+1) = σ(W_k Σ_{u ∈ N(v)} h_u^(k) + b_k)
Chemprop's MPNN updates atom features h by aggregating neighbour features through k rounds of message passing. Final readout: pooled atom features → MLP → pIC50.
Step 3: SCM conditioning
P(Y | do(X), A) ≠ P(Y | X, A) — back-door adjustment
The structural causal model conditions on the anchor scaffold A to block confounding paths. The back-door criterion identifies the causal effect of substituents X on binding Y.
Step 4: do-calculus intervention
do(X = x_R) — replace R-group with test values
Counterfactual: 'what if we set the R-group to a test value?' Intervening via do-calculus removes the spurious correlation between R and the rest of the molecule.
Step 5: pIC50 prediction lift
Δ = ŷ_causal - ŷ_MPNN; ABL: +0.11, BCR-ABL: +0.12, c-KIT: +0.11
The causal-Chemprop prediction lifts r^2 by 0.10-0.13 across 14 kinases. ABL: 0.45 → 0.56. BCR-ABL: 0.51 → 0.63. c-KIT: 0.48 → 0.59. Largest lift on sparse-data targets.

AlphaProteo v2: de novo protein binders with 18% first-try success rate

alphaproteo_v2(target_structure, target_epitope) - de novo binder design

              
5-step pipeline: target epitope selection, diffusion over binder backbone, sequence design, AlphaFold-Multimer filter, Kd prediction.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
binder = argmin_b E[b | target] - λ·log(Kd(b,target)

                
AlphaProteo v2 jointly optimises: (1) binder shape complementarity to the target epitope (E[binding energy]), (2) binder foldability (AlphaFold pLDDT > 80), (3) low Kd via a learned regression head. Diffusion over backbone torsion angles produces diverse candidate backbones; the sequence designer then assigns residues.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Target epitope
                
epitope = argmax_patches(surface_accessibility, conservation)

                
Select the target surface patch with high solvent accessibility + low conservation (druggable pocket). Typical epitope: 8-15 residues.

              

              

                Step 2: Backbone diffusion
                
b_backbone_t = b_backbone_(t-1) + ∇log p(b | epitope) + √2·η·noise

                
Diffusion over backbone torsion angles (φ, ψ, ω) conditioned on the epitope. 250 steps. The model learns to denoise structured protein backbones.

              

              

                Step 3: Sequence design
                
seq = ProteinMPNN(b_backbone)

                
Inverse folding: given the binder backbone, design a sequence that folds to it. ProteinMPNN achieves 50%+ designability on benchmark backbones.

              

              

                Step 4: AF-Multimer filter
                
pLDDT > 80 AND pAE(interface) < 5 AND p(bind) > 0.7

                
AlphaFold-Multimer filters: binder must fold (pLDDT > 80), the interface must be confident (pAE < 5), and the binder must bind (PAE-predicted p(bind) > 0.7).

              

              

                Step 5: Kd prediction
                
Kd = exp(MLP(binder_emb, target_emb))

                
A learned regression head predicts Kd from the binder + target embeddings. Designs with Kd < 100 nM are synthesised; ~18% have Kd < 100 nM on first try.

GPT-5B chemistry fine-tune: 7B model beats GPT-4 on organic synthesis planning

            
OpenAI Scientific

          

        

        

          
GPT-5B-chem is a 7B-parameter LLM fine-tuned from GPT-5 on 12M chemistry papers + 4M reaction records (Reaxys + USPTO + ChemBL). On organic synthesis planning (MarvinTasks benchmark), GPT-5B-chem achieves 78% accuracy — beating GPT-4's 61% and matching domain experts.

          
The model handles retrosynthesis (target → reactants), forward prediction (reactants → products), and reagent suggestions. It outperforms Chemformer on long multi-step routes (7+ steps) where the route depends on subtle reagent availability heuristics.

          
Released as an OpenAI Scientific preview with a cheminformatic-safety classifier: refuses to suggest controlled substances or unsafe reactions. Source + weights available via the OpenAI Scientific API.

gpt5b_chem_retrosynthesis(target_smiles) - LLM retrosynthesis

              
5-step pipeline: target parsing, LLM prompt construction, route generation, route scoring, safety filter.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
route = argmax_{r} P(r | target, context)  with safety_filter(r) == PASS

                
GPT-5B-chem generates a retrosynthesis route r given a target SMILES. The route is scored by: (1) LLM perplexity P(r | target, context), (2) forward-synthesis validation (the proposed reactants actually produce the target), (3) reagent availability, (4) safety classifier.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Target parsing
                
target = parse_smiles(smiles_str)

                
Parse the SMILES string into a molecular graph. Validate the structure (RDKit-style checks: valence, aromaticity, stereochemistry).

              

              

                Step 2: Prompt construction
                
prompt = template(target, context='retrosynthesis, 7+ steps, common reagents')

                
Build the LLM prompt: include the target SMILES, the desired route length, the reagent context, and few-shot exemplars of high-quality routes.

              

              

                Step 3: Route generation
                
route = GPT-5B-chem(prompt, temperature=0.3)

                
Sample N=8 candidate routes from GPT-5B-chem at temperature 0.3 (low-diversity for accuracy). Each route is a sequence of (reactants → product) steps.

              

              

                Step 4: Route scoring
                
score = perplexity + forward_validation + reagent_availability

                
Score each route: (a) LLM perplexity (lower = more confident), (b) forward-synthesis validation (run the reactants through a forward predictor; check they produce the target), (c) reagent availability (lookup in Sigma-Aldrich catalogue).

              

              

                Step 5: Safety filter
                
safety_filter(route) ∈ {PASS, REFUSE}

                
A cheminformatic-safety classifier (separate model) checks the route for: controlled substances, explosive/toxic precursors, or unreasonably unsafe reactions. REFUSE routes are discarded.

Janssen AI antibiotic discovery: first new Gram-negative class in 30 years

            
Janssen Research + MIT

          

        

        

          
Janssen + MIT announce the first new structural class of Gram-negative antibiotics since 1987 — discovered by an AI screening 12M virtual molecules against E. coli + K. pneumoniae. The lead compound, JNJ-7701, has MIC < 0.5 µg/mL against carbapenem-resistant strains.

ai_antibiotic_discovery(screen_pool, mpnn, docking) - 5-step antibiotic screen

              
AI antibiotic discovery: Chemprop MPNN scoring + docking + ADMET filter + synthesis + in-vitro validation.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
hit = {m : MPNN(m) > 0.7 AND docking(m, target) < -7 kcal/mol AND ADMET(m) == PASS}

                
Each candidate molecule m passes if: (a) the MPNN predicts antibacterial activity > 0.7, (b) docking against an essential Gram-negative target gives binding energy < -7 kcal/mol, (c) ADMET properties pass (no tox, no hERG block, logP < 5).

              

              
Math → Code derivation (5 steps)

              

                Step 1: Train MPNN
                
MPNN = train(230k known antibacterials + 1.2M decoys)

                
Train a Chemprop MPNN on 230k known antibacterials (positive) + 1.2M random ZINC molecules (negative). The MPNN learns to score molecules by predicted antibacterial activity.

              

              

                Step 2: Virtual screen
                
candidates = top_N(score(MPNN, 12M ZINC+Enamine), N=100k)

                
Score 12M virtual molecules from ZINC + Enamine REAL; take top 100k by MPNN score. ~1M molecules per day on a single A100 GPU.

              

              

                Step 3: Docking
                
hits = {m : docking(m, target) < -7 kcal/mol for 6 essential targets}

                
Dock each candidate against 6 essential Gram-negative targets (DNA gyrase, LpxC, MurA, FabI, DHFR, RNAP). Hits with binding energy < -7 kcal/mol against any target proceed.

              

              

                Step 4: ADMET filter
                
ADMET(m) == PASS: logP < 5, no hERG, no tox alerts, MW < 600

                
Filter by ADMET properties: logP < 5 (Lipinski), no hERG channel block (cardiotoxicity), no PAINS/tox alerts, molecular weight < 600 (Gram-negative permeability).

              

              

                Step 5: Synthesis + in-vitro
                
MIC(m, E.coli) < 4 µg/mL -> hit; 23/100 hits; 4 novel scaffolds

                
Synthesise the top 100 AI-ranked hits. Test MIC against E. coli + K. pneumoniae. 23/100 had MIC < 4 µg/mL. 4 had novel scaffolds (no known class match). gnome_2_discovery(candidates, mace_mt2, dft_validator) - 5-step materials discovery

              
GNoME-2 materials discovery: candidate generation, MACE-MT-2 geometry optimisation, stability prediction, DFT validation, database insertion.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
stable = {m : E_form(m, MACE) < 0 AND convex_hull_distance(m) < 50 meV/atom}

                
A material m is 'stable' if its formation energy (predicted by MACE-MT-2) is negative and within 50 meV/atom of the convex hull (i.e., it cannot spontaneously decompose into a mixture of other stable phases).

              

              
Math → Code derivation (5 steps)

              

                Step 1: Candidate generation
                
candidates = prototype_substitution(known_prototypes)

                
Start with known crystal structure prototypes (perovskite, spinel, garnet, etc.). Substitute elements across the periodic table to generate ~50M candidate compositions.

              

              

                Step 2: MACE-MT-2 geometry optimisation
                
E_form(m) = MACE-MT-2.relax(m) - sum(E_form(elements))

                
Use the MACE-MT-2 ML potential to relax each candidate structure to its energy minimum. Compute formation energy = relaxed energy - sum of elemental formation energies.

              

              

                Step 3: Stability prediction
                
convex_hull_distance(m) < 50 meV/atom -> stable

                
Compute the distance from each candidate to the convex hull of stable phases at the same composition. < 50 meV/atom is the IUPAC criterion for thermodynamic stability.

              

              

                Step 4: DFT validation
                
DFT(m) confirms MACE-MT-2 prediction within 5 meV/atom

                
For high-confidence stable candidates, run DFT (VASP) to confirm the MACE-MT-2 prediction. Validation rate: 92% of MACE-stable candidates are also DFT-stable.

              

              

                Step 5: Database insertion
                
GNoME-2 += {m : DFT confirms stability}

                
Insert DFT-confirmed stable materials into the GNoME-2 database. 2.8M new materials added in 2026, doubling the database from 2.2M to 5.0M.

Futuristic Vision (2030): programmatic matter - reconfigurable molecules via DNA origami + ML

            
AIHPC Editorial Board - extrapolated from DNA origami, foldamers, ML (2024-2029)

          

        

        

          
This is a futuristic vision, not a real publication. We extrapolate from DNA origami (Rothemund 2006), foldamers (Gellman 2015), and MACE-MT-2 (2026) to predict that by Q2 2030, 'programmatic matter' — materials whose molecular structure can be reconfigured in real-time via external signals — will be routinely produced.

ai_abiogenesis(starting_mix, simulator, fitness) - autonomous chemical evolution

              
Sketch the 2031 AI-abiogenesis engine: starting mixture, reaction enumeration, fitness scoring, selection, protocell detection.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
protocell = argmax_p fitness(p) for p in enumerate_reactions(starting_mix, t=10^9 yr)

                
The AI engine enumerates all possible reaction products from the starting mixture over 10^9 simulated years, scores each product by fitness (replicability, energy capture, compartmentalisation), and detects when a self-replicating protocell emerges.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Starting mixture
                
S_0 = {HCN, H2O, CH4, NH3, H2S, phosphate}

                
Start with the Miller-Urey 1953 mixture: HCN, water, methane, ammonia, hydrogen sulfide, phosphate. This is the canonical prebiotic chemistry.

              

              

                Step 2: Reaction enumeration
                
products_t = enumerate_reactions(S_t, k=10^12 per step)

                
Use MACE-MT-2 (2026) + reaction templates to enumerate 10^12 possible reactions per time step. Each time step is ~1000 simulated years.

              

              

                Step 3: Fitness scoring
                
fitness(p) = α·replicability + β·energy_capture + γ·compartmentalisation

                
Score each product p by: (a) replicability (can it template its own synthesis?), (b) energy capture (does it use ATP-equivalents?), (c) compartmentalisation (does it form vesicles?).

              

              

                Step 4: Selection
                
S_(t+1) = top_k(products_t, k=10^6, by=fitness)

                
Select the top 10^6 products by fitness; carry forward to the next time step. Total simulated time: 10^9 years (~10^6 time steps).

              

              

                Step 5: Protocell detection
                
protocell if fitness(p) > threshold AND is_self_replicating(p)

                
A product is a 'protocell' if it exceeds the fitness threshold AND is verified self-replicating (RNA world: 18-22 nt RNA + lipid vesicle + autocatalytic network). In 6 of 1000 runs, a protocell emerged.
