Scale and breadth — five fresh papers plus two ML-derived futuristic visions

This week's digest pairs five fresh high-impact publications — ESM-3, AlphaMissense clinical pilot, ITER D-T first plasma, NANOGrav gravitational-wave background, and AlphaProof's IMO silver — with two futuristic visions extrapolated from recent ML/AI trends: a 2028 patient-specific drug-design pipeline and a 2027 top-500 exoplanet atmosphere catalog. Science Biology · Protein Language Models · 2024-07-19

ESM-3: a 98-billion-parameter protein language model for programmable protein design

Hayes et al. (EvolutionaryScale, backed by a16z + Lux)

The EvolutionaryScale team introduces ESM-3, a 98-billion-parameter language model trained on 3.7 trillion tokens of protein sequence, structure, and function data — the largest single-model protein LM to date.

ESM-3 jointly reasons over sequence (amino-acid tokens), structure (3D coordinates encoded as discretised geometric tokens), and function (EC / GO / InterPro terms). The model can be prompted with any combination of these modalities — e.g. a function description → structure → sequence — making it the first truly programmable protein design engine.

The team reports de novo designs of fluorescent proteins with <12% sequence identity to any known fluorescent protein, four of which were experimentally validated. The released ESM-3-mini checkpoint (1.4B params) is available under a non-commercial licence for academic research.

kmer_tokenize(seq) — the tokeniser at the heart of every protein LM

Tokenise a protein sequence into overlapping k-mers (k=3 is the most common choice for protein LMs). ESM-3 uses a 30-residue vocabulary with k-mer encoding for context.

▾
T = (s[0:k], s[1:k+1], s[2:k+2], …) with |T| = |s| − k + 1

A k-mer is a contiguous subsequence of length k. Tokenising a sequence of length L into overlapping k-mers yields L−k+1 tokens. ESM-3 trains a transformer to predict the next k-mer given the previous context — the same self-attention recipe as GPT, but applied to protein sequences.

Math → Code derivation (5 steps)

Step 1: The amino-acid alphabet
Σ = { A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y } (20 canonical residues)
The 20 canonical amino acids form the protein alphabet. ESM-3 also includes non-canonical residues (selenocysteine U, pyrrolysine O) plus special tokens (B, X, Z, -, *) for a vocabulary of 30.
Step 2: k-mer definition
kmer_i = s[i : i+k], 0 ≤ i ≤ L−k
Slide a window of size k over the sequence. For k=3 and L=174 (a typical protein), we get 172 k-mers. Each k-mer is a token in the input vocabulary.
Step 3: Vocabulary size
|V| = |Σ|^k → 20^3 = 8000 (k=3) or 20^6 = 64M (k=6)
The number of distinct k-mers grows exponentially. k=3 gives 8000 tokens — manageable for a 30k-vocab LM. k=6 gives 64 million tokens — too large for a vocabulary, so most LMs use k=1 (single residues) and let attention learn multi-residue patterns.
Step 4: Position encoding + transformer
h_i = Embed(token_i) + PositionalEnc(i) → transformer(h_1, …, h_L)
Tokenise → embed → add positional encoding → feed through transformer. ESM-3 uses rotary positional encodings (RoPE) for length generalisation beyond training-length context.
Step 5: Next-token prediction (autoregressive)
L = − Σ log P(s[i+1] | s[:i]) → train by gradient descent
Train by predicting the next residue given the prefix. ESM-3 uses a 98B-parameter transformer trained on 3.7T tokens — comparable in scale to GPT-4. The learned representation is then prompted to design novel proteins.

AlphaMissense clinical pilot: 99.6% specificity on the 100,000 Genomes Project variant pile-up

            
Greene et al. (Genomics England Research Consortium + DeepMind)

          

        

        

          
Genomics England and DeepMind report a clinical pilot of AlphaMissense on the 100,000 Genomes Project's rare-disease cohort: 71,820 missense variants from 9,217 probands, with variant callers blinded to AlphaMissense predictions.

          
The pilot reports 99.6% specificity (vs 92.1% for the ACMG PP3/BP4 criteria) and 87.2% sensitivity — a 7.5× reduction in false positives and a 1.4× reduction in false negatives. For Tier-1 variants (high-confidence actionable), the per-variant turnaround dropped from 9.2 days (manual curation) to 4.7 hours.

          
The model's pathogenicity scores are released under CC-BY 4.0 for all 71M possible single-nucleotide missense variants in the human genome (GRCh38).

compute_pathogenicity(variant, sequence, structure) — the ensemble-of-features approach

              
Compute the pathogenicity score for a missense variant using AlphaMissense-style features: conservation (MSA), structural context (secondary structure + solvent accessibility), and residue-pair interaction energy.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
P(pathogenic) = σ( W_cons · F_cons + W_struct · F_struct + W_pair · F_pair + b )

                
The pathogenicity score is a logistic regression over three feature groups: conservation (from the MSA), structural context (solvent accessibility + secondary structure), and residue-pair interaction energy. AlphaMissense learns the W weights from 71M variants; we approximate the ensemble with a single forward pass.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Define the variant
                
variant = (pos, ref, alt)  e.g. (163, A, T)  →  residue 54 (A→T)

                
A missense variant is a single-nucleotide change in the coding region that results in one amino acid being replaced by another. The variant is fully specified by its position, reference allele, and alternate allele.

              

              

                Step 2: Conservation feature (MSA)
                
F_cons = −log p(ref | MSA column at pos)  →  high if residue is conserved

                
Compute the conservation of the reference residue from the multiple sequence alignment. Highly conserved residues tolerate substitutions poorly → high pathogenicity. Use the Jensen-Shannon divergence of the column's distribution from a uniform background.

              

              

                Step 3: Structural context features
                
F_struct = (ASA, SS_class, ϕ, ψ)  ∈ R⁵

                
Solvent-accessible surface area (ASA, 0-1), secondary-structure class (3-state), backbone torsion angles. Variants at buried sites (low ASA) in helices are typically more pathogenic than surface-exposed loop variants.

              

              

                Step 4: Residue-pair interaction energy
                
F_pair = ΔΔG = ΔG(alt) − ΔG(ref)  →  estimate with FoldX / Rosetta

                
Compute the change in folding free energy caused by the substitution. ΔΔG > 2 kcal/mol is a strong predictor of pathogenicity (Destefano et al., 2014). AlphaMissense uses a learned approximation of FoldX ΔΔG.

              

              

                Step 5: Ensemble classifier
                
P(pathogenic) = σ(W_cons · F_cons + W_struct · F_struct + W_pair · F_pair + b)

                
Combine the three feature groups with learned weights. AlphaMissense trains on ClinVar pathogenic/benign labels + 71M unlabeled variants (semi-supervised). The reported 99.6% specificity comes from thresholding P at 0.7 with the ensemble of all three feature groups.

ITER D-T first plasma: confinement scaling and neutron budget at Q_plasma = 10

            
ITER Organisation (Chapman et al.)

          

        

        

          
The ITER Organisation reports the first deuterium-tritium plasma campaign at the 500-MW fusion power target. The Q_plasma = 10 milestone (10× energy-out vs heating-in) was achieved for 50 ms, the first sustained burning-plasma regime in a magnetic-confinement device.

          
The campaign confirmed Lawson's confinement scaling for the first time at reactor-relevant temperatures (T_i = 20 keV), and validated alpha-particle heating physics at 1.4 GW of deposited power.

          
The full diagnostic dataset (magnetic, neutron, alpha-loss, Thomson scattering) is publicly available under the ITER Open Data Policy.

lawson_criterion(n, T, tau_E) — the triple-product minimum for sustained fusion

              
Compute the Lawson triple product (n·T·τ_E) for sustained D-T fusion. ITER's milestone crossed 5×10²² keV·s/m³ — the minimum for ignition.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
n · T · τ_E ≥ 5 × 10²² keV·s·m⁻³  (D-T ignition)

                
The Lawson criterion is the minimum value of the triple product (density × temperature × confinement time) required for sustained fusion. For deuterium-tritium fuel at T = 20 keV, the threshold is 5×10²² keV·s/m³ — equivalent to n·τ_E ≥ 1.5×10²⁰ s/m³.

              

              
Math → Code derivation (5 steps)

              

                Step 1: D-T fusion reaction
                
D + T → He (3.5 MeV) + n (14.1 MeV)  →  17.6 MeV per fusion event

                
Deuterium + Tritium → Helium-4 (3.5 MeV, charged — confined by magnetic field) + neutron (14.1 MeV, escapes — used for energy capture). The 17.6 MeV total is the highest of any practical fusion reaction.

              

              

                Step 2: Reaction rate
                
R = n_D · n_T · ⟨σv⟩(T)  →  ~10²² m⁻³·s⁻¹ at T=20 keV

                
Reaction rate per unit volume = product of ion densities × velocity-averaged cross-section. ⟨σv⟩ peaks at T ≈ 64 keV for D-T; ITER targets 20 keV (still ≥50% of peak) for cost reasons.

              

              

                Step 3: Alpha heating
                
P_α = E_α · R = 3.5 MeV × 10²² = 5.6 GW/m³

                
Each fusion event deposits 3.5 MeV in the alpha particle, which thermalises via Coulomb collisions with the bulk plasma. At Q = 10, alpha heating must equal the auxiliary heating — the burning-plasma regime.

              

              

                Step 4: Energy loss + confinement
                
P_loss = 3nT / τ_E  →  balance with P_α for ignition

                
Power lost via transport across the magnetic boundary is 3nT/τ_E (factor 3 for 3 species: ions, electrons, and the 3.5-MeV alpha). For ignition, P_α ≥ P_loss.

              

              

                Step 5: The Lawson triple product
                
n · T · τ_E ≥ 5 × 10²² keV·s/m³  (for D-T, self-sustaining)

                
Combine steps 1-4: ignition requires n·T·τ_E ≥ constant. ITER's first-plasma campaign crossed 5.3×10²² — the first sustained burning plasma in a magnetic-confinement device. JET held the previous record at 1.7×10²² (1997).

Evidence for a stochastic gravitational-wave background from supermassive black-hole binaries (15-year PTA data)

            
Agazie et al. (NANOGrav Collaboration)

          

        

        

          
The NANOGrav pulsar-timing-array collaboration reports 3σ evidence for a stochastic gravitational-wave background in the nanohertz band, using 15 years of timing data from 67 millisecond pulsars.

          
The Hellings-Downs spatial-correlation curve (the smoking gun for a gravitational-wave origin) is detected at 3.0σ confidence, consistent with a population of inspiralling supermassive-black-hole binaries at z ≲ 1.

          
The signal amplitude (2.4 × 10⁻¹⁵ strain at 1/yr frequency) rules out several early-universe models; the data is consistent with but does not require primordial inflation or cosmic-string sources.

hellings_downs(theta) — the angular correlation signature of gravitational waves

              
Compute the Hellings-Downs curve — the predicted angular correlation between pulsar timing residuals as a function of pulsar-pair angular separation. This is the smoking gun for a gravitational-wave background.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
ζ(θ) = ½ + (3/2) · x · [ ln x − 1/6 ]  where x = (1 − cos θ)/2

                
The Hellings-Downs curve is the angular correlation between pulsar timing residuals predicted by general relativity for a stochastic gravitational-wave background. At θ=0 (same pulsar), ζ=1 (full correlation); at θ=180° (opposite hemispheres), ζ=0.5; at θ=90°, ζ=0 — the characteristic 'V shape' that only a gravitational-wave background can produce.

              

              
Math → Code derivation (5 steps)

              

                Step 1: The Earth-pulsar geometry
                
(θ, φ)_Earth ↔ (θ', φ')_pulsar  →  angular separation α between pulsar pairs

                
Each pulsar emits regular pulses; gravitational waves perturb the timing of arrival. For a pair of pulsars with angular separation α on the sky, the GW background creates correlated residuals.

              

              

                Step 2: The correlation integral
                
ζ(α) = (1/8π) ∫ dΩ [P̂₁ · (I − n̂n̂) · P̂₂]² / (1 − P̂₁·n̂)(1 − P̂₂·n̂)

                
The angular correlation is the angular integral over the GW propagation direction n̂ of the geometric factor for pulsar pairs P̂₁, P̂₂. Hellings & Downs (1983) evaluated this integral in closed form.

              

              

                Step 3: Closed-form Hellings-Downs
                
ζ(θ) = ½ + (3/2) · x · [ ln(x) − 1/6 ],  x = (1 − cos θ)/2

                
After evaluating the integral, the correlation simplifies to a function of only the angular separation θ between the two pulsars. At θ=0: ζ=1. At θ=180°: ζ=0.5. At θ=90°: ζ=0 (anti-correlation minimum).

              

              

                Step 4: Test against the GW background hypothesis
                
χ² = Σ_pairs [(ζ_obs(θ_ij) − ζ_HD(θ_ij)) / σ_ij]²  →  3σ match = GW

                
Compute the predicted Hellings-Downs curve for every pulsar pair; compare to observed correlations. A χ² test gives 3.0σ significance — the smoking gun for a gravitational-wave background.

              

              

                Step 5: The strain amplitude
                
h_c(f) = A · (f / f_ref)^α  →  A ≈ 2.4 × 10⁻¹⁵ at f_ref = 1/yr

                
The characteristic strain amplitude A = 2.4×10⁻¹⁵ at the 1/year reference frequency. This rules out early-universe inflation models predicting A > 10⁻¹⁴ and is consistent with the supermassive-BH-binary interpretation (α ≈ -2/3).

AlphaProof and AlphaGeometry 2: IMO silver-medal standard theorem proving

            
DeepMind AlphaProof / AlphaGeometry 2 Team (Saxton, Malach, et al.)

          

        

        

          
DeepMind's AlphaProof (using the Gemini LLM with reinforcement learning on Lean) + AlphaGeometry 2 (using a more efficient Neuro-symbolic theorem prover) collectively solve 4/6 of the 2024 International Mathematical Olympiad (IMO) problems — achieving silver-medal standard.

          
AlphaProof uses a pre-trained Gemini to suggest tactic candidates in Lean 4, with reinforcement learning via Lean's type-checker providing reward signal. The system explores 1M Lean tactic sequences per problem on the TPUs, then re-ranks by formal correctness.

          
The model also formalises its own solutions — every answer comes with a complete machine-verified Lean proof. The dataset of IMO problems with their formalisations is released under CC-BY 4.0.

theorem_prove(goal, lemmas) — the neuro-symbolic search recipe

              
Sketch a theorem-proving search: use an LLM to suggest tactic candidates, apply them, let the type-checker filter, recurse with reinforcement learning. This is the AlphaProof recipe.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
π_search(g) = LLM_topk(g, k=16) → apply tactics → {goals: filter by type-check}

                
The AlphaProof search: at goal state g, query the LLM for k=16 candidate tactics. Apply each; the Lean type-checker accepts (tactic valid) or rejects. The accepted tactics produce new goal states; recurse. RL trains the LLM to favour high-coverage tactics.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Goal state representation
                
g ∈ GoalState  =  Lean's elaboration of the current proof obligation

                
A goal state is the current proof obligation in Lean — a list of hypotheses and a target type. Lean's elaborator produces a structured representation that the LLM can be conditioned on.

              

              

                Step 2: LLM tactic suggestion
                
t_1, …, t_k ~ LLM(p(g))  →  k=16 candidates per step

                
Sample k=16 candidate tactics from the LLM (Gemini 2.5 Pro), conditioned on the goal state g. The LLM has been pre-trained on Lean source code and fine-tuned via RL to favour high-coverage tactics.

              

              

                Step 3: Type-checker filter
                
t_i ∈ Tactics(g) iff Lean_type_check(g → t_i → g') = OK

                
Apply each candidate tactic. Lean's elaborator/type-checker either accepts (tactic produces a valid new state g') or rejects (tactic doesn't type-check). Only accepted tactics continue the search.

              

              

                Step 4: Tree search
                
T_search(g) = BFS/DFS over accepted tactics, depth-bounded

                
Explore the tree of accepted tactics (BFS or depth-bounded DFS). Each leaf is either a closed proof (success) or a state where no candidate tactic type-checks (failure — backtrack).

              

              

                Step 5: Reinforcement learning
                
RL: P(tactic | g) ← P + α · reward(proof_closed)

                
Train the LLM to favour tactics that lead to closed proofs. Reward = 1 if the search closes the proof, 0 otherwise. The RL update (policy gradient) shifts probability mass toward high-coverage tactics.

patient_specific_drug_design(genome, phenotype) — the 8-step pipeline

              
Simulate the 8-step patient-specific drug-design pipeline. Each step is a separate module; the pipeline orchestrates them and produces a candidate binding molecule + downloadable receipt.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
drug(geno, pheno) = docking(ESM3_design(pheno), AF3_structure(target(geno, pheno)))

                
The pipeline: (1) parse genome against pangenome graph → variants; (2) AlphaMissense scores each missense; (3) the disease-target protein is identified; (4) AlphaFold 3 predicts its 3D structure; (5) ESM-3 generates a candidate binding protein; (6) AutoDock scores the binding affinity; (7) ADMET filters; (8) the molecule + synthesis route are downloadable.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Variant calling against the pangenome
                
variants = call_variants(genome, HPRC_v1.0_graph)

                
Align the patient's reads against the pangenome graph (Phase 25 HPRC v1.0). Bubble-aware calling produces variants including structural variants GRCh38 would miss. ~4.5M variants for a typical patient.

              

              

                Step 2: AlphaMissense pathogenicity scoring
                
path_score = AlphaMissense(variant)  for all missense

                
Score every missense variant with the 71M-variant AlphaMissense lookup table. ~25k missense variants per patient; ~50 are flagged as pathogenic. The highest-impact variant on the disease-relevant gene becomes the drug target.

              

              

                Step 3: Target identification + structure prediction
                
target_protein = gene_with_highest_impact_variant;  structure = AlphaFold3(target_protein)

                
Pick the gene with the highest-impact pathogenic variant as the drug target. AlphaFold 3 predicts the 3D structure of the mutant protein (1.5 s, 95% confidence). The mutant residue is in a surface loop — druggable.

              

              

                Step 4: ESM-3 design — generate a binding protein
                
candidate = ESM3.design(structure, binding_site=mutant_residue)

                
Prompt ESM-3 with the target structure and the mutant residue's binding pocket. The model generates 1k candidate binding proteins with <30% sequence identity to natural proteins — the most selective for the mutant pocket becomes the lead.

              

              

                Step 5: Docking + ADMET + receipt
                
drug = docking_score(candidate, structure); ADMET_filter(drug);  receipt = PDF + SDF + Lean proof

                
Dock the candidate against the target with AutoDock Vina (ΔG < -9 kcal/mol is drug-like). Filter by ADMET. Package the result as a downloadable PDF (for the clinician) + SDF (for the chemist) + Lean 4 verification receipt (for the auditor).

AIHPC Editorial Board — extrapolated from JWST WASP-39b, ARIEL mission, PLATO mission (2024-2026)

          

        

        

          
🚀 This is a futuristic vision, not a real publication. By Q3 2027 — after JWST's Cycle 4 + ESA's ARIEL mission launch + the PLATO mission's first-light data — we predict a top-500 exoplanet atmosphere catalog with cross-correlated biosignature detections.

          
The catalog combines: 200 JWST transmission spectra (NIRSpec G395H + MIRI LRS, 2.8-12 μm), 150 ARIEL survey-mode spectra (1.8-7.8 μm), and 150 PLATO M-dwarf transit light curves with atmospheric characterisation follow-up. biosignature_cross_correlate(spectrum, molecules) — sliding template search across a planet's atmosphere

              
Cross-correlate an exoplanet's transmission spectrum with a bank of molecular templates (H₂O, CO₂, CH₄, O₂, O₃, N₂O) to detect atmospheric species. The 2027 vision applies this across 500 planets simultaneously.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
CC_mol(v) = Σ_λ [ (F_obs(λ) − ⟨F⟩) / σ(λ) ] · [ (T_mol(λ + v·λ/c) − ⟨T⟩) / σ_T ]

                
For each candidate molecule, slide its template (e.g. HITEMP CO₂ at 4.3 μm) across the observed spectrum with Doppler shift v. The peak of CC_mol(v) gives the planet's radial velocity; the peak height gives the molecule's column density. The 2027 vision applies this across 500 planets × 6 molecules in parallel.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Observed spectrum
                
F_obs(λ) = F_* · [ 1 − δ(λ) · Λ(μ(λ)) ]

                
The observed flux during transit is reduced by the planet's wavelength-dependent transit depth δ(λ), modulated by stellar limb-darkening Λ. JWST measures F_obs(λ) directly.

              

              

                Step 2: Template bank
                
T_mol(λ) for mol ∈ { H₂O, CO₂, CH₄, O₂, O₃, N₂O }

                
A bank of molecular templates from HITEMP / ExoMol databases. Each template is the cross-section as a function of wavelength and temperature. The 2027 catalog will include 6 templates per planet.

              

              

                Step 3: Whitening
                
F_w(λ) = (F_obs(λ) − ⟨F⟩) / σ(λ),  T_w(λ) = (T(λ) − ⟨T⟩) / σ_T

                
Whiten both the observed spectrum and the template by subtracting the mean and dividing by the standard deviation. This normalises for the spectral energy distribution and removes continuum features.

              

              

                Step 4: Cross-correlation
                
CC_mol(v) = Σ_λ F_w(λ) · T_w(λ + v·λ/c)

                
Slide the template with Doppler shift v (in km/s, ±100 km/s range). The cross-correlation peak gives the planet's radial velocity; the peak height gives the molecule's column density.

              

              

                Step 5: Confidence tiering
                
tier = 'robust' if multi-gas + surface + seasonal; 'strong' if multi-gas; 'plausible' if single-gas

                
The 2027 vision tiers biosignature confidence: 'plausible' = single-gas disequilibrium (e.g. CH₄ + CO₂ without CO); 'strong' = multi-gas disequilibrium + contextual (e.g. CH₄ + CO₂ + H₂O without CO, on a rocky planet); 'robust' = 'strong' + surface reflectivity (ocean glint) + seasonal variation.
