Multi-Head Attention

Instead of a single attention with d_model-dim queries/keys/values, split into h parallel heads each with d_model/h dimensions. Each head learns a different attention pattern — head 1 might attend to syntax, head 2 to coreference, head 3 to entity types, etc. The outputs are concatenated and projected back to d_model with W_O.

Math → Code

MultiHead(Q,K,V) = Concat(head_1, ..., head_h) W_O; head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
Step 1
Q_i = Q · W_i^Q, K_i = K · W_i^K, V_i = V · W_i^V
Project the d_model-dim Q, K, V to d_k = d_model/h dimensions per head. Each head has its own learned projection matrices W_i^Q, W_i^K, W_i^V — this is what allows heads to specialise.
Step 2
head_i = Attention(Q_i, K_i, V_i)
Each head runs the standard scaled dot-product attention in parallel. The h attention patterns are computed independently — no communication between heads during the forward pass.
Step 3
concat = [head_1; head_2; ...; head_h]
Stack the h outputs of shape [seq, d_v] along the feature axis to get [seq, h*d_v]. Since d_v = d_model/h, this concatenation restores the d_model dimension.
Step 4
output = concat · W_O
Apply a learned projection W_O of shape [d_model, d_model] to mix the information from all heads. This projection is what lets the model combine head outputs (e.g., 'head 2 said token is a verb, head 5 says it agrees with subject').
Step 5
Same FLOPs as single-head (h heads * d_model/h dim = d_model)
Multi-head has approximately the same compute cost as single-head attention with full dimension. The benefit is that heads can specialise — empirically, heads learn to track syntax, coreference, rare words, etc. Ablating individual heads often barely affects performance, suggesting redundancy.

Multi-head attention runs h parallel attention computations, each with d_model/h-dimensional projections, then concatenates and re-projects with W_O. Heads empirically learn specialised roles: syntax, coreference, entity types, long-range dependencies. Pruning literature shows many heads can be removed at inference with minimal quality loss — suggesting redundancy is by design, providing robustness against random head failure during training.
