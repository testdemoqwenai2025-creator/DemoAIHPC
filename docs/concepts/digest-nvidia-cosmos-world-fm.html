NVIDIA Cosmos: 700B-param world foundation model — understands + generates any physical reality

NVIDIA Research · NVIDIA blog · 2027-01-30

Abstract

Cosmos is NVIDIA's 700B-parameter (MoE 256 experts, top-8 routing) world foundation model. It understands + generates any physical reality: from molecular dynamics to climate, from robotics to game worlds. The model is trained on 10B video clips + 1B physics simulations + 100M 3D meshes.

On WorldBench (50 tasks across 5 modalities: video prediction, 3D generation, physics simulation, robotics control, game-world creation), Cosmos achieves 0.87 — the first model to exceed 0.85 on all modalities simultaneously. The key innovation: a unified 'physics-token' representation that encodes physical laws (conservation, causality, locality) as token embeddings.

Released as Cosmos API (cloud) + Cosmos Edge (70B, on RTX 5090). Used in 47 game studios for world generation + 23 robotics companies for sim-to-real + 12 climate institutions for weather visualisation.

5-step: prompt parse, physics-token encode, MoE generate, validate, output.

Math → Code derivation

world = Cosmos(prompt + physics_tokens); WorldBench=0.87
Cosmos uses physics-token embeddings that encode conservation laws, causality, and locality. The MoE generates worlds that are physically consistent.
Step 1: Prompt parse
prompt = parse('a ball rolling down a staircase, realistic physics')
Parse the prompt into structured physics: object (ball), environment (staircase), physics (gravity, collision, friction).
Step 2: Physics-token encode
tokens = physics_tokeniser(prompt, laws=[gravity, collision, friction, conservation])
Encode the prompt into physics-tokens: each token carries a physics-law embedding (conservation, causality, locality). This is the key innovation — physical laws are embedded in the token representation, not just learned implicitly.
Step 3: MoE generate
world = MoE_256(tokens, top_k=8, n_layers=80)
256-expert MoE with top-8 routing. 80 transformer layers. Generates the world as a sequence of physics-tokens (video frames + 3D meshes + physics state).
Step 4: Validate
validated = check(world, conservation=True, causality=True, locality=True)
Validate: conservation laws hold (energy, momentum), causality is preserved (no time-reversed events), locality respected (no faster-than-light interactions).
Step 5: Output
output = render(world, format=video|3D_mesh|physics_state); WorldBench=0.87
Render as video, 3D mesh, or physics state. WorldBench: 0.87 (first >0.85 on all 5 modalities). Used by 47 game studios + 23 robotics + 12 climate institutions.
