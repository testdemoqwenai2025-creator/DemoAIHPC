Huber Loss

Huber loss is quadratic (MSE-like) for small errors and linear (MAE-like) for large errors, with a configurable threshold δ. It's the canonical robust-regression loss — less sensitive to outliers than MSE, but smoother than MAE (differentiable everywhere). δ controls the transition point.

Math → Code

L_δ(e) = { ½e² if |e| ≤ δ; δ(|e| − ½δ) if |e| > δ }
Step 1
e_i = y_i − ŷ_i
Same as MSE/MAE — the error for sample i is the difference between true and predicted values.
Step 2
L = ½ e²
For small errors (within the threshold δ), the loss is quadratic — same as MSE. This gives fast convergence near the optimum.
Step 3
L = δ(|e| − ½δ)
For large errors (beyond δ), the loss is linear — same as MAE. This caps the influence of outliers: a 10× outlier gives the same gradient as a 2× outlier (both are δ).
Step 4
L_δ(e) = { ½e² if |e| ≤ δ; δ(|e| − ½δ) if |e| > δ }
The two regions are continuous at |e| = δ: ½δ² = δ(δ − ½δ) = ½δ². The gradient transitions from e (quadratic) to δ·sign(e) (linear) at the threshold.
Step 5
δ = 1.0 (default) or σ·1.345 (Mad)
δ controls the transition. A common heuristic is δ = 1.345·σ (where σ is the residual standard deviation) — this gives 95% efficiency under Gaussian noise while remaining robust to outliers. Smaller δ → more robust (like MAE); larger δ → more sensitive (like MSE).

Huber loss is the canonical robust-regression loss — quadratic for small errors (fast convergence) and linear for large errors (outlier-resistant). The threshold δ controls the transition: smaller δ → more robust (MAE-like), larger δ → more sensitive (MSE-like). The gradient is capped at δ for outliers, preventing a single bad sample from dominating training.
