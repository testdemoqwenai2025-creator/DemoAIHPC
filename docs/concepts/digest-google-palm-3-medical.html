PaLM-3 medical: 340B-pathway LLM with adaptive retrieval for real-time guidelines

Google DeepMind Health · Google Health blog · 2027-01-04

Abstract

PaLM-3 medical is Google's 340B-parameter (8-pathway MoE) clinical LLM with an adaptive RAG system that retrieves the most current clinical guidelines in real-time. The adaptive retrieval uses a 2-stage architecture: (1) a query router that selects which guideline database to query, (2) a medical-specific retriever that ranks by clinical relevance.

On MultiMedQA-Pro, PaLM-3 medical scores 0.92 (matching Claude 4 medical's 0.93). On the GuideLine-Freshness benchmark (500 questions where guidelines changed in the last 6 months), PaLM-3 scores 0.89 — beating Claude 4 (0.71) and Gemini 2.5 (0.68) by a wide margin, thanks to adaptive retrieval.

Released via Google Cloud Healthcare API + Med-PaLM API. Used in 18 NHS trusts + 7 US health systems. Supports 47 languages with translation-verified medical accuracy.

PaLM-3 medical uses adaptive retrieval: a query router selects the most relevant guideline database, then a medical retriever ranks by clinical relevance. Citations are checked for freshness (< 6 months).
Step 1: Case parse
case = parse(clinical_text); entities = extract(case)
Parse the clinical case + extract structured entities (symptoms, meds, labs, imaging).
Step 2: Query routing
db = router(case, candidates=[NICE, WHO, Cochrane, UpToDate, FDA])
The query router selects which guideline database(s) to query based on the case's domain. E.g. UK cardiology case → NICE + Cochrane.
Step 3: Adaptive retrieval
evidence = medical_retriever(case, db, top_k=10, rank_by=clinical_relevance)
A medical-specific retriever ranks documents by clinical relevance (not just vector similarity). Uses a clinical-relevance fine-tuned BGE model.
Step 4: Generation
analysis = PaLM3Med.generate(case + evidence, citations=True)
Generate the analysis with citations. 340B 8-pathway MoE; only 42B active per token (top-1 routing per pathway).
Step 5: Freshness check
fresh = all(citation.date > now - 6 months for c in citations)
Check that all citations are from guidelines updated in the last 6 months. If any are stale, re-retrieve from the latest version. GuideLine-Freshness: 0.89 (beats Claude 4 0.71).
