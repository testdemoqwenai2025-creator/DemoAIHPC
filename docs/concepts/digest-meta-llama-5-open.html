Llama 5: 1T-param open-weight MoE (Apache 2.0) — matches Claude 5 at 1/10th the cost

Meta AI · Meta AI blog · 2027-01-23

Abstract

Llama 5 is Meta's 1-trillion-parameter (MoE 256 experts, top-8 routing) open-weight LLM. Released under Apache 2.0 — the largest fully-open model ever. On MMLU-Pro, Llama 5 scores 0.89 (matching Claude 5's 0.89, beating GPT-5's 0.85). On HumanEval-Plus, Llama 5 scores 0.93 (beating Claude 5's 0.91).

The 256-expert MoE means only ~80B params active per token (top-8 of 256 experts × ~4B/expert). Deployable on a single NVIDIA B200 (192 GB HBM3e). The model was trained on 15T tokens of curated text + code + math.

Released as 4 variants: Llama 5 Mini (8B, on-device), Llama 5 Small (70B), Llama 5 Medium (400B), Llama 5 Max (1T). All Apache 2.0. The Max variant matches closed models at 1/10th the API cost.

Math → Code derivation

output = Llama5(prompt); routed through 8 of 256 experts per token
Llama 5 routes each token through the top-8 of 256 experts. ~80B active params. 4 variants from 8B to 1T. Apache 2.0.
Step 1: Prompt tokenise
tokens = BPE(prompt, vocab=256k)
Byte-pair encoding with 256k vocabulary. Supports 47 languages. Code tokens are AST-aware.
Step 2: Expert routing
experts = router(tokens, top_k=8, n_experts=256)
256-expert MoE with top-8 routing. Each expert ~4B params. Active: ~80B per token (8 × ~4B). The router is a small MLP trained jointly.
Step 3: Expert processing
hidden = Σ(expert_i(tokens) * weight_i) for i in top_8
8 selected experts process the tokens. Each expert specialises (e.g. code, math, languages, reasoning). Outputs combined via weighted sum.
Step 4: Generate
output = decode(hidden, autoregressive=True, max_tokens=4096)
Autoregressive generation. Max 4096 tokens. Supports: function calling, JSON mode, tool use, retrieval augmentation.
Step 5: Self-check
verified = self_check(output, consistency=5_runs)
5-run self-consistency check. If outputs disagree by > threshold, re-generate. MMLU-Pro: 0.89 (matches Claude 5). HumanEval-Plus: 0.93.
