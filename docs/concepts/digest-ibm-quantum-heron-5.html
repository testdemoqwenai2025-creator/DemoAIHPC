IBM Quantum-Heron 5: 1,331-qubit modular quantum computer with 0.1% error rate

IBM Quantum · IBM Research blog · 2026-12-20

Abstract

Quantum-Heron 5 is IBM's 5th-generation superconducting quantum processor. 1,331 qubits (vs Heron 4's 462) arranged in a modular 11×11 lattice. Two-qubit gate error rate: 0.1% (vs 0.3% in Heron 4). Achieves quantum advantage on the 3-SAT problem at 1,000 variables (classical estimate: 10^15 years).

Key innovation: modular scaling via chip-to-chip coupling. 11 chips of 121 qubits each, coupled via tunable couplers with 0.05% cross-chip error. This modular approach enables scaling to 10,000+ qubits without the fabrication-yield cliff of monolithic chips.

Available via IBM Quantum cloud. 200 university + 30 industry research groups have access. Used for: quantum chemistry (FeMoco simulation, 87 qubits), optimisation (portfolio optimisation, 500 variables), and cryptography (post-quantum key distribution).

5-step: problem encoding, modular qubit allocation, transpilation, execution, error mitigation.

Math → Code derivation

result = Heron5.execute(transpile(problem, topology=11x11)); mitigated = ZNE(result)
Quantum-Heron 5 solves a problem by: encoding it onto qubits, allocating across the modular 11×11 lattice, transpiling to native gates, executing, and applying zero-noise extrapolation (ZNE) error mitigation.
Step 1: Problem encoding
hamiltonian = encode(problem, qubit_count=n)
Encode the problem (e.g. 3-SAT, QUBO, VQE) as a quantum Hamiltonian acting on n qubits. For 1,000-variable 3-SAT, n=1,000.
Step 2: Modular allocation
allocation = distribute(hamiltonian, n_chips=11, qubits_per_chip=121)
Distribute the Hamiltonian across 11 chips of 121 qubits each. Cross-chip couplers handle inter-chip interactions. 0.05% cross-chip gate error.
Step 3: Transpilation
circuit = transpile(allocation, native_gates={CZ, RZ, SX, X})
Transpile to the native gate set (CZ, RZ, SX, X). The transpiler optimises for circuit depth + cross-chip communication overhead. Typical depth: 50-200 layers.
Step 4: Execution
result = Heron5.execute(circuit, shots=8192)
Execute on the Heron 5 processor. 8,192 shots. Two-qubit gate error: 0.1%. Total execution time: 50-500 µs (coherence limit: 200 µs T₂).
Step 5: Error mitigation
mitigated = ZNE(result) + PEC(result); final = majority_vote(mitigated, n_runs=5)
Apply zero-noise extrapolation (ZNE) + probabilistic error cancellation (PEC). Run 5 times with different seeds; majority vote. Effective error: 0.01% post-mitigation.
