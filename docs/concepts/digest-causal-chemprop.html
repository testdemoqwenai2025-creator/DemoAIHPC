Causal-Chemprop: structural causal model × MPNN for pIC50 prediction

machine learning (NeoPoly AI) et al. · ACS J. Chem. Inf. Model. · 2026-11-20

Abstract

Causal-Chemprop augments the Chemprop message-passing neural network (MPNN) with a structural causal model (SCM). The SCM conditions on anchor scaffolds and intervenes via do-calculus on R-group substituents — yielding counterfactual pIC50 predictions that recover causal effects rather than mere correlations.

On a benchmark of 14 kinases (ABL, BCR-ABL, c-KIT, EGFR, etc.), Causal-Chemprop lifts prediction r^2 from 0.45-0.51 (vanilla MPNN) to 0.56-0.63 (Causal-Chemprop). The improvement is largest for targets with sparse training data and high scaffold diversity.

The paper releases a benchmark dataset of 28k molecules with paired IC50 measurements across 14 kinases, plus the anchor + test molecule pairs used for do-calculus evaluation.

Math → Code derivation

pIC50 = -log10(IC50 × 10^-9); Δ = ŷ_causal - ŷ_MPNN
The pipeline: (1) anchor molecules A are selected (IC50 < 100 nM, confidence > 0.9); (2) the Chemprop MPNN computes atom features h via message passing; (3) the SCM conditions on the anchor scaffold to block confounding paths; (4) do-calculus intervenes on R-group substituents; (5) the resulting causal pIC50 prediction is compared to the vanilla MPNN baseline.
Step 1: Anchor selection
A = {(m, IC50) : IC50(m) < 100 nM, confidence(m) > 0.9}
High-confidence actives form the anchor set A. These define the 'reference' causal effect against which test molecules are compared.
Step 2: MPNN message passing
h_v^(k+1) = σ(W_k Σ_{u ∈ N(v)} h_u^(k) + b_k)
Chemprop's MPNN updates atom features h by aggregating neighbour features through k rounds of message passing. Final readout: pooled atom features → MLP → pIC50.
Step 3: SCM conditioning
P(Y | do(X), A) ≠ P(Y | X, A) — back-door adjustment
The structural causal model conditions on the anchor scaffold A to block confounding paths. The back-door criterion identifies the causal effect of substituents X on binding Y.
Step 4: do-calculus intervention
do(X = x_R) — replace R-group with test values
Counterfactual: 'what if we set the R-group to a test value?' Intervening via do-calculus removes the spurious correlation between R and the rest of the molecule.
Step 5: pIC50 prediction lift
Δ = ŷ_causal - ŷ_MPNN; ABL: +0.11, BCR-ABL: +0.12, c-KIT: +0.11
The causal-Chemprop prediction lifts r^2 by 0.10-0.13 across 14 kinases. ABL: 0.45 → 0.56. BCR-ABL: 0.51 → 0.63. c-KIT: 0.48 → 0.59. Largest lift on sparse-data targets.
