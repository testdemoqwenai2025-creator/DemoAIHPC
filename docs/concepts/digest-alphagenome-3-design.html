AlphaGenome 3: AI-driven whole-genome design — 10Mbp context + variant editing

DeepMind Genomics · DeepMind blog · 2027-01-28

Abstract

AlphaGenome 3 is DeepMind's 3rd-generation whole-genome model. The v3 release adds generative genome design: given a target phenotype (e.g. 'drought-resistant rice'), AlphaGenome 3 designs a complete genome (gene sequences + regulatory elements + chromatin structure) that produces the target phenotype with 78% accuracy.

Key upgrade: 10Mbp context window (vs v2's 1Mbp) — long enough to capture entire gene clusters + topologically-associating domains (TADs) + enhancer-promoter loops in a single prediction. The model is 200B params (MoE 128 experts, top-4 routing).

On the GenoDesign-2027 benchmark (50 target phenotypes × 5 species), AlphaGenome 3 achieves 78% phenotype-accuracy (vs v2's 61%). 23 of 50 designed genomes have been synthesized + tested in vivo — 18 show the target phenotype.

AlphaGenome 3 designs a complete genome from a target phenotype using a 200B-param MoE with 10Mbp context. 78% phenotype accuracy.
Step 1: Phenotype parse
phenotype = parse('drought-resistant rice, high-yield, disease-tolerant')
Parse the target phenotype into structured traits: drought resistance, yield, disease tolerance. Map each to known genetic pathways.
Step 2: Context retrieval
context = retrieve(reference_genome, phenotype_pathways, window=10Mbp)
Retrieve 10Mbp context around each relevant gene cluster. The 10Mbp window captures TADs + enhancer-promoter loops — critical for regulatory element design.
Step 3: Generative design
genome = design(context, phenotype, n_genes=50, n_regulatory=200)
Generate a complete genome: 50 gene sequences + 200 regulatory elements (promoters, enhancers, insulators) + chromatin structure. The MoE has 128 experts; 32 are genomics-specific.
Step 4: Variant editing
edited = edit(genome, variants=[SNP, indel, CNV, SV])
Apply variant edits: SNPs, insertions/deletions, copy-number variations, structural variants. The model predicts the effect of each edit on the phenotype.
Step 5: Phenotype prediction
predicted = predict(genome, phenotype); accuracy = 78%
Predict whether the designed genome produces the target phenotype. GenoDesign-2027: 78% accuracy. 18/23 synthesized genomes show the target phenotype in vivo.
