GPT-5B chemistry fine-tune: 7B model beats GPT-4 on organic synthesis planning

OpenAI Scientific · OpenAI technical report · 2026-08-20

Abstract

GPT-5B-chem is a 7B-parameter LLM fine-tuned from GPT-5 on 12M chemistry papers + 4M reaction records (Reaxys + USPTO + ChemBL). On organic synthesis planning (MarvinTasks benchmark), GPT-5B-chem achieves 78% accuracy — beating GPT-4's 61% and matching domain experts.

The model handles retrosynthesis (target → reactants), forward prediction (reactants → products), and reagent suggestions. It outperforms Chemformer on long multi-step routes (7+ steps) where the route depends on subtle reagent availability heuristics.

Released as an OpenAI Scientific preview with a cheminformatic-safety classifier: refuses to suggest controlled substances or unsafe reactions. Source + weights available via the OpenAI Scientific API.

5-step pipeline: target parsing, LLM prompt construction, route generation, route scoring, safety filter.

Math → Code derivation

route = argmax_{r} P(r | target, context) with safety_filter(r) == PASS
GPT-5B-chem generates a retrosynthesis route r given a target SMILES. The route is scored by: (1) LLM perplexity P(r | target, context), (2) forward-synthesis validation (the proposed reactants actually produce the target), (3) reagent availability, (4) safety classifier.
Step 1: Target parsing
target = parse_smiles(smiles_str)
Parse the SMILES string into a molecular graph. Validate the structure (RDKit-style checks: valence, aromaticity, stereochemistry).
Step 2: Prompt construction
prompt = template(target, context='retrosynthesis, 7+ steps, common reagents')
Build the LLM prompt: include the target SMILES, the desired route length, the reagent context, and few-shot exemplars of high-quality routes.
Step 3: Route generation
route = GPT-5B-chem(prompt, temperature=0.3)
Sample N=8 candidate routes from GPT-5B-chem at temperature 0.3 (low-diversity for accuracy). Each route is a sequence of (reactants → product) steps.
Step 4: Route scoring
score = perplexity + forward_validation + reagent_availability
Score each route: (a) LLM perplexity (lower = more confident), (b) forward-synthesis validation (run the reactants through a forward predictor; check they produce the target), (c) reagent availability (lookup in Sigma-Aldrich catalogue).
Step 5: Safety filter
safety_filter(route) ∈ {PASS, REFUSE}
A cheminformatic-safety classifier (separate model) checks the route for: controlled substances, explosive/toxic precursors, or unreasonably unsafe reactions. REFUSE routes are discarded.
