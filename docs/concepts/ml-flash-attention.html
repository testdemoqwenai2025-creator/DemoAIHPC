FlashAttention

FlashAttention (Dao et al. 2022) computes the exact same attention as scaled dot-product, but reorders the computation to avoid materialising the full N×N attention matrix in HBM. Instead, it loads tiles of Q, K, V into SRAM, computes a partial softmax that can be merged incrementally ('online softmax'), and writes only the final output back. Result: same numbers, 2-4x faster, 10x less memory.

Math → Code

Attention(Q,K,V) computed via tiling + online-softmax — never materialises the full N×N matrix
Step 1
Load Q[i:i+B_q], K[j:j+B_k], V[j:j+B_k] into SRAM
GPU SRAM (~192KB/SM) is 100x faster than HBM (~3TB/s, 80GB). Standard attention writes the full NxN score matrix to HBM then reads it back for softmax. FlashAttention instead processes Q,K,V in tiles that fit in SRAM.
Step 2
m_new = max(m_old, m_tile); s_new = exp(m_old - m_new) * s_old + sum(exp(s_tile - m_new))
Normally softmax needs the max over the full row. 'Online softmax' (Milan Puzic / Nikolay Dryden) shows we can update the running max and running sum incrementally as we see each K tile. This is the key trick that makes attention tileable.
Step 3
o_partial = sum(exp(s_tile - m_new)) * V_tile / s_new
For each K tile, compute the partial weighted sum of V. Maintain the running normaliser s_new so the partial output can be correctly reweighted when new tiles arrive.
Step 4
Recompute attention in backward pass instead of storing the N×N matrix
Standard autograd stores the N×N softmax weights for the backward pass. FlashAttention recomputes them — trades compute for memory. Since SRAM is so fast, the recompute is faster than the saved HBM I/O.
Step 5
10x memory → enables 32K context GPT, training not possible otherwise
Standard attention at seq=32K needs ~4GB just for the score matrix. FlashAttention needs ~512MB — enabling long-context LLMs (GPT-4 128K, Claude 200K, Gemini 1M). The exact same mathematics, just reordered for the memory hierarchy.

FlashAttention (Dao et al. 2022) is the algorithmic breakthrough that enabled long-context LLMs. The exact same scaled dot-product attention is computed, but the loops are reordered to keep data in GPU SRAM (192KB/SM, 100x faster than HBM). The 'online softmax' technique (incremental max + sum updates) makes tiling possible. Backward recomputes the score matrix — trading FLOPs for memory, which is faster because SRAM is so much faster than HBM. Result: 32K → 200K contexts become tractable; GPT-4, Claude, Gemini all use FlashAttention variants.
