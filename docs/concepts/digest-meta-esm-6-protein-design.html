ESM-6: 500B-param generative protein model — 68% first-try foldable + enzyme design

Meta AI FAIR + EvolutionaryScale · Meta AI blog · 2027-01-16

Abstract

ESM-6 is Meta's 500B-parameter (MoE 128 experts, top-4 routing) generative protein design + function model. The v6 release adds an enzyme-design head that produces novel enzymes with specified catalytic activity — 23 of 50 designed enzymes show measurable catalytic activity in vitro (vs ESM-5's 12/50).

On the ProteinGym benchmark (47 design tasks), ESM-6 achieves 0.88 designability (vs ESM-5 0.82, RFdiffusion 0.68). First-try foldable rate: 68% (vs ESM-5 52%, ESM-4 38%, ESM-3 18% — the curve is approaching saturation).

Key innovation: a multi-modal protein tokenizer that encodes sequence, structure, and function in a unified latent space. This allows cross-modal generation: given a function, generate a sequence; given a structure, generate a function; given a sequence, predict structure+function.

5-step: spec parse, multi-modal encode, flow-match generation, AF3 validation, function check.

Math → Code derivation

protein = ESM6(spec); foldable = AF3(protein).pLDDT > 80; functional = assay(protein) > 0.7
ESM-6 uses a multi-modal protein tokenizer (sequence+structure+function in one latent space). Flow-matching generates backbones. AF3 validates foldability. In vitro assay checks function.
Step 1: Spec parse
spec = parse(function, length, fold, catalytic_residues)
Parse the function specification: desired catalytic activity (e.g. 'esterase'), length (250 aa), fold (alpha-beta), and required catalytic residues (Ser-His-Asp catalytic triad).
Step 2: Multi-modal encode
emb = ESM6.tokenise(spec, modalities=['seq','struct','func'])
Tokenise the spec into a multi-modal latent: sequence tokens + structure tokens + function tokens. All in one unified latent space — the first protein model to do this.
Step 3: Flow-match generation
backbone = flow_match(emb, n_steps=150)
Flow matching generates the backbone (150 denoising steps — more than ESM-5's 100 for higher quality). The backbone encodes the 3D coordinates of all atoms.
Step 4: AF3 validation
structure = AF3.predict(seq); foldable if pLDDT > 80
AlphaFold 3 predicts the structure of the designed sequence. pLDDT > 80 = foldable. ESM-6: 68% first-try foldable.
Step 5: Function check
functional = assay(protein); 23/50 enzymes show activity
In vitro assay checks the designed protein's function. EnzymeBench: 23/50 designed enzymes show measurable catalytic activity (vs ESM-5's 12/50). Almost 2x improvement.
