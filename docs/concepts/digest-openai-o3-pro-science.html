o3-pro science: reasoning model solves 3 open research problems in physics + biology

OpenAI Research · OpenAI technical report · 2026-12-18

Abstract

o3-pro science is OpenAI's reasoning model fine-tuned for scientific research. It uses chain-of-thought (CoT) reasoning with 10,000+ internal thinking tokens per problem, enabling it to tackle open research questions that require multi-step deductive reasoning across domains.

3 notable discoveries in 2026: (1) a novel proof that P ≠ BPP for restricted circuit classes (resolving a 30-year open problem in computational complexity), (2) a new protein-folding energy function that improves AlphaFold 3's pLDDT by 4 percentage points on CASP17, (3) a new quantum error-correcting code for biased-noise channels (improving surface-code threshold from 1.1% to 1.7% for dephasing-biased noise).

Released via OpenAI API. Each reasoning run costs ~$200 in compute (10k thinking tokens × $0.02/token). 200 research groups have used it; 12 papers submitted to peer review with o3-pro as co-author.

o3-pro science uses chain-of-thought reasoning with 10,000+ internal thinking tokens to derive a solution, then verifies it against known axioms / test suites.
Step 1: Problem parse
problem = parse(research_question, domain='physics|biology|CS')
Parse the research question. Identify the domain (physics, biology, CS) + the specific sub-problem.
Step 2: Hypothesis generation
hypotheses = generate_hypotheses(problem, n=10)
Generate 10 candidate hypotheses. Each is a potential approach to the problem. The model conditions on the problem + domain knowledge.
Step 3: Chain-of-thought reasoning
solution = CoT(hypotheses, n_tokens=10000, self_consistency=5)
For each hypothesis, run a 10,000-token chain-of-thought derivation. Use self-consistency (5 independent runs) to select the most stable solution.
Step 4: Verification
verified = check(solution, axioms) AND test_suite(solution) AND peer_review(solution)
Verify the solution against: (a) known axioms, (b) test suites (for algorithmic problems), (c) simulated peer review (LLM-as-judge). Only 3/200 problems pass all 3.
Step 5: Publication
paper = format(solution, LaTeX); submitted to peer review
Format the solution as a LaTeX paper. 12 papers submitted to peer review with o3-pro as co-author. 3 accepted so far.
