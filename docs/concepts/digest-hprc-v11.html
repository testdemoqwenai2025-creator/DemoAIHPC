Human Pangenome Reference v1.1: 100+ haplotypes with structural-variant-aware graph calling

HPRC Liao, Asri, Ebler et al. · Nature Biotechnology · 2025-08-12

Abstract

The Human Pangenome Reference Consortium (HPRC) releases v1.1 of the human pangenome reference — 100+ haplotype-resolved assemblies from globally diverse individuals, integrated into a single GFA 2.0 graph.

v1.1 adds 51 new haplotypes (vs v1.0's 47), with improved structural-variant representation in the graph (now 412k bubbles vs 285k). Variant calling on the v1.1 graph reduces SV error rates by 73% in under-represented populations and 41% in European samples.

The reference (hprc-v1.1) is publicly available at the HPRC data hub under CC-BY 4.0; the GFA graph is at github.com/human-pangenomics/hpp_pangenome_resources.

Math → Code derivation

bubbles = { (u, v) : two internally vertex-disjoint paths u→v in G }
A bubble is a pair of parallel paths between two shared endpoints. Each bubble represents a structural variant — SNP, indel, or large SV — that the linear GRCh38 reference would represent as a single path.
Step 1: Parse GFA records
V = { S lines }, E = { L lines }, P = { P lines }
GFA records: S (segment, sequence + length), L (link, oriented), P (path, ordered segments). Build the segment graph G = (V, E).
Step 2: Topological sort
topo = Kahn(V, E)
Topologically sort the segments — left-to-right traversal. Required for bubble detection (bubbles respect the topological order).
Step 3: Bubble definition
bubble(u, v) = pair of internally vertex-disjoint paths u→v
A bubble is two paths from u to v that share no internal vertices. Each path is an allele. Counting bubbles = counting structural variants.
Step 4: Detection algorithm
for u in topo: for v in topo: if len(disjoint_paths(u, v)) >= 2: bubble!
Naive: for every pair (u, v), check if there are 2+ internally vertex-disjoint paths. O(V²) pairs × O(V·E) per check — too slow for 1.27M segments. Use the standard bubble-detection algorithm (O(V+E)).
Step 5: SV error reduction
graph_call_error_rate / linear_call_error_rate = 0.27 (under-represented) / 0.59 (European)
Calling variants against the v1.1 graph reduces SV error rates by 73% in under-represented populations (African ancestry) and 41% in European samples — because the variants are already in the reference, not discovered by noisy alignment.
