Loss Landscape (3D Surface)

Visualise a 2D parameter space (theta_1, theta_2) and the loss as a height field — a 3D surface plot. Real loss landscapes are high-dimensional (millions of parameters), but 2D slices reveal fundamental structure: convex bowls (MSE), saddle points (deep networks), ravines (momentum helps), and flat minima (good generalisation). Visualising trajectories of SGD/Adam/AdamW on this surface shows how each optimiser navigates differently.

Math → Code

L(theta_1, theta_2) = a*(theta_1 - b)^2 + c*(theta_2 - d)^2 + e*sin(f*theta_1)*cos(g*theta_2)
Step 1
L(theta_1, theta_2) = quadratic + sinusoidal perturbation
Mix a convex quadratic (bowl shape) with sinusoidal perturbations to create local minima. The quadratic gives a global structure (ravine, saddle, etc.); the perturbation adds multimodality — closer to real deep-net losses.
Step 2
dL/dtheta_1 = 2a*(theta_1-b) + e*f*cos(f*theta_1)*cos(g*theta_2); dL/dtheta_2 = 2c*(theta_2-d) - e*g*sin(f*theta_1)*sin(g*theta_2)
Analytic gradients. In practice these would be autograd-computed, but for a 2D toy loss we can write them by hand — useful for debugging optimiser implementations.
Step 3
theta_0 = random or specified
Choose an initial parameter vector. For loss landscape visualisations, picking theta_0 far from the minimum shows the optimiser's traversal behaviour — SGD oscillates in ravines, Adam damps oscillations, etc.
Step 4
theta_t+1 = theta_t - eta * grad(theta_t)
Apply the update rule of the chosen optimiser (SGD, Momentum, Adam, AdamW). Record the trajectory (theta_0, theta_1, ..., theta_T) for visualisation.
Step 5
3D surface (theta_1, theta_2, L) + overlay (theta_t trajectory)
Plot the loss as a 3D surface, then overlay the optimiser's trajectory as a coloured line. Different optimisers trace different paths — this is the pedagogical payoff of the 3D loss landscape.
