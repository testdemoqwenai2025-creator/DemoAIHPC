L1/L2 Regularisation (Weight Decay)

L1 and L2 regularisation add a penalty term to the loss function: L1 (sum of |w|) encourages sparsity (many weights -> 0), L2 (sum of w^2) encourages small weights. The regularisation parameter lambda controls the strength: larger lambda = more regularisation (simpler model).

Math → Code

L_reg = L_data + lambda1 * ||w||_1 + lambda2 * ||w||_2^2
Step 1
L2 = lambda * sum(w^2) = lambda * ||w||_2^2
L2 adds lambda * ||w||^2 to the loss. The gradient is 2*lambda*w — proportional to the weight. This shrinks all weights toward 0 smoothly. No weight becomes exactly 0.
Step 2
L1 = lambda * sum(|w|) = lambda * ||w||_1
L1 adds lambda * sum(|w|) to the loss. The gradient is lambda * sign(w) — constant magnitude. This can drive weights to exactly 0 (sparsity), enabling feature selection.
Step 3
L1 gradient = lambda * sign(w) — constant magnitude
Because the L1 gradient is constant (lambda * sign(w)), weights near 0 get pushed to exactly 0. This is unlike L2 whose gradient (2*lambda*w) -> 0 as w -> 0, leaving small but non-zero weights.
Step 4
L_reg = L + lambda1 * ||w||_1 + lambda2 * ||w||_2^2
Elastic net combines L1 (sparsity) + L2 (smoothness). Useful when features are correlated — L1 alone picks one, L2 keeps all small; elastic net keeps groups.
Step 5
Weight decay: theta <- theta - eta * (grad + lambda * theta) = theta * (1 - eta*lambda) - eta*grad
Weight decay is the gradient-descent form of L2: the weight is shrunk by a factor (1 - eta*lambda) at each step. For SGD, this is equivalent to L2. For Adam, see AdamW (decoupled weight decay).

L1 (Lasso) adds lambda*sum(|w|) to the loss, driving some weights to exactly 0 (feature selection). L2 (Ridge) adds lambda*sum(w^2), shrinking all weights smoothly. Elastic net combines both. Weight decay (theta -= eta*lambda*theta) is the gradient form of L2 for SGD. For Adam, use AdamW (decoupled weight decay). Default lambda: 1e-4 (CNNs) to 0.1 (transformers).
