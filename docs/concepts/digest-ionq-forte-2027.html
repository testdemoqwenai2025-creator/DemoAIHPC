IonQ Forte 2027: 1024-qubit trapped-ion system with algorithmic QUBO advantage

IonQ + Duke University · IonQ blog · 2027-01-05

Abstract

IonQ Forte 2027 is IonQ's 4th-generation trapped-ion quantum computer: 1024 qubits (Barium-137 ions) in a 2D fully-connected trap array. Two-qubit gate error: 0.008% (the lowest of any platform). Gate time: 200µs (vs Quantinuum's 400µs).

On the QUBO benchmark (Quadratic Unconstrained Binary Optimisation — the standard for quantum annealing comparison), IonQ Forte achieves quantum advantage at 350 variables (classical estimate: 10^20 years). This beats D-Wave's 200-variable advantage (D-Wave Advantage 6, 2026) and Quantinuum's 250-variable advantage.

Available via IonQ Cloud + AWS Braket + Azure Quantum. 89 university + 31 industry research groups have access. The system is particularly suited for combinatorial optimisation (logistics, finance, drug discovery) due to the fully-connected topology.

Math → Code derivation

solution = Forte.execute(transpile(QUBO→Ising, topology=fully_connected)); advantage at n>350
IonQ Forte maps the QUBO problem to an Ising Hamiltonian, transpiles for the fully-connected trapped-ion topology (no SWAP gates), executes at 0.008% error, and decodes the measurement outcome.
Step 1: QUBO encode
QUBO = Σ x_i Q_ij x_j (binary quadratic)
Parse the QUBO matrix Q. This is the combinatorial optimisation problem (e.g. portfolio optimisation, logistics routing, drug candidate selection).
Step 2: Hamiltonian map
H_Ising = Σ h_i Z_i + Σ J_ij Z_i Z_j (from QUBO)
Map the QUBO to an Ising Hamiltonian: x_i → (1-Z_i)/2. This gives the quantum Hamiltonian that the trapped-ion system will minimise.
Step 3: Transpile
circuit = transpile(H_Ising, topology=fully_connected, native_gates={GZ, RZ})
Transpile for the fully-connected topology (no SWAP gates needed). Native gates: global Z-rotation (GZ) + single-qubit RZ. Circuit depth: 30-80 layers for 350-variable problems.
Step 4: Execute
result = Forte.execute(circuit, shots=8192); error = 0.008% per 2-qubit gate
Execute on the 1024-qubit Ba-137 trapped-ion system. 8,192 shots. Two-qubit gate error: 0.008% (lowest of any platform). Gate time: 200µs.
Step 5: Decode
solution = decode(result, QUBO); advantage if better than classical
Decode the measurement outcome back to a QUBO solution. Quantum advantage at 350 variables (classical estimate: 10^20 years). Beats D-Wave's 200-variable advantage.
