Mean Squared Error (MSE)

MSE is the average squared difference between predicted and actual values. It penalises large errors quadratically — a 2× error gives 4× the loss. The gradient is proportional to the error magnitude, making optimisation well-behaved for convex problems.

Math → Code

L = (1/n) Σ_{i=1}^{n} (y_i − ŷ_i)²
Step 1
e_i = y_i − ŷ_i
For each sample i, the error is the difference between the true value y_i and the predicted value ŷ_i. MSE aggregates these errors across all n samples.
Step 2
e_i² = (y_i − ŷ_i)²
Squaring removes the sign (positive and negative errors both contribute positively) and penalises large errors quadratically. A 2× error gives 4× the loss.
Step 3
L = (1/n) Σ e_i²
Sum the squared errors and divide by n (the number of samples). The 1/n normalises for dataset size — a larger dataset doesn't inherently have larger loss.
Step 4
∂L/∂ŷ_i = −2(y_i − ŷ_i) / n = 2(ŷ_i − y_i) / n
The gradient is proportional to the error — larger errors produce larger gradients. This makes SGD converge quickly toward the correct prediction. The factor 2 comes from the chain rule on the square.
Step 5
ŷ ← ŷ − η · ∂L/∂ŷ
Gradient descent: update the prediction by stepping against the gradient, scaled by the learning rate η. For linear regression, this converges to the OLS solution.

MSE is the default loss for regression. It penalises large errors quadratically — a single outlier with 10× the error contributes 100× the loss. The gradient is proportional to the error (factor 2 from chain rule), making SGD converge well for convex problems. MSE is the maximum-likelihood estimator when residuals are Gaussian.
