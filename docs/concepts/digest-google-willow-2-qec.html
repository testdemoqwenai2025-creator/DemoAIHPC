Willow 2: 105-qubit surface code operating below threshold — first logical qubit with net error reduction

Google Quantum AI · Google Research blog · 2027-01-15

Abstract

Google's Willow 2 is a 105-qubit superconducting processor (transmon) that demonstrates the surface code operating below the error-correction threshold. The key milestone: a distance-5 surface code (25 data qubits + 24 ancilla qubits) achieves a logical error rate of 0.0003 per cycle — below the physical error rate of 0.001, proving that adding more qubits reduces the logical error (exponential suppression).

This is the first experimental demonstration that quantum error correction works as theory predicts — the 'below threshold' regime. Distance-3 → distance-5 shows the expected exponential improvement. Extrapolation to distance-7 (49 data qubits) predicts 0.0001 logical error — sufficient for fault-tolerant quantum computing.

Willow 2 is available via Google Quantum Cloud. 67 research groups have access. The system runs the surface code at 1 MHz cycle rate (1µs per syndrome-extraction round).

Math → Code derivation

logical_error = physical_error ^ (d+1)/2; below threshold when d increases reduce error
The surface code encodes 1 logical qubit in d² data qubits. Logical error rate = physical_error ^ ((d+1)/2). Below threshold: increasing d reduces the logical error exponentially.
Step 1: Encode logical qubit
|0_L⟩ = (1/√2)(|0000...⟩ + |1111...⟩); d²=25 data qubits
Encode 1 logical qubit in a d×d grid (d=5 → 25 data qubits). The logical |0⟩ is a superposition of all-0 and all-1 states.
Step 2: Syndrome extraction
syndrome = measure_ancillas(data_qubits, n_ancillas=24, rate=1MHz)
24 ancilla qubits extract the syndrome (error pattern) by measuring stabilizers (X-type + Z-type). 1 MHz cycle rate: 1µs per round.
Step 3: Error detection
errors = decode(syndrome, decoder=mWPM); matched to syndrome pattern
Decode the syndrome using minimum-weight perfect matching (mWPM). The decoder finds the most likely error chain that produced the observed syndrome.
Step 4: Correction
corrected = apply_pauli_frame(errors, data_qubits)
Apply the Pauli correction frame (X and/or Z rotations) to the data qubits. The correction is applied virtually (via frame updates) — no physical gates needed.
Step 5: Verify — below threshold
logical_error = 0.0003 < physical_error = 0.001 → below threshold ✓
The logical error rate (0.0003) is below the physical error rate (0.001). This proves QEC works: adding more qubits (increasing d) reduces the logical error exponentially. Distance 3→5 shows the expected scaling.
