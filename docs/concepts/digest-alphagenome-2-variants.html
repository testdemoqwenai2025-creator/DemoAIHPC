AlphaGenome 2: whole-genome variant effect prediction at 1Mbp context

DeepMind Genomics · DeepMind blog · 2026-12-03

Abstract

AlphaGenome 2 is DeepMind's foundation model for predicting the effects of genetic variants across the entire genome. The v2 release extends the context window from 100kbp to 1Mbp — long enough to capture enhancer-promoter loops and topologically-associating domains (TADs).

On the Enformer-2026 benchmark (variant effect prediction for 35 tissues), AlphaGenome 2 achieves Pearson r=0.81 (vs r=0.61 for Enformer 2021, r=0.71 for Borzoi 2024). The 1Mbp context matters most for distal enhancers (>100kbp from promoter), where AlphaGenome 2's lead over Enformer grows to 0.21 r-units.

Released as open weights (CC-BY-NC 4.0). Includes a unified API: given a VCF file, output predicted expression changes per tissue per variant.

Math → Code derivation

Δexpression = α · Transformer_1Mbp(context(variant)) · TissueHead(t)
AlphaGenome 2 takes a 1Mbp context window around each variant, encodes it with a transformer, and predicts expression changes per tissue via a tissue-specific head.
Step 1: VCF parse
variants = parse_vcf(vcf_file)
Parse the VCF file. Each variant has (chrom, pos, ref, alt). Multi-allelic variants are decomposed.
Step 2: 1Mbp context extraction
context = genome[variant.pos - 500kb : variant.pos + 500kb]
Extract ±500kbp around each variant — 1Mbp total. This window captures distal enhancers + TAD boundaries.
Step 3: Transformer encoding
emb = Transformer_1Mbp(context, n_layers=24, d_model=1024)
A 24-layer transformer (d_model=1024) processes the 1Mbp context. Uses a custom 1Mbp attention mechanism with linear-complexity sliding window + sparse long-range attention.
Step 4: Tissue-specific head
Δexpression_t = TissueHead_t(emb[variant.pos])
A tissue-specific head per tissue (35 tissues) outputs the predicted log2-fold-change in expression at the variant position.
Step 5: Output
output = {tissue: Δexpression_t for t in 35}
Output: per-variant × per-tissue Δexpression matrix. Pearson r=0.81 vs experimental on Enformer-2026 benchmark.
