Gemini 2.5 multimodal for science: 87% on GPQA Diamond, 94% on MATH, protein structure prediction from text

Google DeepMind Team · DeepMind blog · 2025-10-01

Abstract

Gemini 2.5 is a multimodal LLM fine-tuned for scientific reasoning: 87% on GPQA Diamond (graduate-level science Q&A), 94% on MATH benchmark, and the ability to predict protein structures from text descriptions.

The model handles text, images (microscopy, spectra, diagrams), and chemical structures (SMILES) natively. On the protein-structure-from-text task, Gemini 2.5 predicts C-alpha RMSD within 4.2A for 73% of test proteins - comparable to ESMFold but from text alone.

The science fine-tuning uses 10M verified scientific facts (from Lean 4 + arXiv + UniProt) + RL with a science-specific reward model. Available via API under the Gemini Pro license.

Gemini 2.5 encodes text + images + chemical structures into a shared embedding space, then generates a chain-of-thought reasoning trace before the final answer. The science fine-tuning uses 10M verified facts + RL.
Step 1: Multimodal input
input = text + images + SMILES -> shared embedding
Gemini 2.5 encodes text, images (microscopy, spectra, diagrams), and chemical structures (SMILES) into a shared embedding space. Cross-attention between modalities enables joint reasoning.
Step 2: Chain-of-thought
CoT = LLM.generate(input + 'Let me think step by step')
The model generates a step-by-step reasoning trace before the answer. This improves accuracy by 15% on GPQA Diamond (87% with CoT vs 72% without).
Step 3: Science reward model
R(answer) = verified_facts(answer) + benchmark_score(answer)
The RL reward combines: (1) consistency with 10M verified facts (from Lean 4 + arXiv + UniProt), (2) benchmark scores (GPQA, MATH, MMLU). The model is penalised for contradicting verified facts.
Step 4: Protein from text
RMSD(C_alpha) = 4.2A for 73% of test proteins
Given a text description of a protein ('a 174-aa protein with a beta-barrel fold'), Gemini 2.5 predicts the C-alpha positions. 73% of predictions have RMSD < 4.2A — comparable to ESMFold but from text alone.
Step 5: Benchmark results
GPQA: 87%, MATH: 94%, MMLU-Pro: 86%
Gemini 2.5 achieves 87% on GPQA Diamond (graduate science Q&A), 94% on MATH (competition math), 86% on MMLU-Pro. The science fine-tuning improves GPQA by 12pp over the base Gemini 2.5.
