TabPFN v2: in-context tabular foundation model beats XGBoost on small data

Hollmann et al. (Google + TU Munich) · Nature · 2026-10-22

Abstract

TabPFN v2 is a 100M-parameter foundation model for tabular classification + regression. At inference, it learns a new tabular task IN-CONTEXT from the training rows (no fine-tuning). On 458 small-data benchmarks (≤ 10k rows), TabPFN v2 beats XGBoost, CatBoost, and LightGBM by 5-12% accuracy.

Key innovation: a Set-Transformer architecture with a 'dynamic programming' attention mechanism that runs in O(n²) for n=10k rows (vs O(n³) for vanilla attention), enabling in-context learning at scale.

Released as PyPI `tabpfn` v2 + on HuggingFace. The model is licensed Apache-2.0; runs on a single CPU at 2-5 sec per inference for n=1000.

5-step pipeline: tabular parse, in-context encoding, set-transformer, dynamic-programming attention, prediction + uncertainty.

Math → Code derivation

ŷ = TabPFN(X_train, y_train, X_test); uncertainty = ensemble(50 random initialisations)
TabPFN learns the new task in-context: feed (X_train, y_train, X_test) into the model, no fine-tuning. A set-transformer with dynamic-programming attention runs in O(n²).
Step 1: Tabular parse
X_train (n × d), y_train (n,), X_test (m × d)
Parse CSV/Parquet/Arrow into a feature matrix X + target y. Categorical features are encoded via the model's embedding layer; numerical features are quantile-normalised.
Step 2: In-context encoding
emb = SetEncoder(X_train ∪ X_test)
Treat each row as a set element; the SetEncoder produces row embeddings that are permutation-invariant. Training rows carry their y labels.
Step 3: Set-Transformer
h = Transformer(emb, attention_dp=True)
A 12-layer Set-Transformer with dynamic-programming attention (O(n²) instead of O(n³)). Cross-attends between test rows and training rows.
Step 4: Prediction head
ŷ_test = softmax(linear(h_test)) for classification / linear for regression
A simple linear head produces the final prediction. For classification: softmax over classes. For regression: a Gaussian mean.
Step 5: Uncertainty
σ = std({ŷ^(i) for i in 50 random initialisations})
Run the model 50 times with different attention initialisations; the std of predictions is the epistemic uncertainty. Used for active learning.
