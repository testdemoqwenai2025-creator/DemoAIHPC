Lazy Evaluation as a UX Primitive

Popups open immediately with a pending state and stream updates as the computation progresses. Users feel progress rather than blocking — the feels alive property that's hard to copy. Press the button below: the popup runs a real function call (compute outlier stats on a gene-expression dataset) across all six platform languages, with a rotating DNA helix, streaming "thinking" tokens, and a live result chart.

No external links — everything happens in your browser.

What the popup demonstrates

  • Zero perceived latency. The popup opens in <50ms with a "pending" state; the viewer sees activity instantly even though the full computation takes ~5 seconds.
  • Streaming trace. Sub-steps arrive as the computation progresses — "computing mean...", "computing std...", "identifying outliers...". Each step is part of the decision trace.
  • Polyglot. The same algorithm — compute_outliers(values) — is shown in all six platform languages (Python / Rust / Go / C / Elixir / Scala). Toggle to compare.
  • Real function call. The popup actually runs the function on a small embedded dataset (10 gene-expression values); the result is computed in your browser, not faked.
  • Visual context. A rotating DNA double-helix SVG sets the biological register; the result chart highlights outliers in red.
  • Provenance. The popup footer offers a downloadable receipt (CSV + JSON trace) — the artifact is the asset.

Why this is the central UX primitive

Most platforms block on computation: a spinner hides the work and the user waits. The lazy-evaluated popup inverts this — the popup opens instantly and the work streams in. This is the "feels alive" property that's hard to copy. Combined with the temporal dashboard at /dashboard, it makes computation observable in real time and replayable after the fact.

Evolution of the subject

  • Today. Pure client-side streaming with setTimeout cadence; the popup is the demo.
  • Phase 5+. SSE stream from a sandboxed runtime; each trace event is a JSON object on the wire.
  • Phase 6+. Popups compose — open a sub-popup from any step to inspect the sub-trace. Click any "thinking" token to see its grounding in the knowledge graph.
