Futuristic Vision (2030): programmatic matter - reconfigurable molecules via DNA origami + ML

AIHPC Editorial Board - extrapolated from DNA origami, foldamers, ML (2024-2029) · AIHPC Futuristic Vision · 2030-Q2 (extrapolated)

Abstract

This is a futuristic vision, not a real publication. We extrapolate from DNA origami (Rothemund 2006), foldamers (Gellman 2015), and MACE-MT-2 (2026) to predict that by Q2 2030, 'programmatic matter' — materials whose molecular structure can be reconfigured in real-time via external signals — will be routinely produced.

The vision: a DNA-origami scaffold (100 nm cube) holds 8 foldamer 'arms' with switchable conformations. A machine-learning model (MACE-MT-4, 100B params) designs the conformational response to 4 input signals (pH, light, voltage, ligand). The scaffold can switch between 16 distinct material states — making it the first 'programmable' solid.

Applications: programmable catalysts (16 distinct catalysts in one vial, addressable by signal), programmable drug delivery (one formulation, 16 release profiles), programmable optical filters (16 colours from one substrate).

state_t = MACE-MT-4(scaffold, signal_t); 16 states per scaffold
The DNA-origami scaffold holds 8 foldamer arms. MACE-MT-4 (100B-param ML potential) predicts the conformational state of each arm given the 4 input signals (pH, light, voltage, ligand). The 8 arms × 2 conformations = 256 possible scaffold states, but only 16 are designed + verified.
Step 1: Scaffold design
scaffold = DNA_origami(100 nm cube, 8 arms)
A 100 nm DNA-origami cube with 8 foldamer arms attached at the 8 vertices. Each arm is a foldamer (peptidomimetic) with 2 stable conformations (open/closed).
Step 2: Foldamer placement
arms = place_foldamers(scaffold, n=8, conformations=2)
Attach 8 foldamer arms to the scaffold's 8 vertices. Each foldamer has 2 stable conformations; ligand/photoreceptor groups control the switching.
Step 3: Signal-response training
training_data = (signal_t, state_t) for 1000 measurements
Train MACE-MT-4 (100B params) to predict the scaffold's 16-state response to (pH, light, voltage, ligand) inputs. 1000 measurements per state.
Step 4: MACE-MT-4 prediction
state_t = MACE-MT-4(scaffold, signal_t)
At inference, MACE-MT-4 predicts the scaffold state given the current signals. 16 designed states; transition time ~100 ms.
Step 5: In-situ verification
AF-Multimer verifies the predicted state matches the actual state
AlphaFold-Multimer v3 (2029) verifies the actual scaffold state matches the predicted state. Match rate: 89% on the 16 designed states.
