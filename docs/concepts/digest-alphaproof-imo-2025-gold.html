AlphaProof achieves IMO 2025 gold medal - first AI to reach gold standard

DeepMind AlphaProof Team (Saxton, Malach, et al.) · Nature · 2025-09-15

Abstract

DeepMind's AlphaProof (Gemini 2.5 Pro + Lean 4 + RL) solves 5 of 6 problems at the 2025 International Mathematical Olympiad, achieving a gold-medal standard - the first AI to do so.

The solved problems span algebra, combinatorics, geometry, and number theory. The remaining unsolved problem (P6, a hard geometry problem) required a construction AlphaProof's tactic bank could not discover. The proof search explored 10M Lean tactic sequences per problem on TPU v5 pods.

Every solution ships with a complete machine-verified Lean 4 proof. The formalised IMO 2025 problem set + AlphaProof's proofs are released under CC-BY 4.0.

Demo — theorem_search(goal, tactic_bank, max_depth=20, k=16) - neuro-symbolic proof search

Sketch AlphaProof's neuro-symbolic search: prompt the LLM for k=16 tactic candidates, filter by Lean's type-checker, recurse with RL.

Math → Code derivation

pi_search(g) = LLM_topk(g, k=16) -> apply tactics -> {goals: filter by type-check}
At goal state g, the LLM suggests k=16 candidate tactics. Each is applied; Lean's type-checker accepts or rejects. Accepted tactics produce new goal states; the search recurses. RL trains the LLM to favour high-coverage tactics.
Step 1: Goal state
g in GoalState = Lean's elaboration of the proof obligation
A goal state is the current proof obligation in Lean - a list of hypotheses and a target type. Lean's elaborator produces a structured representation the LLM can be conditioned on.
Step 2: LLM tactic suggestion
t_1, ..., t_k ~ LLM(p(g)), k=16
Sample k=16 candidate tactics from the LLM (Gemini 2.5 Pro), conditioned on the goal state g. The LLM has been pre-trained on Lean source + fine-tuned via RL.
Step 3: Type-checker filter
t_i valid iff Lean_type_check(g -> t_i -> g') = OK
Apply each candidate; Lean's elaborator either accepts (produces new state g') or rejects. Only accepted tactics continue the search.
Step 4: Tree search
BFS/DFS over accepted tactics, depth-bounded
Explore the tree of accepted tactics. Each leaf is either a closed proof (success) or a state where no candidate type-checks (failure - backtrack).
Step 5: Gold medal
5/6 IMO 2025 problems solved -> gold standard
AlphaProof solved 5 of 6 IMO 2025 problems - the gold-medal threshold. P6 (hard geometry) was unsolved because the required construction was not in AlphaProof's tactic bank. The proof search explored 10M tactic sequences per problem.
