Recursive Agentic Benchmark

The team framed this project as recursive development of use agentic workflows. This page observes the agent's own performance as a temporal graph — every phase is a timestep; every metric is a state-change. Same UI as the temporal dashboard, but the subject is the agent itself.

Recursive agentic benchmark · live temporal graph

The agent observes itself.

Decision quality rising · rework rate falling · human-in-loop corrections → 0.

What this is

A formal benchmark for the agent's own performance: trace length (how many steps to reach a goal), decision quality (how often the human accepts the agent's first-pass proposal), rework rate (fraction of timesteps that get rolled back), human-in-loop corrections (count of explicit guidance messages). Every project phase is a timestep; the metrics evolve visibly.
