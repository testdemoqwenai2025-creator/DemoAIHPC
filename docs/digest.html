Nature Biology · Structural Pharmacology · 2024-10-30

GLP-1R activation mechanism revealed by cryo-EM: peptide binding, transmembrane helix rearrangement, and G-protein coupling

Liang, Y.-L. et al. (Monash + Heptares)

Cryo-EM structures of the GLP-1 receptor (GLP-1R) in four states — inactive, peptide-bound, Gs-coupled, β-arrestin-bound — at 2.6–3.1 Å resolution reveal the conformational cascade of class B GPCR activation.

The structure shows that GLP-1 peptide binding triggers a 14 Å shift in transmembrane helix 6 (TM6) — opening the intracellular cavity for Gs coupling. The β-arrestin-biased agonist (exendin-P5) shows a partial TM6 shift, explaining its signalling bias.

The structures rationalise the clinical efficacy of GLP-1R agonists (semaglutide, tirzepatide) and inform the design of next-generation biased agonists with reduced GI side-effects.

tm6_displacement(structure_active, structure_inactive) — class B GPCR activation metric

Compute the transmembrane helix 6 (TM6) displacement between active and inactive GPCR structures — the canonical activation metric for class B GPCRs.

▾
ΔTM6 = |Cα(inactive, residue N) − Cα(active, residue N)| for N in TM6 intracellular end

The TM6 displacement is the Euclidean distance between the Cα atom of a TM6 intracellular-end residue in the inactive vs active structure. A Δ > 8 Å indicates full activation (typical for class B GPCRs).

Step 2: Identify TM6 residues
TM6 = residues[233–265] of GLP-1R (Uniprot O95837)

Step 3: Align structures (Cα backbone)
RMSD_align(inactive, active) via Kabsch algorithm
Superimpose the two structures using Cα atoms of the conserved TM core (TM1, TM2, TM3). The Kabsch algorithm minimises RMSD by optimal rotation.

Gs-bias ∝ ΔTM6_Gs; βarr-bias ∝ ΔTM6_βarr / ΔTM6_Gs
The ΔTM6 for Gs-coupled vs β-arrestin-coupled states gives the bias. lawson_scaling(B, R, n, T) — high-field tokamak confinement scaling

              
Compute the Lawson triple-product scaling for high-field tokamaks: n·T·τ_E scales as B²·R for fixed safety factor — explaining why SPARC (B=12T, R=0.66m) matches ITER (B=5T, R=6m) in Q.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
n·T·τ_E ∝ B²·R  →  Q ∝ B⁴·R (high-field advantage)

                
Confinement time τ_E scales with B²·R (ITER-89H empirical scaling). At fixed T and n, Q (the energy-gain ratio) scales as B⁴·R — a 2.4× field increase gives a 32× Q advantage, allowing SPARC to match ITER's Q with 1/9 the volume.

              

              
Math → Code derivation (5 steps)

              

                Step 1: ITER-89H confinement scaling
                
τ_E = 0.056 · H · I_p^0.93 · B^0.15 · n^0.41 · P^-0.69 · R^1.97 · ε^0.58 · κ^0.78 · M^0.19

                
ITER-89H empirical scaling: energy confinement time scales with toroidal current (I_p), magnetic field (B), density (n), heating power (P, negative), and major radius (R).

              

              

                Step 2: High-field approximation
                
At fixed safety factor q: I_p ∝ B·R, so τ_E ∝ B²·R (simplified)

                
At fixed q (plasma stability), the toroidal current I_p is proportional to B·R. Substituting into ITER-89H: τ_E ∝ B²·R. This is the high-field advantage.

              

              

                Step 3: Lawson triple product
                
n·T·τ_E ∝ B²·R · n · T  →  ignition requires n·T·τ_E ≥ 5×10²²

                
The Lawson triple product must exceed 5×10²² keV·s/m³ for ignition. With τ_E ∝ B²·R, the triple product scales as B²·R·n·T — a higher B lets you reach ignition at smaller R.

              

              

                Step 4: SPARC vs ITER scaling
                
B_SPARC = 12T, R_SPARC = 0.66m  vs  B_ITER = 5T, R_ITER = 6.2m

                
SPARC: B²·R = 144 · 0.66 = 95. ITER: B²·R = 25 · 6.2 = 155. They're within 1.6× — confirming SPARC can achieve Q ≈ 11 (ITER target Q = 10) at 1/40 the volume.

              

              

                Step 5: Net energy gain
                
Q_plasma = P_fusion / P_heating  →  SPARC Q ≈ 11 (V0=2 target)

                
Q_plasma is the ratio of fusion power to heating power. SPARC's V0=2 campaign (2026) targets Q=11 — exceeding ITER's Q=10 target, the first sustained net-energy-gain magnetic-confinement device.

bubble_count(G) — pangenome graph structural-variant density

              
Count bubbles (alternative allele paths) in a pangenome graph — the canonical structural-variant representation. More bubbles = more diversity captured.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
bubbles = { (u, v) : two internally vertex-disjoint paths u→v in G }

                
A bubble is a pair of parallel paths between two shared endpoints. Each bubble represents a structural variant — SNP, indel, or large SV — that the linear GRCh38 reference would represent as a single path.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Parse GFA records
                
V = { S lines }, E = { L lines }, P = { P lines }

                
GFA records: S (segment, sequence + length), L (link, oriented), P (path, ordered segments). Build the segment graph G = (V, E).

              

              

                Step 2: Topological sort
                
topo = Kahn(V, E)

                
Topologically sort the segments — left-to-right traversal. Required for bubble detection (bubbles respect the topological order).

              

              

                Step 3: Bubble definition
                
bubble(u, v) = pair of internally vertex-disjoint paths u→v

                
A bubble is two paths from u to v that share no internal vertices. Each path is an allele. Counting bubbles = counting structural variants.

              

              

                Step 4: Detection algorithm
                
for u in topo: for v in topo: if len(disjoint_paths(u, v)) >= 2: bubble!

                
Naive: for every pair (u, v), check if there are 2+ internally vertex-disjoint paths. O(V²) pairs × O(V·E) per check — too slow for 1.27M segments. Use the standard bubble-detection algorithm (O(V+E)).

              

              

                Step 5: SV error reduction
                
graph_call_error_rate / linear_call_error_rate = 0.27 (under-represented) / 0.59 (European)

                
Calling variants against the v1.1 graph reduces SV error rates by 73% in under-represented populations (African ancestry) and 41% in European samples — because the variants are already in the reference, not discovered by noisy alignment.

production_fitness(program, eval_fn, n_gen) — closed-loop evolutionary optimisation

              
Run AlphaEvolve's evolutionary optimisation on a small test program (matrix multiply). Measure fitness (number of scalar multiplications) over 100 generations.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
fitness_t = -n_mult(P_t)  →  P_{t+1} = argmax(mutations(P_t))

                
At generation t, mutate the population via the LLM and keep the program with fewest multiplications. The fitness signal is the number of scalar multiplications (lower = better).

              

              
Math → Code derivation (5 steps)

              

                Step 1: Initial population
                
P_0 = { naive_matmul } × 50 (clones of the naive algorithm)

                
Start with 50 copies of the naive O(n³) matrix-multiply algorithm. The LLM will mutate them toward better solutions.

              

              

                Step 2: LLM mutation
                
child_i = LLM(parent_i + task + history) → AST mutation

                
Prompt Gemini Pro with the parent program + the task + the recent fitness history. The LLM returns a mutated program — typically 1-3 line modifications.

              

              

                Step 3: Sandboxed fitness
                
f_i = -n_mult(child_i)  (run in sandbox, 10s timeout, 1GB RAM)

                
Run each child program in a sandbox; count scalar multiplications (lower = better). Hard limits: 10s CPU, 1GB RAM.

              

              

                Step 4: Selection (elitist)
                
P_{t+1} = top-50 by fitness from { parents ∪ children }

                
Combine parents + children; keep the top 50 by fitness. This is (μ+λ)-ES — guarantees monotonic improvement.

              

              

                Step 5: Convergence
                
after 100 generations: n_mult = 38 < 49 = Strassen(1969)

                
After 100 generations, AlphaEvolve finds a 38-multiplication 4×4 matrix-multiply — a 23% improvement over Strassen's 1969 result (49 mults). The algorithm is now deployed in Google's TPU scheduler.

The Broad/McGovern team reports the field-deployable SHERLOCKv2 platform — Cas13a + Cas12a collateral cleavage with lateral-flow paper-strip readout, detecting 4 viral targets in a single 30-minute reaction at room temperature.

design_crRNA(target_genome, n_guides=4) — SHERLOCK guide RNA design

              
Design Cas13a crRNA guides for SHERLOCK: pick 28-nt spacers in conserved regions of the target genome. Avoid off-target matches in the human transcriptome.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
crRNA = 28-nt spacer + 24-nt direct repeat (DR)  →  Cas13a binds DR, spacer targets viral RNA

                
Cas13a crRNA = 28-nt spacer (viral-target-specific) + 24-nt direct repeat (Cas13a scaffold). After target binding, Cas13a's collateral activity cleaves nearby reporter RNA — producing a fluorescent or paper-strip signal.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Identify conserved regions
                
conserved = windows where Shannon entropy < 0.5 (across 1000+ genomes)

                
Slide a 28-nt window across the target viral genome; identify windows with low Shannon entropy (high conservation across strain diversity). These are robust detection targets.

              

              

                Step 2: Spacer extraction
                
spacer = 28-nt subsequence of conserved region

                
Each conserved window yields a 28-nt spacer candidate. The spacer is the part of the crRNA that hybridises to the viral RNA target.

              

              

                Step 3: Off-target check
                
off_target = matches in human transcriptome (BLAST, E-value < 1)

                
Check each spacer against the human transcriptome. Reject any with significant off-target matches (would cause false positives from host RNA cleavage).

              

              

                Step 4: Direct-repeat append
                
crRNA = spacer + 5'-GATTTTCTACTAACGATAGTGTC-3' (24-nt DR for LwaCas13a)

                
Append the species-specific direct repeat (DR) for the chosen Cas13a ortholog. LwaCas13a (Leptotrichia wadei) uses a 24-nt DR — the most clinically validated ortholog.

              

              

                Step 5: Multiplexing
                
multiplex = mix 4 crRNAs (one per target) + 4 distinct reporters (one per crRNA)

                
SHERLOCKv2 multiplexes 4 crRNAs (e.g. SARS-CoV-2 N, influenza A NP, influenza B NS1, RSV F) with 4 distinct reporters — 4 targets in a single 30-min reaction. Paper-strip readout: each reporter produces a band at a different lateral-flow position.

ai_survey_scheduler(alerts, telescopes) — closed-loop astronomical survey

              
Simulate the closed-loop AI survey scheduler: prioritise alerts by science-value × feasibility, allocate telescope time, re-plan on new alerts.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
priority(alert) = science_value(alert) × feasibility(alert, telescope) × urgency(alert)

                
Each alert is scored by scientific value × telescope feasibility × urgency. The AI scheduler maximises the total priority observed per night, subject to telescope constraints (visibility, weather, slew time).

              

              
Math → Code derivation (5 steps)

              

                Step 1: Alert stream
                
alerts = [(time, source_id, type, urgency)] from ZTF + Rubin + LIGO + IceCube + SWIFT

                
Real-time alert streams from 5 surveys. Each alert has a type (transient, GW neutrino counterpart, etc.) and urgency (seconds to hours response window).

              

              

                Step 2: Science-value scoring
                
science_value(alert) = rarity(alert_type) × multi-messenger(alert)

                
AI scores each alert: rare event types (kilonova, neutrino counterpart) get high value; multi-messenger events (GW + EM) get a 10× multiplier.

              

              

                Step 3: Feasibility
                
feasibility(alert, telescope) = visibility(alert, telescope) × weather × slew_time

                
For each (alert, telescope) pair, compute feasibility: is the source visible from this telescope at this time? Is the weather clear? How long is the slew?

              

              

                Step 4: RL scheduler
                
π_θ(state) → action = (telescope, target, exposure_time)

                
The RL agent (PPO-trained on 10 years of historical observations) decides: which telescope points where for how long. The reward is the total science-value observed.

              

              

                Step 5: Closed-loop re-planning
                
on new alert: re-plan within 60s, re-allocate telescopes

                
When a new alert arrives, the AI re-plans within 60 seconds — potentially interrupting a current observation to chase the higher-value target. The 2028 vision: 80% of transient events observed within 5 minutes of detection.

program_cell(payload, chassis) — universal cell programming

              
Simulate the 2030 universal-cell programming: inject mRNA + gRNAs into the minimal chassis cell; the payload expresses CRISPR editors that reprogram the genome to the target functional state.

            

            ▾
          

          

            

              
              
              
            

            
            

              

                
state(payload) = genes_silenced(payload.gRNAs) ∪ genes_activated(payload.CRISPRa) ∪ genes_edited(payload.ABE)

                
The injected payload encodes: (1) gRNAs targeting CRISPRoff (silencing specific genes), (2) CRISPRa guide RNAs (activating others), (3) ABE base editors (introducing specific stop/start codons). The combination determines the cell's functional state.

              

              
Math → Code derivation (5 steps)

              

                Step 1: Minimal chassis
                
chassis = E. coli minimalised to 312 essential genes (refactored genome)

                
Start with E. coli K-12, knock out all non-essential genes (~3000 of 4000), keep 312 essential genes. Refactor the genome for predictable regulation — every promoter is repressed by default, every gene is lacI-repressible.

              

              

                Step 2: CRISPRoff payload (silencing)
                
silenced = { genes targeted by CRISPRoff gRNAs }

                
Inject gRNAs targeting specific genes for CRISPRoff-mediated silencing (DNMT3A-3L + dCas9). The silenced set determines which metabolic pathways are turned OFF.

              

              

                Step 3: CRISPRa payload (activation)
                
activated = { genes targeted by CRISPRa gRNAs }

                
Inject gRNAs targeting specific genes for CRISPRa (CRISPR activation — dCas9 + VP64/p65/Rta tri-activator). The activated set determines which metabolic pathways are turned ON.

              

              

                Step 4: ABE payload (precise editing)
                
edited = { A→G edits introduced by ABE8.8 at specific positions }

                
Inject ABE8.8 + a single gRNA to introduce specific A→G edits (e.g. Q54* stop codon to inactivate a repressor). The edited set introduces precise point mutations.

              

              

                Step 5: Functional state
                
state = (silenced, activated, edited) → one of 47 pre-programmed functional states

                
The combination of silenced + activated + edited genes determines the cell's functional state. 47 such combinations have been pre-validated — insulin-producer, hydrogenase-expressor, plastic-eater, etc.
