Phase 38 · Causal inference × MPNN

Causal-Chemprop: structural causal model × MPNN for pIC50

Inspired by the LinkedIn post on the ACS JCIM 2026 paper "Causal-Chemprop" — which augments the Chemprop message-passing neural network (MPNN) with a structural causal model (SCM) for molecular property prediction. The anchor + test molecules are conditionally intervened on (do-calculus), which improves pIC50 prediction accuracy on kinases like ABL (0.45 → 0.56), BCR-ABL, and others. The demo below shows the 5-step causal pipeline; each step has Math → Code annotations (6-language polyglot in the concept card).

Show the 5-step Math → Code derivation
Step 1 — Anchor selection:
A = {(m, IC50) : IC50(m) < 100 nM, confidence(m) > 0.9}
// High-confidence actives form the anchor set A.

Step 2 — MPNN message passing (Chemprop):
hv(k+1) = σ(Wk Σu ∈ N(v) hu(k) + bk)
// Update atom features h by aggregating neighbours' features.

Step 3 — SCM conditioning:
P(Y | do(X), A) ≠ P(Y | X, A) — back-door adjustment
// Condition on the anchor scaffold to block confounding paths.

Step 4 — do-calculus intervention:
do(X = xR) — replace R-group substituents with test values
// Counterfactual: "what if we set R-group to test value?"

Step 5 — pIC50 prediction lift:
pIC50 = -log10(IC50 × 10-9) · Δ = ŷcausal − ŷMPNN
// ABL: 0.45 → 0.56 (r²) · BCR-ABL: 0.51 → 0.63 · c-KIT: 0.48 → 0.59

References: Causal-Chemprop, ACS J. Chem. Inf. Model. 2026. Chemprop (Yang et al. 2019). Structural causal models (Pearl 2009). The concept card at concepts/digest-causal-chemprop.html has the 6-language polyglot code (Python / Rust / Go / C / Elixir / Scala).

Phase 40 · Scientific + Big-Data File Uploader

Drop your molecule / data → live 3D view + parsed stats

Drop a .pdb, .sdf, .mol, .cif file to see real 3D coordinates rendered in the molecule-3d viewer above (no SMILES needed). Also accepts big-data + scientific formats — .csv, .tsv, .parquet, .arrow, .feather, .h5/.hdf5, .nc/.netcdf, .npy/.npz, .mat, .fits, .vtk, .json, .hdfs. Pure client-side. Nothing leaves the browser.

Magic-bytes detection (PAR1 / ARROW1 / \x89HDF\r\n\x1A\n / \x93NUMPY / SEQ) means the right parser is chosen automatically by file content — even if the extension is wrong. The uploader registers molecule-3d as a downstream consumer: any parsed kind: 'molecule' result is automatically pushed into the viewer above.
