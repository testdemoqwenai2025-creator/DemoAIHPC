Component Registry

Interactive dashboard of all AIHPC canvas components — the platform's bill of materials for reproducibility. Reads from docs/component-manifest.json. Each component shows its phase, lazy-load status, global variable, mount pages, and concept-card links.

All Components

The manifest is auto-verified by scripts/gen-component-registry.py (run as audit check component_registry_generator). To add a new component: add it to docs/component-manifest.json + create the JS file + wire it into its mount page(s).
