BOLERO

Liu, Mao, Gallent, Chen, Yan, Vogel, Traunmüller, Zhang, Buenrostro, Zhou, Greenberg — 2025
Cell-state-conditioned sequence-to-function Transformer. Hypernetwork generates per-layer weight deltas from cell-state embedding. Predicts ATAC + transcript abundance directly from DNA. Generalises across species.

Geneformer

Theodoris et al. — Harvard / MIT / Broad — 2023
Pre-trained Transformer on Genecorpus-30M (30M human single-cell transcriptomes). Tokens = ranked genes per cell (not absolute counts). Transfer-learns to: disease classification, in-silico perturbation, gene-network inference, cell-type annotation.

AlphaFold 3

Abramson et al. — Google DeepMind / Isomorphic Labs — 2024
Extends AlphaFold 2 to predict complex assemblies of proteins + DNA + RNA + ligands + chemical modifications. Replaces the structure module with a diffusion model. ~50% improvement on protein-ligand interactions vs AutoDock Vina.

☁️ Cloud storage + compute options for technical users

These papers often involve 10M+ cell datasets and 100M+ parameter models. For researchers wanting to run/fine-tune these models themselves, here are free + paid tiers across major cloud providers:

📁 GitHub Releases (free, ≤2GB/file) 🤗 Hugging Face Hub (free model hosting, ≤10GB/repo) 💾 Backblaze B2 (10GB free, then $5/TB/mo) 🚀 Cloudflare R2 (10GB free, no egress fees) ☁️ AWS S3 (paid, 5GB free for 12mo) ☁️ Google Cloud Storage (5GB free, then $26/TB/mo) ☁️ Azure Blob (5GB free for 12mo) 🐍 Google Colab (free T4 GPU, Pro $10/mo) 📊 Kaggle Notebooks (free P100 GPU) 🖥 Lambda Labs (A100 at $1.10/hr) ⚡ RunPod (A100 at $0.40/hr spot)

For technical-minded users: subscribe to a cloud portal for versioned snapshots of model weights + calibration sets. Hugging Face Hub is the standard for sharing foundation models (BOLERO + scGPT + Geneformer weights are all available there). For compute, Colab Pro or RunPod spot instances are the cheapest way to fine-tune these models on your data.
