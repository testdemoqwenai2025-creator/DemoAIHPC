Design Principles That Made It Last

  • Pure client-side: Zero external services, zero backend, zero API keys. The platform works in 2027 or 2047 — GitHub Pages just serves static files.
  • No-cloning theorem: Quantum mechanics guarantees that unknown quantum states cannot be copied — the foundation of BB84 QKD security (Phase 50).
  • Composable components: Every canvas component has a clean public API + registerConsumer pattern. New visualisations compose with new uploaders without rewriting either.
  • Math is the contract: Every equation (a|n⟩ = √n|n-1⟩, Dice = 2|A∩B|/(|A|+|B|), E = mc²) stays mathematically true forever. Implementations evolve; math doesn't.
  • Audit-gated CI: 52+ machine-checked invariants ensure no regression. The CI workflow tags + pushes to public mirror automatically.
  • Lazy evaluation: IntersectionObserver-based lazy mounting means a single page can host 9+ visualisations without page-load cost.
  • Open standards: Every demo cites real papers (Bennett 1993, Nielsen & Chuang, TotalSegmentator, etc.). Content ages gracefully; we just refresh citations.
