Each step shows the mathematical transformation, explains the intuition, then shows the corresponding code line. This is the bridge between equation and implementation.

1 Objective function — minimize within-cluster sum of squares
argminC,μ Σc=1k Σx ∈ Cc ||x − μc||²
We want to partition n points into k clusters C₁...Cₖ, each with a centroid μ_c, such that the total squared distance from each point to its cluster's centroid is minimized.
# The objective we minimize\ndef wcss(points, assignments, centroids):\n return sum((p[0]-centroids[a][0])**2 + (p[1]-centroids[a][1])**2 for p, a in zip(points, assignments))
2 Assignment step — assign each point to nearest centroid
c(x) = argminc ||x − μc||²
For each point x, find the cluster c whose centroid μ_c is closest (by Euclidean distance). This is the "assignment" half of Lloyd's algorithm.
# Step 2: assign each point to nearest centroid\ndef assign(points, centroids):\n return [min(range(len(centroids)),\n key=lambda c: sum((p[d]-centroids[c][d])**2 for d in range(2)))\n for p in points]
3 Update step — move each centroid to the mean of its assigned points
μc(t+1) = (1/|Cc|) · Σx ∈ Cc x
After re-assigning all points, update each centroid to be the arithmetic mean of all points assigned to it. This is the gradient-descent step that monotonically decreases WCSS.
# Step 3: update centroids to cluster means\ndef update(points, assignments, k):\n return [(\n sum(p[0] for p, a in zip(points, assignments) if a == c) / max(1, sum(1 for a in assignments if a == c)),\n sum(p[1] for p, a in zip(points, assignments) if a == c) / max(1, sum(1 for a in assignments if a == c))\n ) for c in range(k)]
4 Convergence check — stop when assignments stop changing
converged ⟺ c(t+1)(x) = c(t)(x) ∀x
Lloyd's algorithm is guaranteed to converge in finite steps because WCSS is monotonically decreasing and there are finitely many partitions. In practice, we check if any point changed cluster; if none did, we're done.
# Step 4: check convergence\nif new_assignments == old_assignments:\n break # converged
5 Full algorithm — alternate assignment and update until convergence
repeat: (1) assign, (2) update, (3) check → until converged
The complete algorithm: initialise centroids (k-means++), then alternate assignment and update steps until no point changes cluster. Each iteration is O(n·k) — fast for moderate n and k.
def kmeans(points, k, max_iter=100):\n centroids = kmeans_plusplus_init(points, k)\n for _ in range(max_iter):\n assignments = assign(points, centroids) # Step 2\n new_centroids = update(points, assignments, k) # Step 3\n if new_centroids == centroids: break # Step 4\n centroids = new_centroids\n return assignments, centroids
