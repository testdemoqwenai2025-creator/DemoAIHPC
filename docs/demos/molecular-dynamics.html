Step 1: Newton's equation of motion
m · d²x/dt² = F(x) = −∇V(x)
Each particle obeys Newton's second law. The force is the negative gradient of the potential energy V. For Lennard-Jones: V(r) = 4ε[(σ/r)¹² − (σ/r)⁶].
Step 2: Lennard-Jones force
F(r) = 24ε/r · [2(σ/r)¹² − (σ/r)⁶]
The LJ force is the derivative of the LJ potential. At short range, the r⁻¹² term dominates (repulsive); at medium range, the r⁻⁶ term dominates (attractive). The equilibrium distance is r = 2^(1/6)·σ.
function ljForce(r, eps=1.0, sigma=1.0) { const sr = sigma / r; const sr6 = sr**6, sr12 = sr**12; return 24 * eps / r * (2 * sr12 - sr6); }
Step 3: Velocity-Verlet position update
x(t+dt) = x(t) + v(t)·dt + ½·a(t)·dt²
Update position using current velocity and half the current acceleration. This is the first half of the velocity-Verlet step.
for (const p of particles) { p.x += p.vx * dt + 0.5 * p.ax * dt * dt; p.y += p.vy * dt + 0.5 * p.ay * dt * dt; }
Step 4: Velocity-Verlet velocity update
v(t+dt) = v(t) + ½·[a(t) + a(t+dt)]·dt
Compute new forces at the updated positions, then update velocity using the average of old and new accelerations. This is symplectic — it conserves energy on average.
// Compute new forces at new positions computeForces(); // Update velocity with half-step average for (const p of particles) { p.vx += 0.5 * (p.ax + p.ax_new) * dt; p.vy += 0.5 * (p.ay + p.ay_new) * dt; }
Step 5: Full integrator loop
repeat: (2) compute forces, (3) update positions, (4) recompute forces + update velocities
The complete time-stepping loop. Each iteration is O(N²) for the pairwise force computation. With N=20, that's 190 pairs — fast enough for real-time animation.
function step(dt) { computeForces(); // Step 2 for (const p of particles) { // Step 3 p.x += p.vx*dt + 0.5*p.ax*dt*dt; p.y += p.vy*dt + 0.5*p.ay*dt*dt; p.ax_old = p.ax; p.ay_old = p.ay; } computeForces(); // new forces for (const p of particles) { // Step 4 p.vx += 0.5*(p.ax_old + p.ax)*dt; p.vy += 0.5*(p.ay_old + p.ay)*dt; } applyBoundaryConditions(); }

Executive summary

              
    
                
  • Algorithm: Velocity-Verlet integration — the standard molecular-dynamics time integrator. Symplectic (energy-conserving on average).
    • 
                
  • Potential: Lennard-Jones — V(r) = 4ε[(σ/r)¹² − (σ/r)⁶]. Models van der Waals interactions.
    • 
                
  • Complexity: O(N²) per step for pairwise forces. N=20 → 190 pairs — real-time at 60fps.
    • 
                
  • Boundary: Periodic boundary conditions (particles wrap around the box).
    • 
                
  • Output: Downloadable CSV with final positions, velocities, and energies.
