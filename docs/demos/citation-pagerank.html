Step 1: Define PageRank
PR(p) = (1−d)/N + d · Σq∈In(p) PR(q) / OutDeg(q)
PageRank of page p = (1−d)/N (random-jump probability) + d × (sum of PageRank from pages that cite p, divided by their out-degree). d is the damping factor (typically 0.85).
Step 2: Initialize
PR(0)(p) = 1/N ∀p
Start with uniform distribution: every paper gets 1/N. The algorithm iterates from here.
# Step 2: initialize\npr = {p: 1.0 / n for p in nodes}
Step 3: Power iteration
PR(t+1)(p) = (1−d)/N + d · Σq∈In(p) PR(t)(q) / |Out(q)|
At each iteration, recompute PR for every node using the previous iteration's values. The (1−d)/N term handles "random jumps" (users who navigate to a random page); the d × sum handles "following links" (citations).
# Step 3: one iteration\nnew_pr = {}\nfor p in nodes:\n incoming = sum(pr[q] / len(out_edges[q]) for q in in_edges[p])\n new_pr[p] = (1 - d) / n + d * incoming
Step 4: Convergence check
converged ⟺ max|PR(t+1)(p) − PR(t)(p)| < ε
Stop when the maximum change across all nodes is below a threshold ε (typically 10⁻⁶). PageRank is guaranteed to converge because it's a stochastic matrix power iteration.
# Step 4: check convergence\nif max(abs(new_pr[p] - pr[p]) for p in nodes) < 1e-6:\n break
Step 5: Full algorithm
repeat: (2) init, (3) iterate, (4) check → until converged
The complete algorithm: initialise uniformly, iterate power method, check convergence. O(N+E) per iteration. Converges in ~20-50 iterations for typical graphs.
def pagerank(nodes, edges, d=0.85, eps=1e-6):\n n = len(nodes)\n pr = {p: 1.0/n for p in nodes}\n while True:\n new_pr = {p: (1-d)/n + d*sum(pr[q]/len(out[q]) for q in in_[p]) for p in nodes}\n if max(abs(new_pr[p]-pr[p]) for p in nodes) < eps: break\n pr = new_pr\n return pr

Executive summary

              
    
                
  • Algorithm: PageRank via power iteration — the same algorithm Google uses to rank web pages, applied to citation networks.
    • 
                
  • Complexity: O(N+E) per iteration. Converges in ~20-50 iterations.
    • 
                
  • Guarantee: Convergence guaranteed because the transition matrix is stochastic + irreducible + aperiodic (due to the damping factor d).
    • 
                
  • Output: Downloadable CSV with paper IDs + PageRank scores.
    • 
                
  • Audit: The Math → Code derivation shows exactly how the PageRank equation becomes the power iteration loop.
